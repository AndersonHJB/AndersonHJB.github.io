变量的命名规则

  1. 大小写英文；「区分大小写」
name = "aiyc"

Name = "mingxuan"
print(name)
  1. 数字不能开头；
n1a2me = "aiyc"

除了变量的开头不能放数字之外，其他位置都可以放数字。

  1. 变量不能有空格；
user_name = "aiyc"
  1. 系统关键词不能当作变量名；
Class = "aiyc"
# cl_ass = "aiyc"
# _class = "aiyc"
# class_ = "aiyc"
  1. 查看系统关键词；
help("keywords")
  1. 不要使用 Python 的内置函数名做变量名；
