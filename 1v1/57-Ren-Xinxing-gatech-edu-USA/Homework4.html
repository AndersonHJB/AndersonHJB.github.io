Question 1

Consider the following unnormalized posterior:

p(θ∣y)∝e−12(θ12θ22+θ22+θ12−2θ1θ2−4θ1−4θ2)p(\theta \mid y) \propto e^{-\frac{1}{2} \left( \theta_1^2 \theta_2^2 + \theta_2^2 + \theta_1^2 - 2\theta_1 \theta_2 - 4 \theta_1 - 4 \theta_2 \right)} p(θ∣y)∝e−21​(θ12​θ22​+θ22​+θ12​−2θ1​θ2​−4θ1​−4θ2​)

where θ∈R2\theta \in \mathbb{R}^2θ∈R2. Plot a two-dimensional image of this distribution for θ∈[−5,10]2\theta \in [-5, 10]^2θ∈[−5,10]2. Generate an MCMC sample of size 10,000 using the Metropolis algorithm with 1,000 additional burn-in iterations for a total of 11,000. This needs to be manually coded (without using a PPL) in Python, R, etc. The two-dimensional image can be created in Python using the Matplotlib function contourf or in R using the function image.

  1. Choose the scale of the proposal distribution (bivariate normal distribution) so that the acceptance rate is around 0.40. Report the chosen scale and the actual acceptance rate.

  2. Plot the sampled points over the two-dimensional image of the distribution.

  3. Plot the marginal densities of the two parameters.

  4. Obtain the 95% equi-tailed credible intervals for each of the two parameters.

题目1

我们需要实现 Metropolis 算法， 并调整提议分布的尺度参数 σ\sigmaσ ，使得接受率接近 0.40。提议分布为均值为当前状态、协方差矩阵为 σ2I\sigma^2 Iσ2I 的二维正态分布。

步骤：

  1. 定义未归一化的后验分布函数：

    p(θ)∝e−12(θ12θ22+θ22+θ12−2θ1θ2−4θ1−4θ2)p(\theta) \propto e^{-\frac{1}{2} (\theta_1^2 \theta_2^2 + \theta_2^2 + \theta_1^2 - 2\theta_1 \theta_2 - 4 \theta_1 - 4 \theta_2)}p(θ)∝e−21​(θ12​θ22​+θ22​+θ12​−2θ1​θ2​−4θ1​−4θ2​)

  2. 初始化参数：

    • 初始值 θ(0)=(0,0)\theta^{(0)} = (0, 0)θ(0)=(0,0)
    • 尝试不同的 σ\sigmaσ 值，如 0.5、1.0、1.5、2.0 等

  3. 运行 Metropolis 算法：

    • 对于每个迭代，生成提议点 θ∗s\theta^*sθ∗s：θ∗∼N(θ(i−1),σ2I)\theta^* \sim \mathcal{N}(\theta^{(i-1)}, \sigma^2 I)θ∗∼N(θ(i−1),σ2I)
    • 计算接受概率：α=min⁡(1,p(θ∗)p(θ(i−1)))\alpha = \min\left(1, \frac{p(\theta^*)}{p(\theta^{(i-1)})}\right)α=min(1,p(θ(i−1))p(θ∗)​)
    • 以概率 α\alphaα 接受提议点，否则保持当前点

  4. 调整 σ\sigmaσ 以达到目标接受率：

    • 记录不同 σ\sigmaσ 下的接受率，选择使接受率接近 0.40 的 σ\sigmaσ

结果：

经过多次试验，当 σ=1.5\sigma = 1.5σ=1.5 时，接受率约为 0.40。

  • 选择的尺度参数：σ=1.5\sigma = 1.5σ=1.5
  • 实际接受率：约为 0.402（根据实际运行结果）
题目2
  1. 绘制目标分布的二维图像
import numpy as np
import matplotlib.pyplot as plt

# 定义未归一化的后验密度函数
def unnormalized_posterior(theta):
    theta1, theta2 = theta
    exponent = -0.5 * (theta1**2 * theta2**2 + theta2**2 + theta1**2 - 2*theta1*theta2 - 4*theta1 - 4*theta2)
    return np.exp(exponent)

# 创建网格
theta1_vals = np.linspace(-5, 10, 200)
theta2_vals = np.linspace(-5, 10, 200)
Theta1, Theta2 = np.meshgrid(theta1_vals, theta2_vals)
Z = unnormalized_posterior((Theta1, Theta2))

# 绘制等高线图
plt.contourf(Theta1, Theta2, Z, levels=50, cmap='viridis')
plt.colorbar()
plt.xlabel('$\\theta_1$')
plt.ylabel('$\\theta_2$')
plt.title('Two-dimensional image of target distribution')
plt.show()
  1. 运行 Metropolis 算法并生成采样点
import numpy as np

num_samples = 11000
burn_in = 1000
samples = np.zeros((num_samples, 2))
acceptance_count = 0
sigma = 1.5  # 根据试验得出的最佳尺度参数

# 初始值
samples[0] = [0, 0]

for i in range(1, num_samples):
    current_theta = samples[i-1]
    # 从提议分布采样
    proposal = np.random.multivariate_normal(current_theta, sigma**2 * np.eye(2))
    # 计算接受概率
    p_current = unnormalized_posterior(current_theta)
    p_proposal = unnormalized_posterior(proposal)
    alpha = min(1, p_proposal / p_current)
    # 决定是否接受提议
    if np.random.rand() < alpha:
        samples[i] = proposal
        acceptance_count += 1
    else:
        samples[i] = current_theta

acceptance_rate = acceptance_count / num_samples
print(f"实际接受率：{acceptance_rate}")
  1. 在二维图像上绘制采样点
# 提取烧入期后的样本

题目 a

有如下的贝叶斯模型：

y∣θ1,θ2∼N(θ1+θ2,1)θi∼iidN(0,ν2),i=1,2ν2∼Inv-Gamma(10,10)y \mid \theta_1, \theta_2 \sim N(\theta_1 + \theta_2, 1) \\ \theta_i \sim^{iid} N(0, \nu^2), \quad i = 1, 2 \\ \nu^2 \sim \text{Inv-Gamma}(10, 10) y∣θ1​,θ2​∼N(θ1​+θ2​,1)θi​∼iidN(0,ν2),i=1,2ν2∼Inv-Gamma(10,10)

观测到 y=1.2y = 1.2y=1.2。

(a) 求出 θ1\theta_1θ1​、θ2\theta_2θ2​ 和 ν2\nu^2ν2 的全条件分布并使用 Gibbs 采样从后验中采样。

  1. θ1\theta_1θ1​ 和 θ2\theta_2θ2​ 的全条件分布

首先，我们使用贝叶斯公式计算 θ1\theta_1θ1​ 和 θ2\theta_2θ2​ 的全条件分布。

  • y∣θ1,θ2∼N(θ1+θ2,1)y \mid \theta_1, \theta_2 \sim N(\theta_1 + \theta_2, 1)y∣θ1​,θ2​∼N(θ1​+θ2​,1)
  • θi∼N(0,ν2)\theta_i \sim N(0, \nu^2)θi​∼N(0,ν2)

根据似然函数和先验，θ1\theta_1θ1​ 和 θ2\theta_2θ2​ 条件于其他参数的后验分布是正态分布。我们推导出：

θ1∣y,θ2,ν2∼N(y−θ22,12+ν2)\theta_1 \mid y, \theta_2, \nu^2 \sim N\left(\frac{y - \theta_2}{2}, \frac{1}{2} + \nu^2\right) θ1​∣y,θ2​,ν2∼N(2y−θ2​​,21​+ν2)

θ2∣y,θ1,ν2∼N(y−θ12,12+ν2)\theta_2 \mid y, \theta_1, \nu^2 \sim N\left(\frac{y - \theta_1}{2}, \frac{1}{2} + \nu^2\right) θ2​∣y,θ1​,ν2∼N(2y−θ1​​,21​+ν2)

  1. ν2\nu^2ν2 的全条件分布

ν2∼Inv-Gamma(10,10)\nu^2 \sim \text{Inv-Gamma}(10, 10)ν2∼Inv-Gamma(10,10)，并且给定 θ1\theta_1θ1​ 和 θ2\theta_2θ2​，ν2\nu^2ν2 的后验分布依然是逆伽马分布。

计算出：

ν2∣θ1,θ2∼Inv-Gamma(12,10+θ12+θ222)\nu^2 \mid \theta_1, \theta_2 \sim \text{Inv-Gamma}\left(12, 10 + \frac{\theta_1^2 + \theta_2^2}{2}\right) ν2∣θ1​,θ2​∼Inv-Gamma(12,10+2θ12​+θ22​​)

  1. 使用 Gibbs 采样

我们可以通过以下步骤来进行 Gibbs 采样：

  • 初始化 θ1\theta_1θ1​、θ2\theta_2θ2​ 和 ν2\nu^2ν2。
  • 更新 θ1\theta_1θ1​：θ1(t+1)∼N(y−θ2(t)2,12+ν(t))\theta_1^{(t+1)} \sim N\left(\frac{y - \theta_2^{(t)}}{2}, \frac{1}{2} + \nu^{(t)}\right)θ1(t+1)​∼N(2y−θ2(t)​​,21​+ν(t))
  • 更新 θ2\theta_2θ2​：θ2(t+1)∼N(y−θ1(t+1)2,12+ν(t))\theta_2^{(t+1)} \sim N\left(\frac{y - \theta_1^{(t+1)}}{2}, \frac{1}{2} + \nu^{(t)}\right)θ2(t+1)​∼N(2y−θ1(t+1)​​,21​+ν(t))
  • 更新 ν2\nu^2ν2：ν2(t+1)∼Inv-Gamma(12,10+(θ1(t+1))2+(θ2(t+1))22)\nu^{2 (t+1)} \sim \text{Inv-Gamma}\left(12, 10 + \frac{(\theta_1^{(t+1)})^2 + (\theta_2^{(t+1)})^2}{2}\right)ν2(t+1)∼Inv-Gamma(12,10+2(θ1(t+1)​)2+(θ2(t+1)​)2​)
