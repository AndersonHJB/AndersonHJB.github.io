def process(A):
    for i in range(len(A) - 1):
        m = i
        for j in range(i + 1, len(A)):
            if A[m] < A[j]:
                m = j
        A[i], A[m] = A[m], A[i]
Answer

这是选择排序（Selection Sort）的一个实现，该算法的工作原理是通过在数组中寻找最大（或最小）的元素，并将其放到正确的位置。

让我们对其进行时间复杂度的分析。

  1. 对于外层循环：

    for i in range(len(A) - 1):

    它执行了 len(A) - 1 次。假设数组 A 的长度为 n，那么外层循环执行了 n - 1 次。

  2. 对于内层循环：

    for j in range(i + 1, len(A)):

    当 i=0 时，内层循环执行 n-1 次；当 i=1 时，执行 n-2 次；依此类推，直到 i=n-2 时，执行 1 次。

    内层循环的总执行次数为：

    ∑i=1n−1i=(n−1)(n)2=n22−n2\sum_{i=1}^{n-1} i = \frac{(n-1)(n)}{2} = \frac{n^2}{2} - \frac{n}{2}∑i=1n−1​i=2(n−1)(n)​=2n2​−2n​

  3. 在内层循环中的比较和赋值操作：

    if A[m] < A[j]:
    m = j

    因为这些操作在每次内层循环迭代中都执行，所以它们的总执行次数也是:

    n22−n2\frac{n^2}{2} - \frac{n}{2}2n2​−2n​

  4. 最后的交换操作：

    A[i], A[m] = A[m], A[i]

    它在每次外层循环迭代中都执行一次，因此总执行次数为 n - 1。

将所有这些组合起来，代码的运行时为：

T(n)=(n−1)+(n22−n2)T(n) = (n - 1) + \left( \frac{n^2}{2} - \frac{n}{2} \right)T(n)=(n−1)+(2n2​−2n​)

这可以简化为:

T(n)=n22+n2−1T(n) = \frac{n^2}{2} + \frac{n}{2} - 1T(n)=2n2​+2n​−1

这意味着选择排序的时间复杂度为 O(n2)O(n^2)O(n2)。

分摊分析（Amortized Analysis）

假设每行代码执行所需的时间为常数。

Assume for now: Each line of code takes constant time cℓc_\ellcℓ​ > 0 per execution.

def process(A):
    for i in range(len(A) - 1):                 # c1
        m = i                                   # c2
        for j in range(i + 1, len(A)):          # c3
            if A[m] < A[j]:                     # c4
                m = j                           # c5
        A[i], A[m] = A[m], A[i]                 # c6

  1. 外层循环 for i in range(len(A) - 1): 执行了 n−1n-1n−1 次。因此，它对应的运行时间为 c1⋅(n−1)c_1 \cdot (n-1)c1​⋅(n−1)。

  2. 在每次外层循环的迭代中，都会执行 m = i 。因此，这行代码的总执行次数为 c2⋅(n−1)c_2 \cdot (n-1)c2​⋅(n−1)。

  3. 对于内层循环 for j in range(i + 1, len(A)): ，当 i=0 时，执行 n−1n-1n−1 次；当 i=1 时，执行 n−2n-2n−2 次，以此类推。因此，这行代码的总执行次数为: c3⋅∑i=1n−1i=c3⋅(n−1)n2c_3 \cdot \sum_{i=1}^{n-1} i = c_3 \cdot \frac{(n-1)n}{2}c3​⋅∑i=1n−1​i=c3​⋅2(n−1)n​

  4. 在每次内层循环的迭代中，都会进行 if A[m] < A[j]: 的检查，因此，其总执行次数为: c4⋅n22−n2c_4 \cdot \frac{n^2}{2} - \frac{n}{2}c4​⋅2n2​−2n​

  5. m = j 只在 if 条件为真时执行。在最坏情况下（每次都找到一个更大的数），它执行的次数与内层循环相同，即: c5⋅n22−n2c_5 \cdot \frac{n^2}{2} - \frac{n}{2}c5​⋅2n2​−2n​

  6. 在每次外层循环迭代中，都会执行 A[i], A[m] = A[m], A[i] 。因此，这行代码的总执行次数为 c6⋅(n−1)c_6 \cdot (n-1)c6​⋅(n−1)。

这个公式表示了选择排序的时间复杂度，它是一个二次方函数，所以选择排序的时间复杂度是 O(n2)O(n^2)O(n2)。
