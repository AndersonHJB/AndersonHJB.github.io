EN

Bisection is an iterative method for finding approximate roots of a function. Say we know that the function f(x)f(x)f(x) has one root between x0x_{0}x0​ and x1x_{1}x1​ (x0<x1x_{0} < x_{1}x0​<x1​). We then:

  • Evaluate fff at the midpoint xmid=(x0+x1)/2x_{\rm mid} = (x_0 + x_1)/2xmid​=(x0​+x1​)/2, i.e. compute fmid=f(xmid)f_{\rm mid} = f(x_{\rm mid})fmid​=f(xmid​)

  • Evaluate f(x0)⋅f(xmid)f(x_0) \cdot f(x_{\rm mid})f(x0​)⋅f(xmid​)

    • if f(x0)⋅f(xmid)<0f(x_0) \cdot f(x_{\rm mid}) < 0f(x0​)⋅f(xmid​)<0:

      fff must change sign somewhere between x0x_0x0​ and xmidx_{\rm mid}xmid​, hence the root must lie between x0x_0x0​ and xmidx_{\rm mid}xmid​, so set x1=xmidx_1 = x_{\rm mid}x1​=xmid​.

    • else:

      fff must change sign somewhere between xmidx_{\rm mid}xmid​ and x1x_1x1​, so set x0=xmidx_0 = x_{\rm mid}x0​=xmid​.

The above steps can be repeated a specified number of times, or until ∣fmid∣|f_{\rm mid}|∣fmid​∣ is below a tolerance, with xmidx_{\rm mid}xmid​ being the approximate root.

二分法是一种迭代方法，用于查找函数的近似根。假设我们知道函数 f(x)f(x)f(x) 在 x0x_{0}x0​ 和 x1x_{1}x1​ 之间有一个根 (x0<x1x_{0} < x_{1}x0​<x1​)。我们可以：

  • 在中点 xmid=(x0+x1)/2x_{\rm mid} = (x_0 + x_1)/2xmid​=(x0​+x1​)/2 处评估 fff，即计算 fmid=f(xmid)f_{\rm mid} = f(x_{\rm mid})fmid​=f(xmid​)

  • 计算 f(x0)⋅f(xmid)f(x_0) \cdot f(x_{\rm mid})f(x0​)⋅f(xmid​)

    • 如果 f(x0)⋅f(xmid)<0f(x_0) \cdot f(x_{\rm mid}) < 0f(x0​)⋅f(xmid​)<0：

      fff 必须在 x0x_0x0​ 和 xmidx_{\rm mid}xmid​ 之间某处改变符号，因此根必须位于 x0x_0x0​ 和 xmidx_{\rm mid}xmid​ 之间，所以设置 x1=xmidx_1 = x_{\rm mid}x1​=xmid​。

    • 否则：

      fff 必须在 xmidx_{\rm mid}xmid​ 和 x1x_1x1​ 之间某处改变符号，所以设置 x0=xmidx_0 = x_{\rm mid}x0​=xmid​。

以上步骤可以重复指定的次数，或者直到 ∣fmid∣|f_{\rm mid}|∣fmid​∣ 低于某个容忍度，此时 xmidx_{\rm mid}xmid​ 为近似根。

任务

函数

f(x)=−x510+x3−10x2+4x+7f(x) = - \frac{x^{5}}{10} + x^3 - 10x^2 + 4x + 7 f(x)=−10x5​+x3−10x2+4x+7

在范围 0<x<20 < x < 20<x<2 内有一个根。

  1. 使用二分法在 20 次迭代中找到一个近似根 xrx_{r}xr​ （使用 for 循环）。
  2. 使用二分法找到一个近似根 xrx_{r}xr​，使得 ∣f(xr)∣<1×10−6\left| f(x_{r}) \right| < 1 \times 10^{-6}∣f(xr​)∣<1×10−6，并报告所需的迭代次数（使用 while 循环）。

使用变量 x_mid 存储近似根，并使用变量 f 存储 f(xmid)f(x_{\rm mid})f(xmid​)。

提示: 使用 abs 计算数字的绝对值，例如 y = abs(x) 将 x 的绝对值赋给 y。

Answer
# 初始端点值
x0 = 0.0  # 初始的x0值
x1 = 2.0  # 初始的x1值

# 进行20次迭代
for n in range(20):
    # 计算中点值
    x_mid = (x0 + x1) / 2  # 根据二分法计算中间值

    # 计算在(i)左端点以及(ii)中点处的函数值
    # 注意：在这里我们使用了函数f(x)的定义来计算f0和f
    f0 = (-x0**5) / 10 + x0**3 - 10 * x0**2 + 4 * x0 + 7  # 在x0处的函数值
    f = (-x_mid**5) / 10 + x_mid**3 - 10 * x_mid**2 + 4 * x_mid + 7  # 在中点x_mid处的函数值

    # 根据f0和f的乘积来确定新的区间界限
    # 1. 如果f0和f的乘积小于0，那么根必定存在于[x0, x_mid]之间，所以我们更新x1为x_mid
    # 2. 如果f0和f的乘积大于或等于0，那么根必定存在于[x_mid, x1]之间，所以我们更新x0为x_mid
    if f0 * f < 0:
        x1 = x_mid
    else:
        x0 = x_mid

    # 输出当前迭代的结果
    print(n, x_mid, f)
# Initial end points
x0 = 0.0
x1 = 2.0

tol = 1.0e-6
error = tol + 1.0

# Iterate until tolerance is met
counter = 0
while error > tol:
    # 计算中点
    x_mid = (x0 + x1) / 2

    # 在(i)左端点和(ii)中点处评估函数
    f0 = (x0**5) / 10 + x0**3 - 10 * x0**2 + 4 * x0 + 7
    f = (x_mid**5) / 10 + x_mid**3 - 10 * x_mid**2 + 4 * x_mid + 7
    
    # 更新error
    error = abs(f)

    # 判断根的位置
    if f0 * f < 0:
        x1 = x_mid
    else:
        x0 = x_mid

    counter += 1

    # Guard against an infinite loop
    if counter > 1000:
        print("Oops, iteration count is very large. Breaking out of while loop.")
        break
    
    print(counter, x_mid, error)

我们可以使用上述伪代码来实现对给定函数的数列展开。首先，我们用 for 循环来近似计算 1/0.161/\sqrt{0.16}1/0.16​ 的值，然后用 while 循环来找出满足误差小于 1×10−51 \times 10^{-5}1×10−5 的数列项数。

# 导入math模块以使用math.factorial
import math

# x的值 (这样 (1 + x) = 1.84)

# 初始化函数的近似值
approx_f = 0.0

# 使用30个数列项
for n in range(30):
    term = ((-1)**n * math.factorial(2*n)) / (4**n * (math.factorial(n))**2) * x**n
    approx_f += term

# 计算真实值和误差

error = abs(true_value - approx_f)
