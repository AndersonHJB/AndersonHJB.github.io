::: tip 前言 P10 第 5--6 行“把一些原来很有价值，但没办法接触到那么多人的知识，因为书籍带来的连接，因为如同互联网带来的规模效应，从而降低它的规模带来的边际成本。”欠通顺，待改写。

从下面的版本中选择一个你看起来合适、通顺的即可：

- **修改版本 1**：一些原本很有价值、却难以触达大量人群的知识，正是通过书籍这种媒介，像互联网一样产生了规模效应，从而显著降低了知识传播的边际成本。
- **修改版本 2**：许多原本具有高度价值、但难以大规模传播的知识，借助书籍这一媒介实现了类似互联网的规模效应，使得知识传播的边际成本不断降低。
- **修改版本 3**：很多原本非常有价值、但只能被少数人接触到的知识，因为书籍的出现，像互联网一样被规模化传播，最终让传播知识这件事变得越来越便宜。
- **修改版本 4**：书籍为知识带来的，正是一种类似互联网的规模效应：那些原本难以触达大众的高价值知识，得以低成本、大范围地传播。

## Question 13

::: tip P173第9行“以特定字符进行分割，默认空格分隔”，“默认”的前面是否应该加上“而不是”？

**修改**：`.split(sep, maxsplit)` 用于按指定字符进行分割；**如果不传入 `sep`，则默认按空格分隔**。具体来说：如果传入参数「sep」，则以参数进行分割。`.split` 分割后会返回列表。其中 maxsplit 用于控制分割几次。

:::
