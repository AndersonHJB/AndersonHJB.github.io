## 查看源地址
```shell
git remote -v
```

## 修改源地址
```shell
#[GIT URL]为要修改的源地址
 
git remote set-url origin [GIT URL]
```

## 添加源地址
```shell
#[NAME]为新的Git库源地址名
git remote add [NAME] [GIT URL]
```

##  删除源地址
```shell
git remote remove [NAME]
```
