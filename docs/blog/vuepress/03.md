## 1. 配置环境

1. 安装 nodejs: [https://nodejs.org/en](https://nodejs.org/en)
2. 安装 pnpm: `npm install -g pnpm@latest-10` [参考链接](https://pnpm.io/zh/installation)
3. 安装命令行: [https://conemu.github.io/](https://conemu.github.io/)
4. 安装截图软件: [Snipaste](https://www.snipaste.com/)
5. 安装 Git: [https://git-scm.com/](https://git-scm.com/)
6. 注册 GitHub: [https://github.com/](https://github.com/)
7. 配置 SSH: [https://bornforthis.cn/blog/2024/7month/git-ssh.html](https://bornforthis.cn/blog/2024/7month/git-ssh.html)
8. 安装 Typora: [https://typora.io/](https://typora.io/) 需购买，用于写文章的软件
9. 安装 VScode: [https://code.visualstudio.com/](https://code.visualstudio.com/) 设置我们的网站



## 2. 初始化项目

主题官网：[https://theme-hope.vuejs.press/zh/](https://theme-hope.vuejs.press/zh/)

```bash
pnpm create vuepress-theme-hope my-docs  #  my-docs 为你的项目名称
```

## 3. 网站本地启动

```bash
pnpm run docs:dev
```

本地运行，便于观察修改后产生的效果。
