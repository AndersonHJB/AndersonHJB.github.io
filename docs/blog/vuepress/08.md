**默认的官方镜像：[https://registry.npmjs.org](https://registry.npmjs.org)，切换国内淘宝镜像，访问下载更快。**

## 1. npm 设置

::: code-tabs

@tab 1. 查看源

```bash
npm config get registry
```

@tab 2. 设置淘宝源

```bash
npm config set registry https://registry.npmmirror.com/
```

@tab 3. 切回官方镜像

```bash
npm config set registry https://registry.npmjs.org/
```

@tab 4. npm 临时使用

```bash
# 上面那种设置是全局的，以后每次都会自动读取已经设置好的源，如果只是一次性使用，可以使用下面的命令
npm --registry https://registry.npmmirror.com install XXX（模块名）
```

:::

## 2. yarn 设置

::: code-tabs

@tab 1. 查看源

```bash
yarn config get registry
```

@tab 2. 设置淘宝源

```bash
yarn config set registry https://registry.npmmirror.com
```

@tab 3. 切回官方镜像

```bash
yarn config set registry https://registry.yarnpkg.com
```

:::



## 3. pnpm 设置

::: code-tabs

@tab 1. 查看源

```bash
pnpm config get registry
```

@tab 2. 设置淘宝源

```bash
pnpm config set registry https://registry.npmmirror.com
```

@tab 3. 切回官方镜像

```bash
pnpm config set registry https://registry.npmjs.org
```

:::

## 4. 常见问题

npm 修改了下载源，仍然是之前的下载源。或者下载失败、下载到某处停止不动。可以进行如下操作。

1. 清除缓存
2. 将对应项目中的 `node_modules` 文件夹以及 `package-lock.json` 文件删除。
3. 执行安装 + 需要的下载源。
