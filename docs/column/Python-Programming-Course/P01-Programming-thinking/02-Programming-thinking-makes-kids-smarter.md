当我们提到“编程”，很多人脑海里浮现的第一画面，可能就是程序员对着电脑飞快敲打键盘的样子。确实，写代码是编程的一部分。但如果你以为这就是全部，那就太小看它了。实际上，编程的精髓远不只是写出一行行代码，而更在于培养一种独特的思维方式——也就是“编程思维”。

![](https://blog.images.bornforthis.cn/docs-images/sha256/9c/9c276f85c31d25806f053025a54932354794f3a7ea77b88e4b582e22f2236d4a.jpg)

## 1. 什么是编程思维？

简单来说，编程思维是一种把复杂问题拆解、转换成更容易解决的小问题，并逐步找到答案的思维方式。这听起来也许有点抽象，那我们换个角度看：

还记得在数学课上学过的各种面积公式吗？你可以轻松算出长方形或圆形的面积。但如果我现在在纸上画了一只憨态可掬的大熊猫，让你来计算它到底占了多少面积，你会怎么办呢？

![](https://blog.images.bornforthis.cn/docs-images/sha256/38/383e151a23c71bd44465d5dc5fddd39297c0f2cc9eccecbbed4e95b58e81458d.png)

这时候，编程思维就派上用场了。

与其苦苦找寻不存在的“熊猫面积公式”，不如换个思路：想象你把这张纸均匀撒上一层小米粒。然后数一数落在熊猫图案上的米粒数量，和总米粒数相比占了多少比例。假如覆盖在熊猫身上的米粒大概占了一半，那它的面积自然也就是纸张面积的一半。

这正是一种“问题转化”的策略，我们用一个可操作、容易统计的方式（数米粒）来解决一个原本无从下手的问题（图形面积）。而这种方式，在编程世界中有个专业名字：**蒙特卡洛方法**。

很多看似神奇的人工智能算法，比如击败世界围棋冠军的 AlphaGo，其底层也使用了类似的思路：不断进行随机模拟，从中找出最优答案，使人工智能在围棋领域取得了突破性成就。

## 2. 编程思维，不只是为了学编程

也许你会想，明白这些道理，对我们日常生活有什么用呢？其实编程思维的应用远比你想象的广泛。

比如，当你学会了如何用“转化”的方式思考问题，你就更容易在生活中找到捷径；当你习惯把一个大问题拆成几步去解决，无论是写作、做项目还是学习新知识，效率都会大大提升。

这也是为什么越来越多的学校开始重视人工智能和编程课程的原因。在高中阶段，信息技术教材已经开始引入人工智能内容；一些小学、初中也陆续开设了相关课程。

重点不在于让每个孩子都成为程序员，而是帮助他们建立起面向未来的思维方式。

对于大人，说的直接一点：有些大人的思维还不如小孩，快快学起来吧！

## 3. 用科技工具，更要理解背后的原理

你有没有用过“识别植物”的手机 App？拍张照片，它就能告诉你这是什么花。这背后，其实就是人工智能领域中的**机器学习**技术在发挥作用。

又或者你曾用过美颜滤镜，自动识别你的脸、加上猫耳朵、调大眼睛。别看这些功能看似娱乐，它们涉及的技术原理和识别算法，可是当前 AI 技术的热门方向。

而当你了解了它们的基本原理，哪怕你不亲自写程序，也能成为一个更聪明、更有判断力的科技使用者。

## 4. 从“编程思维”开始，打开看世界的新方式

所以在本书的这个部分开始，我不会一开始就手把手教你写代码，而是会通过许多个有趣的小故事，带你学会**12种常用的思考方法**，掌握**10种有效的问题解决策略**。

你会发现，很多科技工具并不神秘，它们的背后，是人类设计出的聪明方法。而这些方法，你也完全能掌握。

也许你未来会学编程，也许不会。但编程思维一定会在很多场合帮到你，让你更善于分析、更敢于尝试、更有能力独立思考。

这就是编程思维的魅力——它不止属于程序员，更属于**每一个想要提升自己思维方式的人**。
