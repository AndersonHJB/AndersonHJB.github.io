在前面，我们聊到了**抽象思维**，其中一个很有代表性的例子就是：把图像、文字、声音这些多彩多样的信息，转化成数字。因为对计算机来说，**数字才是它唯一能理解的“语言”**。

但这就引出了一个有趣的问题：计算机真的能理解所有的数字吗？比如从 0 数到 9，甚至更大的数？

其实啊，计算机的“世界观”比你想象得还要简单——**它只认识两个数字：0 和 1**。没错，哪怕是“2”，它也不认识。

## 1. 计算机识数的秘密

你可能会感到惊讶：虽然我们日常使用的数字是由0、1、2……一直到 9 构成的，但计算机实际上只掌握两个基本符号——0 和 1。换句话说，当看到数字 2、3 或更大的数时，计算机实际上并不直接“认识”它们，而是通过某种方式将所有信息归结为 0 和 1 的组合。

人们习惯使用十进制系统，当我们从 0 数到 9，再到 10 时，其实就是在用数字表示数量的增减。

![十进制](https://blog.images.bornforthis.cn/docs-images/sha256/1c/1cfa5796f84f4e5fcd278f4e813c797ebef546a0258c5809d47d9d4ea7061cbc.png)

那为什么我们人类选择十进制呢？很简单，因为人有十根手指，掰着数更直观、更方便。

![二进制](https://blog.images.bornforthis.cn/docs-images/sha256/de/ded0ba18fad64e7343ca2edad73ff0735d290299b2a4f9a3570bb77f046d0760.png)

但计算机可没有手指，它的“手指”只有开和关两种状态。所以，它的数数方法很特殊，只能使用 0 和 1 这两个数字，这就是二进制。

计算机依靠物理电路中开（1）和关（0）的两种状态来进行信息表达和处理。这样简洁的二元状态不仅方便设计电路，而且能够有效降低复杂性。

## 2. 二进制与十进制的比较

在十进制中，当数字到达 9 之后就需要进位，例如 9 后面紧接着是 10。（逢十进一）

可以看这个，比较直观：0 → 1 → 2 → 3 → … → 9 → 10（进位）

反观二进制，只有 0 和 1，一旦 1 用完，自然也需要借助进位，于是“10”便出现在二进制中。然而，这里的“10”并不代表十，而是表示二进制中的“2”。同样地，二进制中的“11”用来表示十进制的 3 。正因为如此，我们日常所使用的软件和游戏，其运行的底层逻辑都是基于由无数个 0 和 1 构成的数字编码。

我们再来看看二进制的：0 → 1 → 10（进位） → 11 → 100 → 101 → 110 → 111 → 1000 …

![](https://blog.images.bornforthis.cn/docs-images/sha256/74/748db0b5e7d8fd0fb26f7676739820d3b5598b7707142369e8b20584d20a3c86.png)

二进制咋眼一看，还真像十进制。只是看起来像，因为这就好比你在看外语：单词的拼写看起来熟悉，实际意思却完全不同。

## 3. 历史的启迪：莱布尼茨与中国八卦

![莱布尼茨画像](https://blog.images.bornforthis.cn/docs-images/sha256/c5/c5ee282d7395930ed6e0ee12aee824855777f7c6073d40ae6d8996069c476770.png)

其实，二进制并非现代计算机的突然发现，它早在 300 多年前就由著名数学家莱布尼茨提出。

据记载，1701年左右，莱布尼茨创立了**二进制的数学体系**，这项发明背后还有一段引人入胜的小故事。

![八卦图](https://blog.images.bornforthis.cn/docs-images/sha256/c3/c3d8fa188e1d31e4aefb34ec0890d57f8a9985ea94482e2d302ffff6a6cb9228.png)

当时，一位传教士向中国传播文化，对中国古代的“八卦”颇有研究。八卦图由“乾、坎、艮、震、巽、离、坤、兑”八个符号组成，每一卦都是由三根横线构成，而这些横线只有两种状态：连续或断开。

这位传教士就在写给莱布尼茨的信中提到这个八卦，信中说到：每一个卦由三条横线组成，横线要么是**完整的**，要么是**断开的**。

1. 完整的线 → 可以看作“1”

2. 断开的线 → 可以看作“0”

巧妙的是，如果将连续的线视为数字“1”，而断开的线看作“0”，那么每一卦便自然转化为一个由 0 和 1 构成的数字串。

比如：

- “乾”卦（三条完整的线）→ 111
- “坤”卦（三条断开的线）→ 000

这不就是**三位的二进制编码**嘛！

莱布尼茨高兴坏了，觉得自己跟几千年前的中国古人产生了神秘的“心灵共鸣”，他甚至在论文里引用了八卦图，来印证自己对二进制的构想。

不过，当时的科学界并不是很在意这个发明，都觉得这二进制能有啥用啊？

这个问题，或许当年的莱布尼茨回答不出来，但是今天，我们可以帮他回答了：**二进制，是一种特别适合计算机的语言**。



## 4. 为什么选择二进制？

总结起来，二进制系统之所以成为计算机的首选，主要有以下三个原因：

### 4.1 完备的数值表示 

尽管只用 0 和 1 两种符号，二进制依然能表达所有数字的信息。因为只要愿意多加几位，0 和 1 就能拼出任意大小的数字。比如二进制的 “101” 就表示十进制的 5。（省子版：用两个数字，就能表示所有的数字）



### 4.2 数学运算的普适性

![](https://blog.images.bornforthis.cn/docs-images/sha256/01/016db0c479c75523da54b6fec814f104dc85984e49af8205e3801eaefc4eafea.png)

~~所有十进制的运算都可以转换为二进制操作，而不牺牲计算能力。~~ 既然所有的十进制都可以转换成二进制，那么十进制的所有数学运算，二进制都可以。（省字版：可以做所有的数学运算）

### 4.3 电路实现的简洁性

![电子元件](https://blog.images.bornforthis.cn/docs-images/sha256/c0/c0a941e13e1860f05780690f646a08e7193c5980cea53ba60910d3936811376d.png)

在硬件层面，采用简单的“开/关”电路设计远比实现十种状态（比如灯光的九个亮度级别）来得容易和稳定。（省字版：对电路来说，**二进制更简单**）

这种追求最简化解决方案的思路，不仅在硬件设计中得到体现，同样也深深植根于编程和软件开发的实践之中。

上面我们进行了集中的总结，接下来我们来看看实际的例子。

计算机的核心——芯片，其实就是由无数的电子元件构成的小电路。电路工作原理也很简单：电流通过（通电）就是1，不通过（断电）就是 0。

你家里的开关灯，就是最直观的例子：

- 灯亮 → 表示“1”
- 灯灭 → 表示“0”

![不同亮度的灯](https://blog.images.bornforthis.cn/docs-images/sha256/d1/d17547727f5274d89247f6614e15f54daec440933b56ef0b795d3306a9652b3d.png)

如果用十进制呢？一个开关只能表示两个状态，那就不够用了。为了表示从 0 到 9 的十个状态，你得配出十种不同的亮度，比如弱光、中光、强光……可想而知，这既麻烦又容易出错。

相反，**二进制只要两个状态，既稳定又省事**。

所以，计算机的世界选择了最简单、最可靠、最适合电子设备的方式：**只说“是”或“否”，只认“通”或“断”——也就是“1”和“0”**。

## 5. 编程思维中的“简洁原则”

其实，计算机选用二进制的原因，也反映了编程中一个非常重要的原则：**简单就是高效**。

你会发现，越是高级的程序员，写的代码反而越简洁。不是因为他们偷懒，而是他们更擅长把复杂的问题，转化成简单、可执行的结构。

而这正是我们在学习编程时，一直要练习的能力。当然，还是要注意：不是越简洁越好，一切讲究适当。

## 6. 彩蛋问题：生活中的“二进制”

总的来说，计算机利用极其简洁的二进制系统实现复杂的运算与处理，这种设计理念充分体现了“用最少的资源实现最大的功能”的智慧。

既然你已经了解了什么是二进制，那不妨动动脑筋：你能不能在生活中找出一些 **只用两个状态表示信息** 的例子？比如红绿灯？开关？旗语？

下一章，我们要接着探索一个新问题：如果计算机只能开关表示0和1，它是怎么完成像加法、乘法这样的计算的？这背后，其实藏着一种叫做“**逻辑运算**”的神奇工具。

## 7. 旗语「选读」

在写这部分的时候，我亲爱的老婆都进行了阅读。问我什么是“旗语”，我就想着马上补充一下。供你们选读～

### 7.1 🚩什么是旗语？

“旗语”是一种**用旗子传递信息的方式**，最早常用于军队、船队之间通信。想象一下，在没有电话、无线电的年代，两艘船隔着远远的海面，要告诉对方“快来帮忙”或者“发现敌人”，怎么做呢？

这时候，船上的人就会拿出两面小旗子，根据事先约定的动作和方向，**摆出不同的姿势来表示字母或命令**，就像一种“动作语言”。

比如：

- 两只手举成“V”字，表示字母“A”
- 两只旗子水平伸直，表示字母“B”

每一种动作都是一种“信号”。人们用望远镜一看，就能“读”出对方在说什么。

### 7.2 🎯为什么说旗语是“二进制”的？

旗语虽然看起来花里胡哨，其实背后的原理就很简单：

1. 👉 每个手里一面旗子，每次只能选择一个“姿势”
2. 👉 每种姿势要么是 **有效信号**（有意义），要么是 **无效信号**（没意义）

换句话说：**要么表示什么（1），要么什么也不表示（0）**。

甚至每面旗子本身也可以看成“有旗/无旗”，一种二选一的状态。

所以，旗语也是一种 **只用两种状态（动作或没有动作、旗子或没有旗子）来表示信息的方式**，本质上和二进制的“0”和“1”非常相似。

如果你感兴趣，还可以试试和小伙伴自制一套“旗语暗号”系统，用手、旗子、纸片都可以——玩一玩，说不定就更理解“二进制思维”了！ 😄
