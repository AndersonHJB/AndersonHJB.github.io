在前面，提到了计算机只使用两种数字——0 和 1。虽然这种“二进制”跟我们日常使用的十进制不同，但它已经足够让计算机开始运算了。

可你有没有想过，光有数字是不够的。想象一下，小学刚学完1到9之后，是不是紧接着就要学加减乘除？同理，计算机在掌握了0和1之后，也必须掌握一套适合自己的“运算规则”。

你可能会问：“运算规则不就是加减乘除吗？这还有什么花样？”其实，计算机用的并不是我们平时的那一套。它有一套**专属的运算体系**，这套体系更适合它的“电子大脑”来理解和执行。

虽然传统的四则运算看似简单，但在电子电路中直接运用其实并不合适。试想一下，用不同电压来代表各个数字，既复杂又容易受外界干扰。事实证明，电路中的电流状态只有两种：开和关，这样的特性决定了我们必须采用与众不同的运算方式。这时，逻辑运算应运而生，它完全利用“开”和“关”来完成各种操作。

所以，你应该猜到了。这一套规则，叫做**逻辑运算（Logical Operation）**，也叫做布尔运算。我们本书后面的 Python 部分也会讲解到布尔型，里面也有逻辑运算符。

## 1. 一组灯泡就能理解的“逻辑思维”

我们来玩个小游戏，换一个身份——假设你现在是计算机中的一个电子元件。计算机内部的一切，最终都归结为两个状态：“通电”或“断电”。我们用灯泡来代表这两种状态：**亮**表示有电，**灭**表示没电。

### 1.1 “非”运算（NOT）

![非运算](https://blog.images.bornforthis.cn/docs-images/sha256/81/8153d66994d6861972d0931bd71b022fdd3958bbc0b7ad966e9122fce0fae5cc.png)

你看到旁边小伙伴的灯泡亮着，你就把你的灯关掉；他灯泡灭了，你就打开你的灯。总之，就是**跟他反着来**。这就是“非”运算——这样做就好比对输入信号做了“反转”，不论是什么，就返回它的反面。



### 1.2 “或”运算（OR）

![或运算](https://blog.images.bornforthis.cn/docs-images/sha256/72/72cec8b8ccef09677bd320c96269365474fab484dadf605d6dc28248d41b411f.png)

现在，对方有两个灯泡。只要**其中有一个是亮的**，你就把你的灯也点亮；如果他那两个都灭了，那你就不点灯。这叫“或”运算，只要有一个满足，就点亮。

## 1.3 “与”运算（AND）

![与运算](https://blog.images.bornforthis.cn/docs-images/sha256/5d/5d47093a4b71757e92bed7dce879c3913c5cb1d8ca6f6d568b7b0b33b5d5df87.png)

还是两个灯泡。这次你得严格一点：**只有当对方两个灯泡都亮着**，你才点亮自己的灯；否则，灯就保持关闭。这就是“与”运算，讲究“全部都满足”。

![乔治·布尔](https://blog.images.bornforthis.cn/docs-images/sha256/cf/cf61e875649b19adc70c627bce444714cada0b2baa3f19dcb9758410d1f31f70.png)

这三种操作构成了逻辑运算最基础的部分，而完整的逻辑体系正是由数学家乔治·布尔提出，因此这种运算方式也被称为 **“布尔运算（Boolean Logic）“** 。布尔最初提出这套理论时，虽然在当时并没有受到广泛关注，但它后来成为电子计算的基石。

其实，计算机的很多最基础的计算，都是基于这三种逻辑规则来完成的。

## 2. 布尔的“逻辑革命”

![克劳德·香农](https://blog.images.bornforthis.cn/docs-images/sha256/50/504a9cfe89f0019f0631ce37be9a596f2c7dad974a7ab83be2a64d41337a2ebd.png)

那么，为什么现代计算机会舍弃传统的加减乘除，而选择这种看似简单却极为高效的逻辑运算呢？

因为，乔治·布尔生活在19世纪，他的逻辑体系起初并没有被广泛应用。但在多年后，一位充满好奇心的科学家重新点燃了这套理论的火花，这人就是——**克劳德·香农**。

香农是一位集天赋与幽默于一身的天才。别看他外表严肃，他发明的东西一个比一个有趣：电动跳跳鞋、自动迷宫老鼠、自己会把自己关上的“无用机器盒子”……可别小看这些玩意儿，背后都是科学思维在闪光。

真正让香农被奉为“信息时代奠基人”的，是他在研究电路时提出的一个划时代的想法：**如果电路的通断可以用 0 和 1 表示，那是不是可以用布尔运算来控制这些电路的行为？**

这个念头不只是天马行空。他立刻动手设计了模型，证明了**布尔逻辑可以直接用于控制电路的开关，从而执行各种计算任务**。

## 3. 为什么不是加减乘除？

你可能会疑惑，既然加法那么常见，为什么不直接在电路里实现加减法呢？

回顾早期的实验：若用电压高低来表示数字：1 伏表示数字 1，2 伏表示 2……但一台计算机每秒要处理成千上万种数据，如果每种数字都靠电压来表示，那就需要成百上千种精确的电压，稍有干扰就可能出错。并且计算机在执行复杂运算时或旁边有其他机器的干扰，电压也很容易出现偏差，计算就会出错。所以，加减乘除法用在计算机电路里不太合适。

当时人们还尝试过：建立三进制计算机，结果不仅电路复杂，还极易出错。

逻辑运算就不一样了。它只需要区分“有电”与“无电”，对应的正好就是 1 和 0。就像我们之前提到的小灯泡，要么亮，要么灭，没有中间状态，这让计算机的电路既稳定又高效。

所以，布尔运算 + 二进制，简直就是为计算机量身定做的“黄金搭档”。

而在我们日常编程中，虽然看不到底层电路中灯的闪烁，但正是这种“开和关”构成的基本逻辑，使得计算机能够高效地将复杂问题转化为简单的信号处理任务，从而实现各种功能。简单的二进制和逻辑运算背后，正隐藏着一种强大的**问题抽象**和**转化思维**，这是所有编程思想的重要组成部分。

## 4. 香农的贡献：将理论化为现实

香农在读硕士的时候，看到了布尔提出的布尔运算。他觉得，这套规则用到电路里简直是太合适了。

你想，咱们前面说布尔运算的时候，是拿小灯泡的亮和灭打比方的，其实，小灯泡的亮和灭不就是计算机电路里面的有电和没电吗？

![基础电路](https://blog.images.bornforthis.cn/docs-images/sha256/1f/1f01b1e9a84ae356d4af0aa2c28109f1b7351c94aa87cbf51aeafa1a1a19ca10.png)

所以，布尔运算的规则再加上二进制，正好就可以让计算机处理信息。当然了，香农也在二进制和布尔运算的基础上构建了一套更复杂的体系，好让计算机能够进行各种各样的运算。

需要注意的是：在香农生活的年代，还没有真正意义上的电子计算机。

他提出的，是一套可以把逻辑运算用在电路上的方法。而这一思想，直接成为了现代计算机的基础框架。

之后，计算机的硬件设计、电路逻辑、信号处理、乃至我们今天用的手机、电脑，都是建立在香农这套理论之上的。

今天我们使用的数字通信方式（包括你正在听的音频、打的电话、上的网）也都离不开香农的那套体系。他所提出的“用二进制+逻辑运算处理电信号”的方法，成为信息时代的核心支柱。

## 5. 回到编程思维

你可能会问：这些不是底层硬件的事吗？跟编程有什么关系？

那我们就得重新提一下“**问题转化**”这件事。

计算机只识别电流的“开”与“关”。编程的本质，就是要**把我们的问题转化成一系列“开或关”的指令组合**，也就是一串 0 和 1，然后用逻辑运算规则去一步步处理它们，最终得到结果。

换句话说，**逻辑运算不仅是计算机运行的基础，也是编程思维的一种核心体现**。它教会我们如何把复杂的问题，拆解为最基础的判断与操作。
