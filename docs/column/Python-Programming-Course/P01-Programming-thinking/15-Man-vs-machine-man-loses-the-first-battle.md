在日常生活中，我们时常会听到“人工智能”“AI”等词汇。这些高科技术语背后，隐藏着一场又一场令人着迷的较量：**人类与计算机的对决**。这种对决形式多种多样，往往以某种游戏为战场，双方在规则之内一较高下——不为娱乐，而是为了探寻智慧的边界。

如今再回顾这些比赛，我们发现一个明显的趋势：计算机接连战胜人类冠军。在游戏的世界里，难道我们真的已经全面落后于人工智能了吗？答案并非那么简单。这场“人机争锋”的故事，早在数十年前就已经悄然拉开序幕。

## 1. 早期赛场的硝烟

事实上，关于人机对抗的讨论并非近几年才开始，而是可以追溯到三十多年前。当时，这种较量不仅限于少数游戏，而是涵盖了扑克、象棋、围棋乃至各种电子游戏。不同于日常中轻松娱乐的游戏，这里的对弈通常由各领域的顶尖高手和专为此目的设计的计算机系统进行较量，战场因此显得格外引人注目。

特别值得一提的是棋类游戏。

![中国象棋](https://blog.images.bornforthis.cn/docs-images/sha256/3b/3b819714f898aa9a46f3ef7e1ddb19cca7d8a2f574c08be99057290740a3ce57.png)

任何一局棋局，都充满了极其丰富的变化可能性。以中国象棋为例，其变化种类之多，甚至超过了 10 的 100 次方。正因如此，不论是人类还是机器，每一步决策都承载着巨大的挑战，成为智力和算法较量的绝佳试金石。

早期的一部分科学家曾设想：如果一台计算机能在国际象棋或围棋等棋类比赛中击败世界级高手，那么这台机器便可被认定拥有“真正的智能”。正是在这样的大背景下，棋类比赛逐渐成为人机对抗的重要舞台。

## 2. 英国跳棋的启示

![英国跳棋](https://blog.images.bornforthis.cn/docs-images/sha256/ca/ca8590a9837e04728b5c02df07efe081397f962a11211af6fa20c8b4e1876234.png)

在众多对弈项目中，英国跳棋无疑为这一领域提供了一段极富传奇色彩的历史。不同于我们平常所见的跳棋，英国跳棋的棋盘设计颇似国际象棋，其走法也带有独特规则——棋子不仅可以前进，还能跳跃对方棋子以完成“吃子”。

![数学家·马里恩·汀斯雷｜英国跳棋王](https://blog.images.bornforthis.cn/docs-images/sha256/61/618a1d593a95e068c9fd9b2c4792f20f1c38b43112e8d569fe635ca8db141c7c.png)

在这个领域中，有一位名震一时的棋手——数学家**马里恩·汀斯雷**。他不仅在英国跳棋界久占鳌头，整整四十年鲜有对手问鼎，还被尊称为“英国跳棋王”。然而，他的霸主地位最终被一款名为**奇诺克**的计算机程序所打破。

第一次交锋发生在1990年的一场表演赛上。当时，奇诺克的设计者信心满满，宣称这台机器能够预见未来二十步的可能局面。然而，经验丰富的汀斯雷以 4 比 2 取得了胜利，这场较量也让人们看到了人类智慧的魅力。

几年之后，1994年，两位对手再次站上赛场。这一次的比赛局势却截然不同：双方在六局内均未分出胜负，决胜局时，汀斯雷突然因突发的身体不适中断了比赛。经过后续检查，发现他已被诊断出晚期癌症，迫使他不得不退出竞赛。不久之后，这位传奇棋手离开了人世。由此，奇诺克不仅夺得了英国跳棋冠军的桂冠，还成为了世界上第一个在该领域立下汗马功劳的机器人。

## 3. 计算机胜势背后的秘密

为何计算机能在如此复杂的竞技中逐步占据上风？

核心原因在于其超凡的计算和预测能力。普通人类棋手可能只能大致预估接下来的八到十步，而先进的计算机程序如奇诺克则能够预测二十步之后的局面。

假如你在和同学下棋，当前这一步就你有5种走法，每种走法对手也有5种应对方法，如果你想考虑清楚每一步的后果，就要考虑25种不同的情况，25种，听着好像不太多对吧？别着急，这只是考虑当前这一步的呢。

我稍微带你计算一下：如果奇诺克真的能提前思考20步，它要思考多少种可能性呢？**你可以拿一张纸，在上面写一个1，然后在后面写28个0，这就是奇诺克要考虑的可能性了**。

在这巨量的可能分支中，计算机要找到最优解并不简单，但由于运算能力不断提升，计算机能更快、更稳定地完成这样的工作。这也让它在棋盘上的策略部署上，比人类选手更具有**全局性**和**精确度**。——这正是计算机能在密集信息中迅速锁定最佳策略的原因。

它靠的是什么呢？一种名为 **“蒙特卡洛树搜索”** 的策略。

## 4. 把思考变成一棵树

蒙特卡洛树搜索算法就像是一棵不断分叉的智慧之树，从根部一层层地展开每一种可能，直到找到最佳路径。这样的搜索方式，不仅被用在跳棋上，后来也成为国际象棋、围棋乃至 AlphaGo 等系统的核心算法。

（**省字版｜便于理解**：这种算法需要一层层一步步地进行，就像一棵大树，主干会分成细一些的枝干，每一条枝干又继续分成更多更细的枝干，一直分到最末端的树叶，所以人们就给这种方法起名叫蒙特卡洛树搜索。）

这种逐层分解、逐步推演的思维方式被称为**结构化思考**，对于日常生活同样很有用。比如，新学期伊始，你要组织一场班级才艺晚会，怎么 **分工（分配任务）** 最合理？简单粗放地一拍脑门就安排：得有人给演员们准备服装道具，得有人布置教室，好像还得找人去买点小零食水果。感觉怎么样？——听起来就没有条理，这样分配任务肯定容易疏漏。

而使用结构化思考，就可以这样：可以先把任务拆成“演员及节目准备（表演任务）”和“会场布置（班会会场布置）”两大块，在每块之下再细分——比如分成服装道具、主持人训练、教室布置、小零食采购、音响调试等等。像这样逐层细分，就更不容易出现遗漏或混乱。

            1. 可以继续细分……
            2. 可以继续细分……
        2. 服装道具准备；

            2. 可以继续细分……
        3. 还有主持人排练等等。
    2. **班会会场布置**：
        1. 布置教室桌椅；
            1. 可以继续细分……
            2. 可以继续细分……
        2. 购买小零食；
            1. 可以继续细分……
            2. 可以继续细分……

再大白话一些：其实就是类似平时用的思维导图，有兴趣的读者可以试一试用一用。

这样一类类、一层层地拆分任务，就比东想一个、西想一个要更有条理，更不容易遗漏。

## 4. 迈向全球棋战的新时代

![国际象棋](https://blog.images.bornforthis.cn/docs-images/sha256/dc/dc957c4c5686b7a914598ab408f643c4f8a9687299c4ea6d6306aff2b37802ac.png)

**棋盘换了，但战火未熄！**

从英国跳棋这一战来看，也许会有人说，玩英国跳棋的人不算多，真正的高手数量也有限。

所以，随着人机对弈的经验不断丰富，科技工作者开始将目光转向更具普及性的竞技项目——国际象棋。相比英国跳棋，国际象棋吸引了更多爱好者，高手云集的赛场竞争更加激烈。而国际象棋不仅在棋子的数量和种类上更为复杂，其规则的多样性也对计算机的处理能力提出了更高的要求。正因如此，国际象棋成为了新一代人机对决的热门选项，而未来的较量将为我们揭示更多智慧的碰撞与科技的进步。

在这一系列人机大战的故事背后，我们既能看到人工智能不断突破的进步，也能感受到人类智慧不懈追求完美的精神。更多激动人心的对决与发现，还将陆续在后续章节中展现，敬请期待。
