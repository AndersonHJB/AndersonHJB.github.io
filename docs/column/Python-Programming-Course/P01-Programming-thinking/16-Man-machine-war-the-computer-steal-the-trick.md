人工智能的进化之路，就像一场接一场的战斗，而棋盘——恰恰成了其中最精彩的竞技场。继在英国跳棋中尝到了胜利的果实后，计算机开始瞄准两个更难啃的“硬骨头”：国际象棋与围棋。

这两种古老而深邃的棋类游戏，不是随便能征服的。原因很简单：它们的变化实在太多了。跳棋的可能性已经足够庞大，而国际象棋的局面总数，被估算为 10 的 150 次方。至于围棋呢？更夸张——超过 10 的 300 次方！即使是运算能力再强的机器，面对这种天文数字，也难以用“穷举法”走遍所有路径。

可正因为挑战如此巨大，才更激发了科学家的斗志。

## 1. 第一回合：蓝色巨人的进击

![深蓝 Vs. 卡斯帕罗夫](https://blog.images.bornforthis.cn/docs-images/sha256/b3/b3b5ac80d98a2b48620fc6d2013b9adc9830bbe767312a3972641cd52abb330a.png)

国际象棋这场战役，机器方派出了一位响当当的选手——**深蓝（Deep Blue）**。这台由 IBM 打造的超级计算机，是科技智慧的结晶，专门为了应对最顶尖的人类棋手而生。

而它的对手，更是名副其实的“棋王”：**卡斯帕罗夫**。这个名字在国际象棋界无人不知。他8岁学棋，18岁便成为最年轻的国际象棋特级大师之一，几乎横扫所有对手，甚至曾独自一人击败由全世界5万棋迷组成的“世界队”。

1996年，人机首次交锋——人类胜出。卡斯帕罗夫以其深厚的棋力击退深蓝，捍卫了人类的尊严。

可 IBM 并未认输。他们对深蓝进行了系统升级，让它变得更强、更聪明，甚至改了个新名字：“**更深的蓝（Deep(er) Blue）**”。这位“蓝骑士”可以在每一步思考中，计算比人类多出成千上万的变局。

1997年，升级后的“更深的蓝”再次出战。这一次，卡斯帕罗夫意外落败。赛后他提出再战一局，但科学家们并没有给卡斯帕罗夫复仇的机会，因为在科学家看来，再比下去，人类也是必败无疑。

有可能你会想到，这些科学家是不是心虚了呢？他们是不是怕计算机会输，所以不敢继续比下去啦？诶，还真不是。接下来计算机在更有挑战性的**围棋战场**上，战胜了人类，说明计算机取胜绝不是靠运气。

## 2. 第二回合：黑白世界的智慧博弈

![围棋](https://blog.images.bornforthis.cn/docs-images/sha256/9b/9b09ebb43336295d667cd055cb1d51afc9b9195f46f1ce6af725eb508233b3a6.png)

如果说国际象棋是一场策略之战，那么围棋就是一场宇宙级的对弈。围棋的棋盘更大，变化更复杂，每一步落子都有无数种可能。过去人们普遍认为，围棋太复杂，计算机永远不可能战胜人类顶尖棋手。

直到——**AlphaGo** 登场。

由谷歌旗下的 DeepMind 团队打造的 AlphaGo，不再像深蓝那样试图穷尽可能性，而是采用了截然不同的路径：**学习人类，超越人类**。

怎么说呢？计算机不可能模拟围棋的全部棋局，“深蓝”和 Alpha Go 是怎么打败人类顶尖棋手的呢？咱们一起用编程思维一步步分析一下这个问题。

1. 我以 Alpha Go 为例，既然 Alpha Go 不可能考虑所有的情况，那就可以缩小思考的范围。接下来，问题就变成了，Alpha Go 要考虑哪些情况呢？

2. 当然是考虑对手会考虑的情况，对吧？Alpha Go 的对手呢，就是人类围棋大师。所以 Alpha Go 就有了应对方法，去学习人类大师的下棋方法。要说 Alpha Go 还真是好学，它一下就学习了人类大师的至少 **3000万种下棋的走法**，对人类大师常用的下棋策略非常熟悉了。

3. 但光做到这一步还不够，围棋棋局变化特别多，只会这些固定的套路肯定是不行的，于是 Alpha Go 又干了一件事，那就是练。当然了，没有人能和 Alpha Go 对练，于是它就自己和自己练，在下棋的过程中呢，既模仿人类大师的下法，同时又加入一点点变化。

不知道你发现没有，这和人类棋手学习下棋的过程很像，也是先学习、模仿前辈大师的下法，然后大量地练习，慢慢地形成自己的下棋风格。但在这个过程中，Alpha Go 有几个人类不具备的优势。

首先，Alpha Go 是计算机，它可以在短时间里下很多很多盘棋。人类棋手可能一辈子也就下几千盘棋，而 Alpha Go 呢，自己和自己下了上千万盘棋，这么看来，Alpha Go 可是相当勤奋的。

除了勤奋，Alpha Go 还有**超强的记忆力**，它可以记住每一盘棋里每一步棋是怎么走的，以及走完之后结果怎么样，这可是人类的记忆力做不到的。

经过这一番学习和练习之后，Alpha Go下棋的技术终于超越了人类大师。在这里我要告诉你，Alpha Go 学下棋的这套方法，你在学习新东西的时候也能用上。

比如说，你自己利用 hexo 开发了一个静态网站。然后看到很多人用 hexo 做了二次开发以及美化，此时最好的方法就是：照着 hexo 的前辈们的教程先实现复刻出功能、美化效果。虽然你可能不太能理解这些二次开发的代码和逻辑，但也没关系，这就和 Alpha Go 模仿人类大师下棋一样。

等你熟练掌握了这些二次开发的套路或者结构化流程后，就要**大量地练习**，你可能会觉得很枯燥，但随着碰到的情况越来越多，你渐渐就能理解每个二次开发背后的原理了。

而且，你很可能会发现原来前辈们的二次开发中还有**不完善的地方**或者不是很符合自己的需求和想法。按照自己的方法，你完全可以做得更好。这样一来，你说不定也能成为编程大师。

![柯洁 Vs. Alpha Go](https://blog.images.bornforthis.cn/docs-images/sha256/c3/c35d1aa5c8c115888867c1204c1c8ea8cee28985cc3b03ec9aa0c8b40aa5bed1.png)

如果你对围棋感兴趣，那也许听说过它打败了世界围棋冠军**柯洁**。

但实际上，在此之前，它已在一个围棋网站悄悄挑战了几乎所有世界顶级选手，创下**59战全胜**的惊人纪录。人类棋手，无一胜绩。



## 3. 机器为何能赢？

这部分其实前面已经说了，不过这里**言简意赅**一下。让你迅速理解，我拍你一顿狂读之后不知道重点是啥。

计算机并没有“看到”全部的可能性，但它聪明地选择了哪些“**值得思考**”。就像你学习新技能时，一开始模仿高手，后面不断练习、试错、优化——AlphaGo 也是这么做的。不同的是，它的**速度快、记忆强、不疲惫**。

人类棋手几十年才积累的经验，AlphaGo 几周内就掌握了；人类容易遗忘的细节，AlphaGo 永远牢记。它既勤奋又专注，而这些正是通往顶峰的关键。

## 4. 编程智慧的启示

你可能会想，这些故事只是关于棋类游戏吗？其实不然，它背后展示的，正是**编程思维与算法智慧**的巨大威力。

无论是棋子在格子上跳跃，还是围棋落子于广袤棋盘，计算机胜利背后都离不开“聚焦关键、复制并超越”的思路。

比如 AlphaGo 的学习方式，就和我们日常学习其它学科一样：**先模仿、再练习、再优化**。

我在给学生上课时，就给学生说过：初学者应该从套用高手的“公式”开始，即使不懂为什么，先“照做”也没关系。随着练习增多，自然就能理解，甚至发明出更简洁的解法。

~~人类学习新技能，也可以先参照前辈总结的套路，再通过大量练习去体会内在奥妙。~~



## 5. 智能的胜利，也是人类的胜利

当 AlphaGo 完成围棋征服后，DeepMind 团队又将目标转向实时战略游戏，并再次击败职业选手。

人们不禁开始担忧：既然机器连围棋、电子游戏都赢了，将来是不是会取代我们？如果机器人无所不能，未来会否对人类构成威胁？

其实大可不必担心，AlphaGo 能有今天，靠的正是人类工程师与科学家的智慧。每一次人工智能的飞跃，背后都藏着成千上万个聪明脑袋的努力。

**省字版**：正因为背后有我们——那些设计程序与算法的科学家，才让计算机得以迈出一小步，而人类智慧却在其中大幅提升。
