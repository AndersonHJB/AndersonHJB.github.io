你有没有试过自己下厨？哪怕是最简单的一道炒鸡蛋，一开始也可能让你手忙脚乱：鸡蛋没打匀、葱花飞出碗、锅太热差点糊锅……最后一道菜做下来，时间过去了五六分钟，感觉自己像经历了一场战斗。

你可能会说：“我就是不熟练嘛！”当然，熟练度很重要。但今天我想告诉你：做饭慢，可能还有一个原因——**你没用上“并行计算”的脑子**。（并行计算思维）

听起来有点酷对吧？先别急着追问，我们先换个角度，从天马行空的“寻找外星人”说起。

## 1. 当无线电遇见火星信号

100多年前，无线电刚被发明不久，科学界就开始畅想：如果我们能把电波送出去，那会不会也能接收到外星文明发来的信号？

![](https://blog.images.bornforthis.cn/docs-images/sha256/85/85932ebeeef3be7097e2e3b8801158436e5ed295eb99714bd41fe30bacfe4afc.png)

传奇科学家尼古拉·特斯拉当年在搞实验时，还真以为自己听到了火星发来的问候。第二年，无线电发明人古列尔莫·马可尼也声称，他的设备接收到了来自宇宙的“电报”。虽然后来的研究表明，这些信号很可能只是误判，但科学家们从此便踏上了**搜寻外星人**的道路。

不过，无线电波属于电磁波家族，较可见光波长更长，能穿越尘埃与大气层，所以科学家们并未气馁。

![阿雷西博望远镜](https://blog.images.bornforthis.cn/docs-images/sha256/7f/7fd3f5d595a3daa21ddb86e9f68bf8d7c29f06d8aeea9657736a1a27eb8dcc7c.png)

科学家们建起了巨大的射电望远镜，比如那座外形像铁锅的“阿雷西博望远镜”，直径有350米那么大——差不多能放下一百层楼。只要有外星信号飘进来，它都能接住！

![](https://blog.images.bornforthis.cn/docs-images/sha256/4c/4c034dbfca1b2e0cfb27eb38c0ff5352c092780244d8a3c9f02711415b69b37a.png)

然而，问题很快来了：**信号太多，处理不过来**。

你可以想象一下，就像你一秒钟就收到了几千封信，哪怕是24小时不睡觉，也根本看不过来。于是科学家们想到用**超级计算机**来帮忙。但——超级计算机价格昂贵，政府又不愿意出这笔钱，毕竟“找外星人”听上去不像是当务之急。

那怎么办？科学家们总得想个办法。

如果是你，你会怎么办呢？号召全国热爱外星人的同胞团结起来，给政府施加压力？还是干脆号召大家捐钱给科学家，帮助他们租一台超级计算机？

这些方法都不错，但是跟下面的这个方法一比，可就差远了。

## 2. 一场家用电脑的大联欢

有个叫**戴维·格迪**的计算机科学家，在一次聚会上灵光一闪：**既然大家都有电脑，为什么不让全世界的家用电脑来一起找外星人呢？**

你想想，在20世纪90年代的时候，互联网已经在世界上比较普及了。有许多人家都买了家用计算机。这时候，只要制作一个分析外星人信号数据的软件，把这个软件装在你家的计算机里。然后，再把望远镜接收到的信号通过网络传到你的计算机上。等你睡觉了计算机闲着没事的时候，就可以分析这些信号了。

![SETI@home](https://blog.images.bornforthis.cn/docs-images/sha256/b0/b023518a36c20db91255eec15a14946a5f9968165d4f19d31046d5abdc97cd56.png)

于是，他和一群朋友开发了一个叫做“**在家寻找外星人**（SETI@home）”的程序——只要你愿意，就可以把它装到你家的电脑上。白天你用电脑干自己的事，晚上睡觉了，电脑闲着，它就会自动开始分析外星信号。

从1999年开始，这个项目一度火遍全球，有520万人参与。到2013年，它的总运算能力已经能和世界上最强的超级计算机媲美。

为什么这么厉害？

戴维把一个大任务拆分成很多可以同时进行的小任务，让很多计算机同时运算，最后就顺利解决了问题。这种方法，在计算机科学领域，算是**并行计算**的一种。所谓并行，就是同时进行的意思。

省字版：**并行计算**——把大任务拆成许多小任务，然后**同时分给很多人（或者很多电脑）去做**，效率自然就高了。

那你肯定要问了，找外星人和做饭有什么关系呀？别着急，我们回头看看，如何用并行计算**提升做饭的速度**。

## 3. 炒鸡蛋，其实也能并行

听起来很高大上？其实炒鸡蛋也能用这个思路！

我们来算一算普通炒鸡蛋的步骤：

1. **准备食材**：打鸡蛋（10s）、切葱（20s）、搅拌葱花和鸡蛋（30s），总共大概1分钟；
2. **热锅**：花1分钟把油烧热；~~烧油需要1分钟；~~
3. **下锅翻炒**：把蛋炒熟，大概3分钟。

如果你按顺序一步步做，需要5分钟。

但如果换个思路呢？**边准备食材边加热锅**，时间就可以重叠。也就是说，你可以先把锅放上灶台开火，然后一边让锅热着，一边打蛋、切葱、搅拌。准备好之后，锅也差不多热了，直接炒！这样一来，总共只需要4分钟。

这就是**并行炒蛋法**！

而最开始那种按部就班、一项接一项完成的方式，就是**串行计算**——每一步都要等上一步做完，虽然简单，但效率不高。

举个具体例子：所谓串行的意思，就像是往糖葫芦上穿山楂果。只能按顺序一个一个地穿，前一个没穿好，后面的就得等着。串行计算看起来很省心，但通过前面的例子你肯定也知道了，它会浪费时间。

## 4. 超级计算机的秘密

![](https://blog.images.bornforthis.cn/docs-images/sha256/9e/9eb32dbe324f5058c70f553e1b7cc36634cb24b7bd6f1ef879cc0b7f6358141f.png)

现实中的超级计算机，现实生活中的超级计算机之所以威力巨大，也是因为它也采用了并行计算。

我们一般的电脑里有8个、12个计算核心，而超级计算机里就有**几百万个**。

超级计算机正是靠着**几百万个核心一起工作**，才能在极短时间内完成海量运算。一个复杂的大问题，拆成成千上万块的小问题，每一块分别送给不同的计算核心处理，运算速度自然飙升。

想想看，日常生活中还有哪些场景可以并行优化？是同时听音乐和做作业？还是一边听课一边预习？

说到这儿，你可能兴奋地想加入寻找外星人的行列。可惜“SETI@home”项目已经暂停了，阿雷西博望远镜也因为年久失修而垮塌。但没关系！科学探索永不停歇，现在还有一个叫“Folding@home”的项目，正在邀请大家帮忙研究病毒蛋白质的结构，为人类攻克疾病出一份力。

## 6. 小结

一开始，你或许以为**并行计算**只是科学家才用得到的复杂概念。但其实，只要你愿意动动脑，它就在你炒鸡蛋、写作业、做项目的生活里无处不在。

用并行的眼光看世界，你会发现——时间和效率，真的可以被你掌控！
