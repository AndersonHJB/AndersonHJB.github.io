有时候，做选择真的是一件令人头大的事。

你可能遇到过这样的场景：过生日，家里人让你从几个玩具里挑一个。每个看着都眼馋，每个都想带回家，怎么办？纠结、犹豫、反复横跳……最后还可能选了个最不想要的！

别着急，今天我们就来学习一种来自编程世界的**聪明决策法**，让你以后遇到选择题，就像打游戏开挂一样轻松！

## 1. 「情景剧开场」三位候选班长

![](https://blog.images.bornforthis.cn/docs-images/sha256/b5/b5738c31ee3e523112e596830c4038ddae1d2a3968250bff2eaf8d15cb854c2b.png)

在正式开始之前，我先请你看一个例子。

假设你是全班的一员，现在班里要选新班长了，有三位同学报名参选，分别是：

- **小明**：**成绩**超棒，考试总是第一名，但平时不太爱交朋友，不太合群。
- **小红**：成绩一般，但**人缘**特别好，和谁都能玩到一块去。
- **小刚**：性格正直，乐于助人，**品德**特别好，但人缘比不上小红。

你会选谁做班长？是不是一时间说不出个所以然？每个人都各有闪光点：成绩、人缘、品德，各占了一项。

虽然，我们不能说**成绩**代表一切，但是作为班长，成绩好确实可以给大家起到表率作用，这挺重要的吧？但**人缘**好也很重要，毕竟班长是要和全班同学打交道的，选一个大家都喜欢的人也是理所当然嘛。那**品德**呢？就更不用说了，你肯定不能想象一个班长品德不好对吧？ 

那问题就来了，小明、小红、小刚这三个同学，谁最合适当班长呢？如果你现在手里有一张选票，你会把它投给谁呢？

诶，等一下，虽然投票是最常见的选班长的方法，但这真的是最好的选班长的方法吗？

按照这个方法选的话，可能人缘好的小红同学最有可能当选班长。她比较受欢迎嘛，大家都投票给他。不过，很可能品德好的小刚同学会更适合当班长。而成绩好的小明同学呢，说不定在当了班长之后，也会慢慢改变，能够变得更**合群**一些。

看起来挺**棘手**，是吧？谁都不想错过，这时候就需要我们请出主角——**决策模型**！

## 2. 决策，其实也是一门科学

其实，要选谁做班长，就是要做一个**决策**。

对计算机来说，做决策是特别常见的事情。比如，咱们前面说过的一步棋要怎么走、判断一张图片上的动物是猫还是狗狗，这都是做决策。

其实，很多你以为靠“感觉”做的决定。在计算机眼中，全是**理性计算**。

举个例子：有种情绪识别软件，可以通过摄像头观察人脸的细节。比如嘴角有没有上扬、眉毛是不是皱起来，然后告诉你这个人是开心、愤怒，还是害怕。这听起来像魔法吧？

咱们之前的文章讲过，计算机要先把图片上的一个个**像素点都转换成数字**。经过学习之后，它就能够分辨出来哪里是眼睛、哪里是嘴巴。但要想读懂表情，光能分辨眼睛、鼻子、嘴肯定是不够的，计算机还要找到我们脸上反映情绪的关键位置。

这个实现，还是得结合显示当中。我们如何判断一个人的情绪呢？——开心的时候，**嘴角**肯定会**上扬**。想不通问题时，眉毛也会皱眉吧。

所以，对于嘴角、眉毛这些地方，能特别明显地反映一个人的情绪，就都属于关键位置。

科学家，在开发情绪识别软件时，可是找了几十个关键位置，这样才可以让计算机更精准的判断情绪。

找到了关键位置还不够，计算机并不能直接判断情绪。

我们平时说：“这个人眉毛都扬上天了，嘴角都咧到耳朵根了”。

咱们人类肯定能听懂，还能判断出来这个人挺**高兴**的。但这依赖的是**感觉**，计算机可没有人类的感觉。在前面讲抽象思维的时候说过，计算机只能处理数字。

## 3. 定量化

这时候，就要用到抽象思维里的一种方法叫做**定量化**，说白了就是要用一个具体的数字来表示眉毛、嘴巴的变化。比如眉毛上扬了2厘米，嘴角弯曲了10°。根据这些数字，计算机才能作出判断。

整理出来的逻辑如下：

1. **找出关键点**（比如嘴角、眉毛）；
2. **用数字表示**这些地方的变化（比如嘴角弯曲了几度）；
3. **计算结果**，判断当前的情绪。

也就是说，计算机并不“感受”表情，而是通过对这些数字的分析来“推理”出情绪。

## 3. 专家组上线，各司其职

上面捋清楚了计算机实现的具体逻辑，但是人类的表情太复杂了，科学家很难找到一个算法能同时适用于眼睛、鼻子、嘴巴。怎么办呢？

你还记得咱们前面说的模块化吧？在这个问题上，科学家也可以制作好几个**模块**，每个模块都有各自擅长的领域，假如科学家造了几个模块，分别让它们担任眼睛专家、嘴巴专家、鼻子专家……

每个专家模块都会给出一个判断，想象一个情绪识别小队。每个模块是某方面的专家：

- **嘴巴模块**觉得：嘴巴张这么大，是惊讶！
- **眼睛模块**认为：眼睛都眯成月牙了，是开心！
- **鼻子模块**冷冷说：这角度我看不出啥情绪……

每个模块都可以给不同情绪打分，那如果打出来的分数差不多，怎么办？

我们来个具体的评分示例：

1. 眼睛专家会认为，这个人眉开眼笑，投9分给高兴，投7分给惊讶。
2. 嘴巴专家不同意，觉得这个人大张嘴巴应该是惊讶，所以给惊讶8分，给高兴5分。
3. 鼻子专家呢，给高兴投了1分，愤怒投了5分。

我们来计算一下：

1. 高兴：9 + 5 + 1 = 15；
2. 惊讶：7 + 8 = 15；
3. 愤怒：5；

我做成表格，方便你更加直观的阅读：

| 情绪 | 眼睛专家 | 嘴巴专家 | 鼻子专家 | 总分 |
| ---- | -------- | -------- | -------- | ---- |
| 高兴 | 9        | 5        | 1        | 15   |
| 惊讶 | 7        | 8        | 0        | 15   |
| 愤怒 | -        | -        | 5        | 5    |

高兴和惊讶都是15分，必须要选一个，怎么选呢？

这就要说到另一种有意思的方法了，叫做**给权重**。诶，权重是什么意思呢？

## 4. 什么是权重？

权重就像“重要程度”的分数。比如在**歌唱比赛**里，**普通观众**的投票可能每票算1分，而**专业评委**的票可能一票就值10分，这就是他们的“权重”不一样。

**权重越高，代表越重要。**

同样道理，如果我们觉得嘴巴在表达情绪上最关键，就给嘴巴模块的打分乘个3（嘴巴权重：3）；

眼睛模块更权威？乘个4（眼睛权重：4）；

鼻子……就乘1（鼻子权重：1）；

| 模块 | 权重 |
| ---- | ---- |
| 嘴巴 | 3    |
| 眼睛 | 4    |
| 鼻子 | 1    |

这样一来，分数乘以各自的权重，哪个情绪最后分数最高，就选它！

我们接下来，把上面的例子计算一下：

1. **高兴：**

    - 眼睛：9 × 4 = 36

    - 嘴巴：5 × 3 = 15

    - 鼻子：1 × 1 = 1

    - → **加权总分：52**

2. **惊讶：**

    - 眼睛：7 × 4 = 28
    - 嘴巴：8 × 3 = 24
    - 鼻子：0 × 1 = 0
    - → **加权总分：52**

3. **愤怒：**

    - 鼻子：5 × 1 = 5
    - （眼睛和嘴巴没有给愤怒打分）
    - → **加权总分：5**

咦？怎么高兴和惊讶通过权重的加持后，还是相等的？

虽然，高兴和惊讶依然打平。但权重加进去以后，决定依据变得更细致、更贴近我们心中的判断标准了。

以及需要知道的是：即使用了权重，有时候分数还是会**打平**。那怎么办？这时候，我们可以**加一个“优先级规则”**，比如：

1. 如果高兴和惊讶持平，**优先选择更积极的情绪**；

2. 或者请一个“最终裁决专家”来投最后一票。

## 5. 额外的例子

例子还是上面的例子，不过上面因为加权后得到结果还是打平的。所以，我要来一个在加权之前打平，加权之后不打平的例子。

### 5.1 🧩 原始评分（未加权）

| 情绪 | 眼睛模块 | 嘴巴模块 | 鼻子模块 | 总分 |
| ---- | -------- | -------- | -------- | ---- |
| 高兴 | 8        | 6        | 1        | 15   |
| 惊讶 | 6        | 8        | 1        | 15   |
| 愤怒 | -        | -        | 5        | 5    |

👉 此时高兴和惊讶得分相同，是平局。

### 5.2 ⚖️ 设置模块权重

- 眼睛模块权重：**4**
- 嘴巴模块权重：**3**
- 鼻子模块权重：**1**

### 5.3 🧮 加权计算后得分：

1. **高兴：**

    - 眼睛模块：8 × 4 = 32

    - 嘴巴模块：6 × 3 = 18

    - 鼻子模块：1 × 1 = 1

    - **总分 = 32 + 18 + 1 = 51**

2. **惊讶：**

    - 眼睛模块：6 × 4 = 24

    - 嘴巴模块：8 × 3 = 24

    - 鼻子模块：1 × 1 = 1

    - **总分 = 24 + 24 + 1 = 49**

3. **愤怒：**

    - 鼻子模块：5 × 1 = 5

    - **总分 = 5**

### 5.4 ✅ 分析结果

原始打分时，高兴和惊讶都是 15 分，谁也不比谁强。可是，当我们考虑不同模块的重要性，比如我们觉得“眼睛最能看出情绪”，于是给眼睛模块更高的权重（乘以4），嘴巴其次（乘以3），鼻子最弱（乘以1）——再一计算，“高兴”的加权总分是 51 分，“惊讶”是 49 分，差距就出现了！

这说明：**权重可以帮助我们在原本难以抉择的时候，做出更合理的判断！**



## 6. 把这招用在选班长上试试看

好了，回到我们的班长选择题。

我们来看看关键特征是什么，在选班长的例子里面，就是学习、人缘和品德这**三个特征**。

但光说小明同学学习好，人缘不太好，我们是没法做比较的，所以我们要给它们定量化，说白了就是打个分，比如每一项都在1-10范围内打分吧。

那么我们也开始操作，也来学计算机的方法：把**“学习”、“人缘”、“品德”**作为三个决策指标。

比如：

| 姓名 | 学习 | 人缘 | 品德 |
| ---- | ---- | ---- | ---- |
| 小明 | 9    | 6    | 8    |
| 小红 | 6    | 9    | 7    |
| 小刚 | 7    | 7    | 10   |

这时候，我们可以把他们的分加起来算个**总分**做判断了。我们来计算一下：

| 姓名 | 总分 |
| ---- | ---- |
| 小明 | 23   |
| 小红 | 22   |
| 小刚 | 24   |

这样当然没错，但可能不够好，因为对班长来说，学习、人缘和品德，这三项的重要程度不一样。

怎么办呢？这时候，又可以用到前面提到的权重思维了。给学习、人缘和品德分别赋予一个**权重**。比如选班长不是选学习委员，成绩重要性相对低一些，就给它一个权重2。人缘呢，稍微重要一些，给权重3，品德最重要了，就给它权重5。

| 指标 | 权重 | 说明                     |
| ---- | ---- | ------------------------ |
| 学习 | 2    | 成绩不错，但不是唯一标准 |
| 人缘 | 3    | 与同学相处能力较重要     |
| 品德 | 5    | 最关键的品质，优先考虑   |

于是我们来算“加权总分”：

| 项目     | 权重 | 小明     | 小红     | 小刚      |
| -------- | ---- | -------- | -------- | --------- |
| 学习     | 2    | 9×2 = 18 | 6×2 = 12 | 7×2 = 14  |
| 人缘     | 3    | 6×3 = 18 | 9×3 = 27 | 7×3 = 21  |
| 品德     | 5    | 8×5 = 40 | 7×5 = 35 | 10×5 = 50 |
| **总分** |      | **76**   | **74**   | **85**    |

最后，小刚得分最高！恭喜他，成为最适合的班长！

## 7. 用这招，生活中也能当“决策大王”

其实，除了选班长，这种“**量化+给权重**”的判断方法，在做各种各样抉择的时候都可以用上。

~~这套“定量 + 权重”的方法，不只是选班长用得上哦：~~

- **去哪儿旅行？**
- **今晚吃什么？**
- **买哪一款耳机？**

如果犹豫半天还定不下来，那你就可以试试这种方法。

只要你列出几个关键指标（价格、口味、评分、风格……），再按重要性给个权重，分分钟搞定决定！

## 8. 小结一下

面对难以抉择的问题时，我们可以用三个步骤来决策：

1. **找关键特征**（选班长就看学习、人缘、品德）；
2. **给每个特征打分**（定量化）；
3. **给每项特征分配权重**，计算加权总分。

这就是一套简洁、科学又实用的“编程思维式”决策法！
