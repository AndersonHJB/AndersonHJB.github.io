你相信“侦探”这个角色，也能由程序员来扮演吗？今天我们就来挑战一个大案子——谁才是真正写出《红楼梦》的人？

## 1. 开场疑云：作者竟然不止一个？

提起《红楼梦》，你也许会脱口而出：“曹雪芹！”没错，大部分语文课本上都是这么写的。但如果我告诉你，这个问题其实困扰了几代学者、甚至诞生出一个叫“红学”的专门学科呢？

200多年来，无数“红学家”像福尔摩斯一样，翻书页、找线索，甚至连鲁迅也加入过这场“文学破案”。有统计说，历史上曾有**六十多个名字**被怀疑是《红楼梦》的作者。你没听错，有人连皇帝都怀疑上了，什么崇祯啊、顺治啊，脑洞大的不得了。

为啥会搞成这样？因为线索太少了。你知道曹雪芹这个名字，可其实他活了多少年、长啥样、怎么写书的，史书上都说不清楚。所有关于他的资料，拼拼凑凑连一页纸都写不满。这种情况，当然给足了“侦探们”猜测的空间。

![1960年的胡适](https://blog.images.bornforthis.cn/docs-images/sha256/3a/3ab5ecb92e76f90c3e0aa27a02970471a1427886f959c95b78751f5a58346ab2.jpg)

直到有一天，一位名叫**胡适**的大先生出场了。他提出一个广为流传的说法：《红楼梦》的**前80回是曹雪芹写的，后40回是高鹗续的**。听起来蛮合理的吧？但争议也从没停过——有人说全是曹写的，也有人说曹压根就不是作者。

可是，文学这种事，有什么绝对正确的意见呢？同样一篇文章，可能你觉得很美，但别的读者就不喜欢。

这就像是**数学考试和语文考试的差别**。

数学考试，你错了就是错了，看到考卷上最后的分数，你肯定是心服口服。但是语文就不一样了，凭什么他的作文得了满分，而我就要扣5分呢？我觉得自己的作文就该得满分呀——你是不是也这样想过呢？

对于红学家来说，也是这样。这又不是数学题，凭什么你说得就对，我说得就不对？所以，他们一直吵个不停，吵架吵得唾沫星子都能淹死人了。

那么，我们有什么办法劝劝架，让他们不再吵了呢？——用**问题转换思想**，把这个问题转化成数学题不就行了！

## 2. 语文题？不，这是“数学题”！

在大家吵来吵去，谁也说服不了谁，那怎么办？这时候，程序员上线了。他们说：“别吵了，这事可以用数学解决！”

比如我们以前学过的“密码分析”方法：在一门语言里，有的词使用次数高，有的词使用次数低，根据这个信息就能破解密码。

同样的，每个人写文章都有自己的语言习惯。就像你喜欢用“然后”、“其实”，我喜欢用“所以”、“比如”。这些词用得多了，就能体现“作者风格”。（省字版：**文风和写作习惯**）

早在70年前，一些好奇的研究者就用这招“解锁”《红楼梦》。（统计词汇的方法）

有位叫**潘富俊**的专家，原来是搞植物学的，他就分析《红楼梦》里植物出现的频率，结果发现：

- 前80回：平均每回提到11种植物；
- 后40回：平均只提3.8种！

这也太明显了吧？前80回的作者像个园艺大师，后40回的植物水平堪忧。显然，不像是同一个人写的。

你看，这种说法是不是很有道理呢？它至少说明了：《红楼梦》前后两部分的作者是不一样的。

可是这样，大家就会满足了吗？并没有。我们前边讲了，还是有很多人不服胡适。有没有可能，《红楼梦》的作者不止2个，而是有3个、4个？说不定，你的爷爷的爷爷的爷爷的爷爷，也掺和了一脚，写了一回呢？当然，这么说肯定是开玩笑的。但对于这种千古之谜，真要是胡适说什么我们就听什么，也不是个好主意。 

那怎么办呢？程序员又想出来一个好办法，能够在事先没有任何信息的情况下，推测出来一本书有几个作者。这种办法就是咱们前边讲过的“**聚类分析**”。

## 3. 程序员的秘密武器：聚类分析

接下来，我们来讲一下更“高阶”一点的方法，在**完全不知道作者是谁的前提下**，就判断出这本书是不是出自多个作者之手。——叫**聚类分析（Clustering）**的算法。这个算法的核心思想是：“相似的归在一起”。

你可以这样理解：假如你看到一张地图，上面有120个小点，每个点代表一回《红楼梦》的文字风格。通过计算这些点之间的“相似程度”，程序就能自动把它们归为若干组。是不是太抽象，不够具体。别急，我们来看看下面具体的图示和例子。

![](https://blog.images.bornforthis.cn/docs-images/sha256/ea/ea75e9d8b61da4fde5e4cbce4e168c07d26e36bc1f4e980a07e43008a53ccb9b.png)

如果，我们假设每个小方块都代表一支军队，这些小方块就是几个国家的军队布置图。那现在我问你，一共有几个国家呢？

你肯定会猜3个吧？每个国家的军队一般都驻扎在自己国家的城市附近，它们肯定会凑成一团的。没错，按照小方块之间距离关系，聚类分析就把它们分成了**3个阵营**，分别用红黄蓝表示。这就是聚类分析的基本思想了！

![](https://blog.images.bornforthis.cn/docs-images/sha256/7f/7f4e18c8e8322c6712a7951d7dfe8e5fec6e7ab8cb3ada99f0bf77b6e15a76fd.png)

同样的，在做《红楼梦》作者分析的时候，程序员先是找出了一些能代表作者写作风格的文字。

然后通过一个算法，把每一回里有代表性的文字转换成小方块画在图上，最后看画出来的120个小方块里，哪些小方块凑在一起，那这些小方块代表的回数很可能就是同一个作者写的。

结果如何？

1. 程序发现：**前80回和后40回确实不属于同一个“写作风格”群体**，验证了胡适的说法；
2. 更妙的是：**第67回**的风格有点“双重身份”，像是两个作者共同创作的；
3. 而**第105回**则像是“外星人写的”，跟前面后面都不太一样！（也就是：即不像前80回的作者，也不像后40回的作者）

聚类分析不光从数据上验证了《红楼梦》前后80回作者不同，而且还提出了另有新作者的观点，是不是很厉害呢！而且这种数据得出的结论让人信服。（用数据说话）

聚类分析算法都告诉我们：《红楼梦》作者这事，绝对没那么简单。

## 4. 生活中也能“聚类分析”

![](https://blog.images.bornforthis.cn/docs-images/sha256/00/00eec267708661d40d69810a8204daf65cdb21e63fb5d725a5a268d8ea79e1b5.png)

你以为这种分析方式只能用在古文研究里？那可就小看它了。生活中，我们也常常不自觉地用“聚类思维”判断一个人。

比如说，班上来了一个插班生。大家肯定都在默默地观察他：他是个好玩的人吗，他会成为我的朋友吗？同样，老师也会关心：这个孩子学习成绩怎么样呀，能不能和其他同学好好相处？

可是，对于老师来说：现在距离考试还远着，成绩这事儿谁也说不准。那么，现在就完全没有办法了解他了吗？其实，利用聚类分析，就可以提前猜到这个新面孔的性格、学习成绩，甚至是一些小癖好。

具体怎么做呢？

我稍微提示一下，然后你再思考试一试：古人早就有一句话讲得明明白白：“**物以类聚，人以群分**。”（同类的东西经常聚在一起，而志同道合的人呢，也经常在一起活动。这就是中国古代的聚类思想。）——这就是聚类的朴素版本。

所以，我们具体的分析如下：

1. 插班生来到了一个陌生的环境，他肯定要交朋友。
2. 而人类，就喜欢跟自己相似的人交朋友。
3. 所以，只需等待一个星期，我们看看他跟谁成了朋友，就可以**猜测他的个性和成绩**了。

比如：

1. 插班生跟班里最闹腾的几个人成了好朋友，那他基本上也是个活泼外向的人；

2. 要是他跟学习成绩特别好的人成了朋友，那他的成绩大概也不会太差。
3. 这其实就是在做“非官方聚类”：通过行为特征，猜测他属于哪个“人群类型”。

当然了，这种聚类分析的方法虽然说不上100%准确，但要比毫无目的地瞎猜，还是要准确不少。

**小结**：只要是需要分类的地方，就有聚类分析的用武之地。所以，用聚类分析给《红楼梦》的每一回按照作者分分类，那是再自然不过的了。

## 5. 编程思维的神奇视角

所以，别小看《红楼梦》作者之谜，它不仅是文学上的谜团，也是一道编程思维可以破解的逻辑题。我们学的算法，能从文本风格中看出作者是谁；从行为模式中分析人际关系。它能帮你破案、交朋友，甚至解决老师布置的“分析作文风格”的难题。

这就是聚类分析的魅力。
