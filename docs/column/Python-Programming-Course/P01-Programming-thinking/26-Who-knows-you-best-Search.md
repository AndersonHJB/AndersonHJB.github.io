那么，你有没有想过，搜索网站是怎么知道找到你想要的东西的呢？这里面呀，就有算法的功劳。

## 1. 🕰 从混乱到秩序：搜索的起点

故事要从三十多年前说起。

1991年，全球第一个网站正式上线。别惊讶，那时候的互联网简直原始得像石器时代。想访问网站？你得老老实实输入一长串网址，记不住？对不起，只能回头查笔记。比如下面两个链接：

1. 世界上第一个网站：[http://info.cern.ch/](http://info.cern.ch/)；
2. 我的博客网站：[https://bornforthis.cn/](https://bornforthis.cn/)；

如果你要查看世界上第一个网站或者我的博客网站，长什么样子。嘿嘿，你就得老老实实的去输入这两个链接才看看见。

这样的上网方式，你可能没法想象吧？要是想去不同网站里查点资料，那就得记许许多多的网址，进去之后还得找半天，就像从一个胡乱塞满东西的箱子里找玩具，特别浪费时间。

![](https://blog.images.bornforthis.cn/docs-images/sha256/79/79d6ebfe7d8762651cc8ebb01932ce7be481498a886215ca7b42aa7f4b2faa74.png)

就在这信息如沙堆的时代，一个神奇的网站横空出世：**Yahoo！（雅虎）**。它不是自己造内容，而是帮你整理信息，把全世界的网站按“种类”分门别类，就像图书馆的书架。（省字版：**第一代搜索引擎：雅虎**）

因为雅虎网把全世界最重要的网站都收集了起来，然后**分门别类**地展示出来。比方说吧，新闻网站分一类，游戏网站分一类，体育网站分一类，等等等等。这样一来，大家就不用记住那么多网站的网址了，只需要记住雅虎这一家网站的网址就可以了。

通过雅虎就可以让你轻松找到新闻、游戏、体育等内容，成为当时最受欢迎的“**门户网站**”。

为什么称为：门户网站呢？

因为，对于那时候的网友来说：雅虎网相当于打开了一扇通向互联网世界的魔法之门。所以，就给它起了个名字叫“**门户网站**”。就像现在你熟悉的新浪、网易，它们当初也是靠这种方式起家的。

那为啥现在还有新浪和网易，而我们却再也没听说过雅虎了呢？这是因为，雅虎被**互联网大爆炸**给炸死了。当然了，这个爆炸呀，说的是信息大爆炸。这里面的过程比较复杂，我慢慢给你说。

在**1995年的8月**，全世界的网站也就不到**2万**个。而1年后就翻了10多倍，达到了**20万**个。

这时候，雅虎网就会面对一个大难题，雅虎网上列出来的网址，都是员工**手工录入**的。现在网站那么多，想要把新的网站都列上去，那显然做不到了。于是他们就只列一些比较重要的网站。

可就算是只列重要的网站，那数量也不少。所以雅虎网就变得密密麻麻，从首页点进新闻类别，可能你进去之后，还会看到美国新闻、外国新闻等各个不同的类别，于是你就需要像在电脑文件里找东西一样，一层一层点进去寻找。

~~面对这个问题，雅虎公司很快就想到了一个办法。他们在首页上加了一个**搜索框**，这个搜索框，看着跟今天的差不多，但其实是不一样的。因为它**只能搜到雅虎网列出的网站**，没有被列入雅虎网的是搜不到的。~~

~~不过，随着互联网像开了挂一样迅猛增长，从两万个网站暴涨到二十万个，雅虎的人工整理方式很快就吃不消了。~~

于是，**搜索框**出现了。但是和当下的搜索框不同，别以为它有多聪明——它只能搜到被雅虎录入的网站，换句话说，你还是只能“在自家花园”里找东西。

但这对于当时的网友来说，已经很高级了。大家也越来越爱用雅虎网，甚至上雅虎都成了上网的代名词！在2000年前后，雅虎简直要称霸整个互联网世界了。

## 2. 🚀 颠覆者登场：一场算法革命

### 2.1 缘起

![](https://blog.images.bornforthis.cn/docs-images/sha256/a0/a0482342524e59ec6815de4b2d4b4bc1de78f45982d84a70877e1da8bfaa6e55.png)

1998年，两位年轻的博士生**拉里·佩奇**和**谢尔盖·布林**，在斯坦福大学的寝室里，搞出了个新玩意儿：一个名叫 **Google（谷歌）** 的搜索引擎。

他们不想做一个“目录表”，而是要做一个**真正理解网页关系的搜索系统**。他们发明了一个强大的算法——**PageRank（网页排名算法）**，简单来说，就是：**不是看谁重复关键词多，而是看谁被别人“推荐”得多**。

其实，当时世界上已经有别的公司做搜索引擎了，如果你输入一个关键词，就能出现很多结果，当然也包括雅虎没有收录的网址。但他们的算法和谷歌公司的算法不太一样，搜出来的结果排序也不同。

### 2.2 一般的搜索引擎实现原理剖析

![](https://blog.images.bornforthis.cn/docs-images/sha256/c4/c481cc2d9bd01b08ea8acc563fe9664e69d27179ba84edd9c33326a155f3f5d1.png)

咱们先说说，一般搜索引擎的结果是按什么顺序排列的。说来也简单，它们是按照相关性排列的。

比如说，有个网站为了骗流量，在背景里偷偷堆了几千个“AI悦创”关键词，普通搜索引擎可能真会被骗。具体来说：如果一个网页里出现了1000次“AI悦创”，而另一个网页里只出现了90次“AI悦创”，那么有1000次的就会排在前面。

这种方法是不是还挺聪明的？只不过，它有一个缺点，或者说是人类自己有一个缺点。那就是：**有人会作弊**！

具体怎么作弊呢？你可以自己想想。例如：一个网站本来是虚假保健品的，那它肯定没多少人爱看。这时候，它就在网站里头偷偷写了1000个“AI悦创”！

你可能会想了：那要是网页上写满了“AI悦创”，跟卖保健品的内容混在一起，别人点进去一看，乱七八糟的简直看不了一点！那肯定不能这样，不过作弊的人也想到了一个”巧妙的方法“——只要把所有的“AI悦创”这三个字，设置成跟网页的背景一样的颜色，然后堆到一个不起眼的角落里去，那就根本不可能有人看得见这些”AI悦创“了。

不过呢，人虽然看不到，但是搜索引擎不一样。它虽然没长眼睛，但看得却更清楚。搜索引擎看的是网页的源代码，所以它就被骗了。

搜索引擎一数，这里头有这么多“AI悦创”呢，那它肯定是 AI悦创·黄家宝的官方网站。于是，你下次搜“AI悦创”的时候，这个网站就跑到了最前面。但你点开一看，嚯，原来是卖保健品的！这才知道上当了。



### 2.3 谷歌的页面排名算法（PageRank）

但是现在，谷歌公司的布林和佩奇的**网页排名算法**却堵住了这个漏洞。怎么堵的呢？

我就拿我自己的 AI悦创来说吧，如果这个网站优质文章内容多且学习访问的人多，那别的网站肯定会经常推荐我这个网站，在自己的网页上放上它的链接。并且现在很多网站的友情链接，就是为了达到这样的效果。

![别碰我的镜头盖·友情链接页面](https://blog.images.bornforthis.cn/docs-images/sha256/3c/3cf165b08c0bdf96524d72c693157cbd5798d626bca02b333c26cd760edf6f07.png)

它只信那些被大量其他优质网站“引用”过的网页。被推荐次数多，排名就高；没人提起你？对不起，请靠边站。例如：还是上面说的卖保健品的网站，是不是挺无聊还有可能是骗子网站。那别的网站肯定不想与有可能是骗子的网站一伙，且去推荐。

所以，网页排名算法就是要统计一下，**每个网站都被别的网站推荐了多少次**。然后，把它们按照**推荐次数**从高到低排名。

接下来，你想想基于谷歌的这个排序算法，前面的作弊行为还会发现吗？——不会，那个伪装的“AI悦创”网站，就再也不能滥竽充数了。就算它在网页里写上100000个“AI悦创”，别的网站也不会推荐它，它就只能老老实实地排在最后边了。

当然，实际的**网页排名算法**要比这个还复杂一些，它还使用了本书前面讲过的“**给权重**”的方法。那些被推荐得多的网站，肯定是个好网站，那它投一票，就相当于别人投2票，甚至投10票。而差劲的网站呢，就算它投了票，也不算数的。

是不是感觉有点小抽象，那么我举个具体小例子：给权重的实际就是谷歌给推荐本身打分。假如推荐你的网站是个**权威新闻媒体**，那它的一票比一个无名小站的十票还要有分量。而如果是个“小破站”、“骗子网站”推荐，那就算一票甚至这一票无效。这样是不是好理解一些？

基于这样的算法下，谷歌的搜索引擎越来越精准，它给我们返回的结果，也越来越符合我们的心意。**谷歌**公司也越来越厉害，成为世界上最伟大的互联网企业之一。很快，谷歌就超越了雅虎，成了新一代互联网霸主。而雅虎的门户网站就被时代淘汰了，现在阅读本书的你，可能听都没听过。（省字版：页面排名算法，让搜索结果变得更真实、更有用。）





## 3. 🧠 搜索的进化：从关键词到理解你

这场技术进化并没有止步，**谷歌**的搜索引擎还只算是**第二代搜索引擎**。很快经过改良，又出现了**第三代搜索引擎**。我们接着往下阅读，来看看第三代搜索引擎。

第二代搜索引擎解决了“找得到”的问题，第三代搜索引擎开始尝试“看懂你说的话”。

在**第二代搜索引擎**里，你输入的**关键词**是“完美世界石昊（空格）最高修为”，等出现一堆网页之后，你再去这些结果里找答案。

而在**第三代搜索引擎**里，你就可以直接写“完美世界石昊最高修为是多少？”——搜索引擎会直接告诉你答案，省去了中间翻页查找的麻烦。这就好比，它不只是“听懂了字”，而是“明白了你在问什么”。

当然，智能归智能，它也偶尔“翻车”，但进步仍是惊人的。毕竟，互联网只花了**30年**就成了今天的高级模样，在未来，它肯定会变得更好，我们就慢慢期待更美好的未来吧。



### 3.1 「选读」30年如何来？

![](https://blog.images.bornforthis.cn/docs-images/sha256/66/6636ac2263b639e51c0b56c8296e3fa5990bc189ebd69228e81c8b090777a430.png)

写到本书中的互联网 30年时，我就好奇的去研究了一下。然后汇总出下面的结论：

这个问题可以从两个角度来回答：**“互联网的雏形”什么时候出现**，以及**“真正意义上的互联网”从什么时候开始普及**。

#### 3.1.1 📌 从“雏形”开始算

- **1969年**，美国的ARPA（国防高级研究计划署）启动了一个叫做 **ARPANET** 的项目，是世界上第一个可以把不同计算机连接起来的网络，常被看作互联网的“祖先”。
- 到 **2025年**，正好是 **56年**。

#### 3.1.2 📌 从“现代互联网”的诞生算

- **1989年**，**蒂姆·伯纳斯-李**（Tim Berners-Lee）提出了**万维网（WWW）**的构想，并于1991年正式上线第一个网页。这标志着我们今天所说的“互联网”开始形成。
- 从 **1991年** 到 **2025年**，是 **34年**。

#### 3.1.3 📌 从“普通人开始普遍上网”算

- **1994年到1996年**，互联网开始面向公众普及，浏览器 Netscape 诞生，搜索引擎和网站如雨后春笋般出现。
- 那么从 **1995年** 到现在，大约是 **30年**。

| 起点          | 起始年份 | 到 2025 年多少年 | 特点                       |
| ------------- | -------- | ---------------- | -------------------------- |
| ARPANET       | 1969 年  | 56 年            | 军事/科研用途的原型网络    |
| 万维网（WWW） | 1991 年  | 34 年            | 网页浏览、全球信息共享开端 |
| 大众化普及    | 1995 年  | 30 年            | 普通人开始接触并使用互联网 |

纯粹兴趣，准确度还是仁者见仁，智者见智。



## 4. 🌐 网中的网：把世界织成一张大网

前面讲了这么多，你可能会想：搜索引擎是很方便，可这对我有什么启发呢？

谷歌的伟大，并不只是因为它技术领先，而是因为它**改变了“看待信息”的方式**。

它不再把网站当作一堆孤零零的“点”，而是看成**一张互相关联的大网**。这让搜索结果更贴近真实世界的结构，也让我们对知识的理解变得更有层次。

![](https://blog.images.bornforthis.cn/docs-images/sha256/4f/4f357135f7960850199c943da900fef3e2869c27f428a6982802f775667dc859.png)

这不仅仅是我这么想，谷歌公司一位资深员工也说过，**网页排名算法**的高级之处，就在于**它真正把互联网当成了一张网**。

以前的搜索引擎，在搜索的时候，只会调查每个网站自己的情况，而不会去关注网站之间的关系（例如：雅虎）。而谷歌呢，它会考虑网站之间的相互推荐，就考虑了**网站之间的关系**。

拿蜘蛛网来比喻，以前的搜索网站只看到了蜘蛛丝的节点，却漏掉了连接节点的蜘蛛丝。而谷歌看到的，是能够抓住猎物的蜘蛛丝。

![](https://blog.images.bornforthis.cn/docs-images/sha256/37/375167c421ef0d39f28c1f9f60952b2fd00bbc10f8cb58d3fb05e07a88249b0b.png)

所以，我们在学习的时候也是一样：只是学会单独的知识点，作用其实不大。我们要想方设法，在单个的知识点之间建立起联系，让它们织成一张知识的大网，到那时候，才算真正掌握了这些知识。

写到这，我忍不住还是要重复赘述一遍，强调一遍：想象一下我们在学习时，如果只死记硬背每一个知识点，永远只是机械地堆积信息。（每个碎片化的知识点越来越多，但是不成自我的体系。）但如果我们能建立起这些知识点之间的联系，构建自己的“知识网”，那才算是真正学会了。

## 5. 忍不住，真的忍不住

![](https://blog.images.bornforthis.cn/docs-images/sha256/58/58c944eb47c2136b7831a646d0a4fe715b20c9ac346ae4f717037d7940d19ade.png)

我还是要在这篇中，跟你聊聊碎片化阅读好不好。不要觉得突兀，因为上面提到了学习方法：知识网。

人在人生的早期阶段，一定要有一些吃过苦头的、真实的深度阅读。为什么呢？因为这个时候等于初步搭建起来了一个属于自己的架子，也就是你人生的一个框架。就如同我们现在讲的：人生观、价值观、世界观，这些是要我们搭建起来。搭建起来之后，你在碎片化阅读（学习）是没有问题了。

因为，你已经有了自己的体系。你往后所有的阅读，都可以纳入自己的体系之中。并且你会发现，自己拥有了触类旁通的能力。随便吸收一个知识，你都能够纳入现有的知识体系之中。

随便产生一个认识（认知），也都可以纳入现有的认识体系（认知体系）之中。

可如果在什么体系都未建立起来时，直接东拉西扯的阅读（学习）这个情况是很糟糕的——所以，碎片化阅读是有门槛的！

我把上面这段内容，分享给了我的公众号读者们，他们留下了下面的理解：

- 读者**初道**：有体系之后就能有分别有标准的筛选和吸收，作为少年时读了很多优质武侠小说的70后，同样觉得那时的阅读对自己的价值观和后期成长的帮助也很大，如果读更优质的书，效果会更好。
- 读者**壹自习室**：悦创老师这个点说的太好了：碎片化阅读之前，一定是体系化阅读，建立起一个整体认知体系。有了这个体系之后，碎片化阅读就可以起到锦上添花的作用了！
- 读者**阳光心灵**：所言极是，真有感触。大量，深度的阅读之后培育起的学习能力，是可以在碎片化的知识里面快速的吸取知识内化成自己的。
- 读者**繁华驿站**：我最认可的对于：碎片化阅读和大量系统读整本书，哪种方式最适合的认知。刚开始的一本本读书就像一节节脊椎，稳稳的支撑着读书的人。后来的碎片化阅读就像从脊椎散发出的各类神经元，让人触类旁通。
- 读者**拿铁味的洋柿子**：先建房子，再给房子买家具，电器，饰品……
- 读者**宏**：曾经有位长辈和我讲过一个植树人生，就是有些树别看它长得快，但没有根基，大风一吹就倒，有些树虽长得慢，但它一直扎根巩固基础成长中风吹不倒，他的这段话一直启示着我。
- 读者**允之**：只是阅读就能建立起体系来吗？就像是只把肉吞下去，就能消化了吗？阅读后的思考、讨论，产生自己的观点，才是关键。
