在前面学习了搜索引擎，我们聊的是“搜索”——你主动出发，像个小侦探一样去找线索。而今天我们要说的是“推荐”——你啥也没干，结果消息自己敲门进来了。

其实现在的推荐算法几乎是无处不在了，你有没有发现这种事儿经常发生？比如你刚刚搜了一下猫咪打喷嚏的视频，下一秒，视频平台立刻给你端上一堆更萌的猫猫合集。又或者你爸妈买了双跑鞋，购物网站马上推送一大堆运动服和智能手环。没错，你还没说“我想要”，它就已经猜到你心里去了。

是不是哪里有一双眼睛一直在看着我们，偷窥我们内心的小秘密？这背后的魔法师，就是我们今天的主角：**推荐算法**。

我们一起来看看这双眼睛是如何发挥作用的～

## 1. 从书店小弟到推荐天才

要说推荐算法，就得从最早的购物网站——**亚马逊**讲起。

![](https://blog.images.bornforthis.cn/docs-images/sha256/59/59dfc490bd5e16af7947f5ba19728f1ebf05a585c3e9df17e0d66653065d7e56.png)

这家巨头在刚起步时，只是个卖书的网站。一开始他们的方式很简单：把书都摆出来，顾客想买啥就自己挑。

但很快他们意识到：嘿，人们的购买习惯其实有规律可循！如果掌握了这个规律，就可以卖出更多的书。什么规律呢？

这个规律，其实你自己早就掌握了。只是你还未发现，我们来看看例子：

![不要插入此图片](https://blog.images.bornforthis.cn/docs-images/sha256/4b/4bc09afb355ad2caf0ff14257a3b48048df952f03057ca4757395202f03e68c3.png)

如果小悦买了《哈利·波特》第一本，在小悦生日的时候，你会买什么书送给小悦？小悦可能对什么感兴趣？——也许是第二册、第三册，甚至是漫画版的《哈利·波特》。

不仅仅是送生日礼物，就算是推荐给小悦也是再合适不过的。所以，这个不是我教给你的方法，而是你本身就会的方法！（学习就是把某些你潜意识的知识，挖掘出来变成有意识的。）

亚马逊按上面人类会做的方法，思考着：如果能提前猜到顾客的心思，那销量不就蹭蹭涨了吗？

不过，你可以靠着经验给小悦选生日礼物、推荐书，但机器可没有经验。它要怎么办呢？亚马逊想了个办法：不靠直觉，而是靠**大数据**。

什么意思呢？亚马逊公司会把在自己网站上买过《哈利·波特与魔法石》的用户数据收集起来，看看他们后来又买了什么书，然后把这些书放在《哈利·波特与魔法石》的下边，推荐给用户。

是不是还是想不到，亚马逊的具体操作？别急，我们一起来看看下面的例子：

他们分析买过《哈利·波特与魔法石》这本书的用户，还买了什么别的书。结果发现：全网站有1000个人买了《哈利·波特与魔法石》，然后经过统计，发现在这1000人里头，有800个人买了哈利·波特系列的第2册，有700个人买了第3册。还有600个人买了《福尔摩斯探案集》，比买哈利·波特第4册的人还多！

这样一来，亚马逊给用户推荐的时候，就不是按照哈利波特2、3、4这样的顺序推荐了。而是先推荐哈利波特第二、三册，之后推荐《福尔摩斯探案集》。简单直接，但效果惊人。——推荐系统就此诞生！

这就是早期的推荐算法，虽然技术含量不高，却已经相当聪明了。不过跟今天的推荐算法相比，它还只能算是一道小菜。今天的推荐算法非常庞大且精准，可以为每一个用户建立一个兴趣档案。

## 2. 看不见的“标签机”

![](https://blog.images.bornforthis.cn/docs-images/sha256/a5/a5e56298bc9879c1559f6fcf169d225d120895ef5f1635e2053345ef76720a36.png)

不过嘛，今天的推荐算法可不是当年的“老实人”了，它已经变身为超级智能助理。

它不仅知道你买了啥，还知道你在哪个页面停留了多久，喜欢在晚上几点刷视频，你看完这个视频又看了哪个视频，甚至能猜到你什么时候心情好、什么时候想点外卖，这些信息全都会记录在案。

每一次点击、滑动、点赞、收藏，都会被记录并转化为一张你的“兴趣画像”。网站就会根据你的记录给你贴上标签，你的标签可能是“猫咪爱好者”、“周五熬夜党”、“动作片迷”、“糖果控”……然后以此标签，为你推荐你可能感兴趣的东西。

举个例子：网站可能会发现，你到了周五的晚上，就会睡得很晚，而且还喜欢在这个时间看电影。那么，它就会在周五的晚上，等你放了学，就把好多你感兴趣的电影摆在首页，吸引你去点击。它就像一个精明的服务生，早早备好你爱看的内容，恭候大驾。

有了这么好的推荐算法，你的生活会变得更加方便。推荐算法就像是一个忠诚的**仆人**，老老实实地记录你的爱好，然后推荐你感兴趣的东西，让你过得很舒心。

通过前面的讲解，你可能觉得这挺好的啊！是的，它确实让生活更轻松了。

但你有没有想过：这份贴心，也可能是一种“甜蜜的陷阱”。

## 3. “地平说”的故事，和茧房的陷阱

![](https://blog.images.bornforthis.cn/docs-images/sha256/d5/d5dfae9d33288ac9454effac6ddc0313241a0884f5127961ac7d4e6974bc5fbe.png)

咱们来说个真实得让人咋舌的例子：地球到底是圆的，还是平的？

“这还用问吗？”你可能会笑出声，“当然是圆的！”

但有些人相信“地平说”，就是认为地球不是个球，而是扁扁的、平平的。注意：我说的这些人可不是古人，而是生活在21世纪的实打实的现代人。

那你肯定会好奇了，这些人是不是生活在比较落后的地区，没有见过宇宙飞船给地球拍的照片？——还真不是，这些人都可以上网，只要愿意，他们可以看到各种各样的信息。那他们为什么会相信地平说呢？

问题出在哪儿？

这里头的原因很复杂，但有些人相信地平说，推荐算法要背一部分锅。在相信地平说的人当中，有一部分人本来是相信**地圆说**的，也认为地球是圆的，他们抱着好奇的心态看了关于地平说的内容。结果呢，推荐算法以为他们喜欢地平说的内容，于是不停给他们推荐这方面的内容。这些人呢，整天都看到地平说的信息，时间长了，难免就被误导了。

换句话来说：有些人本来只是出于好奇，点开了一个讲“地平说”的视频。结果推荐算法一看：“哟，这位用户对地平说感兴趣啊！”于是开始不断推送相关内容。久而久之，他们看到的都是“地球是平的”论调的信息，听不到其他声音，慢慢地，也就动摇了。

上面虽然有重复赘述之嫌，但还是希望你能 get 到我要表达的。

推荐算法这个只会奉承你的仆人，可能会让你只看自己爱看的东西，最后陷进一个**小圈子**里去。如同古代皇帝，如果只听信爱听的太监或奸臣说的，那这个皇帝基本上也就废了。

虽然你不至于相信地球是平的，但是推荐算法可能会让你接触不到新的信息，沉浸在自己喜欢的那一片小世界里，没办法再继续成长了。

这个现象，被人们叫作“**信息茧房**”，茧就是毛毛虫吐丝做的那个茧，一层又一层，把自己包住，最终看不见外面的世界。也就是说，如果你只关注自己感兴趣的人和事，那你最后就会像一只毛毛虫一样，用吐出的丝完全把自己包围起来，眼界就完全封闭住了，这就是推荐算法的危险之处。

写到这，我想起了我许多年前在朋友圈中发布的一段对于推荐算法的观点：人们往往只相信那些他们**亲眼看到的**、**亲身感受到的**、或者早已在脑海中形成印象的东西。他们更愿意接受**已经得到社会认同的观念**，以及那些**与自己世界观相符的解释**。至于那些颠覆认知、挑战信仰、打破舒适圈的信息，哪怕就摆在面前，也往往会被下意识地**忽略、否定，甚至视而不见**。

而在今天这个由推荐算法主导的信息时代，这种倾向只会变得更加明显。算法会不断记录我们的点击、偏好和停留时间，继而精准地投喂我们想看的内容、认同的观点、熟悉的语气。这些算法就像是一面面“认知回音壁”，把我们已经相信的东西，反复包装、放大、回响。久而久之，我们看到的世界，不再是客观真实的全貌，而是一面经过滤镜处理的镜子——它只映照出我们想看到的那一部分。

于是，我们就这样陷入一个温柔却危险的信息茧房：越看，越信；越信，越窄。**推荐算法在强化我们的选择的同时，也悄悄关上了通往不同观点与多元认知的大门。**

## 4. 怎么破茧而出？

那么，我们该如何像蝴蝶一样打破茧房，重新获得自由呢？

对于平台：为了不让我们变成困在小世界里的毛毛虫，很多平台也想了办法。他们会在你喜欢的内容之间，**夹带一点“随机推荐”**，让你有机会跳出旧圈子，接触新观点。

不过如果你稍微拥有批判性思维，那我想告诉你：不要等待平台给你的一些些随机来改变自己，跳出圈子。你要自己主动出击，有意识的去改变。毕竟，有些平台虽然明面上说有夹带随机的推荐，不然你成瘾，但实则没有给你随机。因为只有“作茧自缚的你”，才能造就愈发依赖平台的你。~~这样就会越依赖该平台。~~ 也是因为：人是特别容易沉迷哪些，自己所相信的。

这对我们生活、学习其实有很深的启发。

- 交朋友时，不妨试着去和不太一样的人聊聊天。适当的时候还可以扩大社交圈子，不要仅限于自身的小区或者班级；
- 读书的时候，偶尔翻一翻你平时不太感兴趣的那一类书；
- 别只看漫画，也看看科幻小说、历史故事；
- 别老刷搞笑短视频，也试试纪录片。
- ……

不要一味任由着自己，跟着兴趣爱好走。这样，你的路才有可能越走越宽。

阅读本书的你，不知道是否偏科或者有你不喜欢学校安排的学科。你有没有想过，学校为什么要设计哪些那么多的课呢？

其实学校里的那些“你不爱学的课”，其实也是为了帮你打破“知识茧房”而设计的——别只偏爱语文和数学，物理、生物、地理……都值得你张开眼界去看看。

或许有些知识可能比较枯燥，但是它们可以拓宽你的眼界，是你未来获取自由的保证，可不能偏科呢！



## 5. 小结：推荐算法，不只是算法

你看，推荐算法不只是一个冷冰冰的程序，而是与你生活紧密相关的一套机制。它会迎合你的口味，也可能误导你的判断。它能帮你省力，也可能让你封闭。

而理解推荐算法，其实是我们接下来的学习旅程中，理解人工智能的第一步！

因为——推荐算法，就是人工智能技术的早期代表之一。
