## 1. 理解变量——生活中的例子

### 1.1 从字面意思去理解

- 变：变化
- 量：大小

### 1.2 举个例子🌰

假如，你是班级当中的课代表，每个月需要统计班级中每个学生的月考成绩。月考成绩会每个月一张纸，每张纸上都会依次记录每个学生的月考成绩，例如：

1. 李雷    98分
2. 马冬梅    89分
3. 刘奕彤     96分
4. ......

某一天，老师要看刘奕彤 1月、2月、3月的成绩，这个时候作为课代表的你需要怎么办。——总不能直接把每个月的月考成绩单直接给老师，显然是不合适的。

我们应该把刘奕彤 1月、2月、3月的成绩抄写到单独的一张纸上，接着给老师。

那么，我们为什么不一开始直接为每一个学生分配一个信封呢？（也可以是档案袋）信封在一开始是扁的，当我们放东西（数据）进去之后，是不是鼓起来了？——是不是变化了？是不是有大小了呢？显然是的。

那么信封，是不是在我们当前所处的空间当中开辟空间，来存放数据并且说这是信封。

类似的有：冰箱，不也是在我们当前所处的空间中，开辟空间。说这是冰箱，用来存放东西的。

——所以，**<span style="color: orange">变量不就是在计算机的内存当中开辟空间，来存储数据。</span>**

### 1.3 变量的特点

**特点：** 变量的值会被覆盖，只会记着最后一个值。

## 2. 如何创建变量——赋值语句

## 3. 探究 print

### 3.1 同时输出多个数据

```python
a = 1
b = 2
c = 3
print(a, b, c)  # 使用 print 同时输出多个变量

# ---output---
1 2 3
```

从输出的结果可以看出，print 同时输出多个变量，每个值之间默认以空格间隔。

那么，我们可以修改这个默认空格间隔么？——答案显然是可以的。

使用 sep 就可以修改多个变量同时输出的间隔。

### 3.2 sep 修改多个变量同时输出的间隔

```python
a = 1
b = 2
c = 3
print(a, b, c, sep=' 间隔 ')
# print(a, b, c, sep=' ') 与 print(a, b, c) 是等价的！写不写 sep 都是存在的！

# ---output---
1 间隔 2 间隔 3
```

上面的例子，只是让你初步了解到 sep 的作用。你一定要多测试测试其它的字符，这样才能触发自己的大脑思考。sep 对应的字符串，里面可以填写任何内容。

并且需要注意的是，sep 只有在 print 同时输出多个变量时才会生效。（没有多个变量，就算写了也不会生效，当然也不会报错！）

    ```python
    a = 10**100      # 100 位数字

    ```

    **我想你可以知道：我们此刻的代码无法直接使用 a + b 的结果，虽然 print 函数使我们看见 a + b 的结果，但并不能支持我们后续的使用！**——这就是 print 函数中看不中用的意思。

    在我们需要后续操作时，可以考虑使用变量来临时存储数据。（临时：内存上的数据都是临时的，关机、重启、死机等，临时数据都会丢失。只有写入硬盘的数据才是“永久”保存。）

- **课后追问一**：变量名长短会影响运算速度吗？

    > 原始问题：第一个问题就是你代码里面，你创建的result变量，我用d 来代替，字符变result少，从临时存储或者运算角度，他的字符越多越影响运算速度。
    >
    > ::: details image
    >
    > ![](https://blog.images.bornforthis.cn/docs-images/sha256/d7/d7c21e9e1165a0c822d965619d0e41ec5ca4a78c065c43b06df79b6b3d9cb631.png)
    >
    > :::

    不会。变量名只是**给人看的标签**，解释器在执行代码时，会把变量名解析为某个内存地址，之后的操作都直接对内存地址进行读写。

    > 人是记不住地址的，使用变量就类似于给人取一个小名。

    换句话说：

    - `result`
    - `d`
    - `tmp_value_001`

    这些变量名只在**代码解析阶段**有一点点差别，但这点代价极小（可以认为几乎为 0），和程序的实际运行速度无关。

    真正影响运行速度的是：

    - 算法复杂度（$O(n)$、$O(n^2)$…）；
    - I/O 操作（文件读写、网络请求）；
    - 循环次数和数据结构性能；
    - Python 解释器本身的执行效率；

    变量名长短对性能影响几乎可以忽略不计，在 Python 中尤其如此。

    ➡️ **<span style="color:orange">一句话总结：变量名长短不会影响运算速度，写可读性高的变量名更重要。</span>**

- **课后追问二**：哪些操作会写入硬盘？print 会写文件吗？

    > 原始问题：是有保存的函数指令才有写入硬盘，像 print 函数指令都是临时的是吗？

    从两个方面去理解：

    - 第一个方面：你所写的 Python 代码，在保存之前就会存储在内存当中，只有按下保存按钮（Ctrl + S）才会真正的写入硬盘。那在 Pycharm 当中，我不是没有按保存相关的按钮或按键吗，为何关闭之后还在？——因为 Pycharm 在我们运行代码的时候，会自动执行**保存操作**。

    - 第二个方面：面向代码功能来说，只有**明确调用写入操作**才会写硬盘，比如：

        ```python
        with open("a.txt", "w") as f:
            f.write("hello")
        ```

        或数据库写入、日志写入。

        `print()` **不会写硬盘**，它只是：

        - 把内容输出到标准输出（stdout）「在终端当中，输出出来」；
        - 属于**临时性的显示行为**；
        - 不对文件系统产生修改；

        甚至有些运行环境（如 PyCharm、Jupyter）是把 `stdout` 捕获后展示在界面上，本质还是临时的。

        ➡️ **一句话总结：print 是临时输出，不会写入硬盘；只有文件写入函数或数据库调用才会真正存储到硬盘。**

- **简短概要**：

    第一点：变量名长短不会影响程序运行速度。变量名只是给程序员看的，解释器在运行时是根据内存地址读写数据，而不是根据变量名长度来决定速度。性能更多取决于算法、I/O、循环等因素。

    第二点：只有显式的写入操作（如 `open().write()`、数据库写入等）才会真正写入硬盘。`print()` 只是在标准输出显示内容，不会带来实际的硬盘读写，是临时的。

- **补充**：其实在代码的运行过程当中，所有产生的数据都是临时数据，存储于内存当中，除非我们写了保存，否则运算时产生的数据也是临时存在。例如：

    ```python
    a = 10
    b =100
    result = a + b
    print(result)
    ```

    上面的代码运行过程当中，确实会产生 a、b、result 变量存储数据，但都会在程序运行结束之时，销毁（消失）。（因为，我们没有写保存数据的操作，保存数据的意思就是：从内存写入硬盘。）

### 3.3 end 修改 print 输出结尾方式

在使用  end 来控制 print 的输出结尾之前，我们先看看使用 end 之前，print 默认输出的结尾情况。

```python
a = 1
b = 1
c = 1
print(a)
print(b)
print(c)

# ---output---
1
1
1
```

由上面的输出结果可知，常规情况下，print 会在输出的结尾自动换行。

我们接下来修改 end 对应的值，看看有什么操作效果：

```python
a = 1
b = 1
c = 1
print(a, end='\n\n\n')  # 多换行几个，\n 是换行的意思
print(b)
print(c)

# ---output---
1


1
1
```

我在 end 后面编写了许多个 `\n`，`\n` 代表的功能是“换行”，也就是使用 `\n` 可以轻松实现对字符串进行换行。上面连续写了 3个 `\n` 意味着换行三次。

上面的修改使用的是特殊的 `\n` ，难道不能使用其它普通字符吗？

（这里，是我提出来的，但我更希望是：在你上面编写的代码后，引发的思考！AI 时代，我们缺少的不是实力，更多是要有自己的想法。当然，实力还是需要慢慢提升。）

下面，我们把结尾的的内容，修改成一串内容来看看具体的输出效果。注意，下面 end 的字符串内容，前后我都加了一个空格。

```python
a = 1
b = 1
c = 1
print(a, end=" bornforthis is huangjiabao ")  # 我们可以修改成不换行的字符串
```

### 3.4 end 和 sep 可以同时使用

前面我分别讲解了 sep 和 end，但实际上 sep 和 end 是可以同时使用的。

```python
a = 1
b = 1
c = 1
print(a, b, c, sep="~", end=" love Python")

# ---output---
1~1~1 love Python
```

注意：sep 只有在 print 同时输出一个以上的变量时，才会有输出效果。

## 4. 进阶的赋值方法

以往我们想把多个变量赋予相同的值，只能如下操作：

```python
a = 1
b = 1
c = 1
print(a, b, c)
```

那现在在 Python 中有更简单的方法，多个变量同时赋予相同的值。

### 4.1 多个变量同时赋予相同的值

```python
a = b = c = 1
print(a, b, c)

# ---output---
1 1 1
```

### 4.2 多个变量同时赋予不同的值

```python
a, b, c = 1, 2, 3
print(a, b, c)

# ---output---
1 2 3
```

## 5. 变量的命名规则

一切创造其实都有规则。比如，取名字这件事就有规律可循：在国内，姓氏在前，名字在后；而在国外，大多数情况下名字在前，姓氏在后。再比如，我们写作文时都需要有标题，文章也通常包括引言、主体和结论的结构。甚至在艺术创作中，绘画有透视和构图的规则，音乐有音阶和节奏的限制。正是这些规则，使得我们的创造更加有序、美观，并且便于他人理解和欣赏。

所以，在 Python 当中我们在使用、创建变量是，也是要遵守一定规则的。

规则如下：

- 大小写英文、数字和 `_` 的结合，且不能用数字开头；
- 系统关键词不能做变量名使用「获取关键词列表：`help('keywords')`
- Python 中的变量名区分大小写；
- 变量名不能包含空格，但是可以使用下划线来分隔其中的单词；
- 不要使用 Python 的内置函数名称做变量；

### 5.1 内置函数与关键词的区别

在 Python 中，**内置函数（Built-in Functions）**和**关键词（Keywords）**虽然都是 Python 自带的，但它们是两种完全不同的东西。

| 对比项               | 内置函数                     | 关键词                  |
| -------------------- | ---------------------------- | ----------------------- |
| 本质                 | 函数                         | Python 语法的一部分     |
| 是否需要 `()`        | ✅ 需要（大多数情况）         | ❌ 不需要                |
| 能否重新赋值         | ✅ 可以（但不建议）           | ❌ 不可以                |
| 是否可以自己定义同名 | ✅ 可以（会覆盖）             | ❌ 不可以                |
| 数量                 | 约 70 个（不同版本略有差异） | 约 35 个（Python 3.13） |

::: tabs

@tab 1. 内置函数

内置函数就是 Python 已经帮你写好的函数，可以直接调用。

例如：

```python
print("Hello")
len("Python")
max(1, 5, 3)
sum([1, 2, 3])
```

这里：

```python
print()
len()
max()
sum()
```

都是内置函数，特点：后面通常都有 `()`、接收参数、返回结果。

例如：

```python
name = "Python"

print(len(name))

# ---output---
6
```

@tab 2. 关键词

关键词是 Python 的语法，不能当变量名。

例如：

```python
if
for
while
class
def
return
import
```

它们决定了程序的结构。

例如：

```python
if age >= 18:
    print("成年人")
```

这里：`if` 不是函数，而是语法。再例如：

```python
def hello():
    return "Hello"
```

这里：`def`、`return` 都是关键词。

@tab 3. 为什么关键词不能当变量？


会报错：`SyntaxError` 因为 `if` 已经被 Python 当作语法，而：


却不会报语法错误，因为：`print` 只是一个函数名。但是：

```python
print = 100

print("Hello")
```

会报错：

```python
TypeError: 'int' object is not callable
```

因为你把原来的 `print()` 函数覆盖成了整数。
