## 1. 数字型「int、float」

数字型就是常见的数字和小数，只不过在计算机编程中需要明确区分。

下面的代码，主要演示了如何使用 type 检测当前变量的数据类型，以及检测后赋值输出、或者检测时直接使用 print 输出。

### 1.1 代码示例

1. 整型

```python
int_num = 1
t = type(int_num)
print(int_num)
print("int num type is:>>>", t)
print("直接检测数据类型，并输出:>>>", type(int_num))

# output
1
int num type is:>>> <class 'int'>
直接检测数据类型，并输出:>>> <class 'int'>
```

2. 浮点数

```python
float_num = 1.5
t = type(float_num)  # 检测数据类型并把检测结果赋值给变量 t
print(float_num)  # 输出并查看原本的数据
print("float num type is:>>>", t)  # 输出检测结果
print("直接检测数据类型，并输出:>>>", type(float_num))  # 直接检测数据类型，并输出

# output
1.5
float num type is:>>> <class 'float'>
直接检测数据类型，并输出:>>> <class 'float'>
```

## 2. 字符串「str」

字符串（String）是一种用于表示文本数据的基本数据类型。在编程中，字符串是由一系列字符组成的字符序列，通常用于存储和处理文本信息。

### 2.1 代码示例

下面的代码演示如何创建字符串，主要是用的字母创建，当然其它的字符也是支持的，你可以尽情的去尝试自己的想法。

```python
string = "Hello Bornforthis"
t = type(string)
print(string)
print("string type is:>>>", t)
print("直接检测数据类型，并输出:>>>", type(string))

# output
Hello Bornforthis
string type is:>>> <class 'str'>
直接检测数据类型，并输出:>>> <class 'str'>
```

### 2.2 字符串三大特性

1. 有序性
    1. 从左到右，下标是从 0 开始；
    2. 从右到左，下标是从 -1 开始；
    3. 引号里面出现的每个字符都算一个下标；
2. 不可变性
    1. 不同的编程语言处理字符串的方式可能有所不同，但在大多数语言中，字符串都是不可变的，这意味着一旦创建，字符串的内容就不能改变。（辅助记忆：字符串被创建出来之后，就不能被改变）
    2. 注意⚠️：我们说的不可变，是指在**代码运行**的过程当中，不能有对字符串修改、添加、删除之类的操作；

3. 任意字符：
    1. 键盘⌨️上可以输入的字符，都可以是字符串的元素；
    2. 字符放到字符串中，都将成为字符串类型。「也就是：里面的每一个元素都可以称为：子字符（子字符串）」；

## 4. 元组「tuple」

Python 元组（tuple）是一种内置的数据类型，用于存储多个有序的元素。与列表（list）类似，元组也可以存储任意类型的元素，但与列表不同的是，**元组是不可变的**，一旦创建，元组中的元素就不能被修改、添加或删除。

### 4.1 代码示例

```python
tup = (1, 2, 3, 4, "aiyc", 1.1, [1, 2, 3, 4])
t = type(tup)
print(tup)
print("tup type is:>>>", t)
print("直接检测数据类型，并输出:>>>", type(tup))

# output
(1, 2, 3, 4, 'aiyc', 1.1, [1, 2, 3, 4])
tup type is:>>> <class 'tuple'>
直接检测数据类型，并输出:>>> <class 'tuple'>
```

### 4.2 元组的三大特性

1. 有序性
    1. 从左到右，下标是从 0 开始；
    2. 从右到左，下标是从 -1 开始；
        1. 元组里的每个元素算一个；
            1. 比如：`tup = ("aiyuechuang", 12)`；
            2. 上面👆tup 有两个元素，下标分别是：
                1. `aiyuechuang` 是下标 0（从左到右），也是下标 -2（从右到左）；
                2. `12` 是下标 1（从左到右），也是下标 -1（从右到左）；
2. 不可变性
    1. 元组被创建出来之后，就不能被改变；
    2. 注意⚠️：我们说的不可变，是在代码运行的过程当中，不能有对元组修改、添加、删除之类的操作；

3. 任意数据类型：注意⚠️，这里所说的任意数据类型，指的是 Python 所拥有的数据类型；

1. 如果存储的数据或数量是可变的，比如社交平台上的一个日志功能，是统计一个用户在一周之内看了哪些用户的帖子——那么则用列表更合适。
2. 如果存储的数据和数量不变，比如你有一个系统（软件），需要返回的是一个地点的经纬度，然后直接传给用户查看——那么肯定选用元组更合适。（因为经纬度是不会变的！）

## 6. 字典「dict」

Python 字典（Dictionary）是一种内置的数据类型，用于存储键值对（key-value pairs）。

### 6.1 代码示例

```python
d = {"name": "aiyc", "age": 18, 1: "int", 1.1: 1, "tup": (1, 2, 3)}
t = type(d)
print(d)
print("d type is:>>>", t)
print("直接检测数据类型，并输出:>>>", type(d))

# output
{'name': 'aiyc', 'age': 18, 1: 'int', 1.1: 1, 'tup': (1, 2, 3)}
d type is:>>> <class 'dict'>
直接检测数据类型，并输出:>>> <class 'dict'>
```

### 6.2 字典的特性

1. 无序性「Python 3.6+ 之后有序」
    1. 先以无序理解即可；
    2. 字典的有序，并不是上面（字符串、列表、元组……）那种常规有序；
    3. 字典的有序是指：字典中的键值对是有序的，有序前期基本用不到；（在同一个代码运行过程中，字典的键值对的顺序是固定的；）
2. 字典的组成：是由一系列的 key 和 value 组成。`d = {"key1": "value1", "key2": "value2".....}`
3. key：
    1. 不可变的数据类型，才可以当作字典的 key；
    2. 比如：字符串、数字（整数、浮点数）、布尔、元组都可以做为 key；
    3. 列表、字典、集合都不可以作为 key；
    
    > 澳洲 ANU 学生上课时修改，日期：2025 年 9 月 13 日
4. value：任意数据类型，Python 所拥有的数据类型；
5. 可变性：可以添加、修改、删除键值对；

## 7. 集合「set」

在 Python 中， **集合（set）** 是一种无序且不重复的元素集合。集合主要用于成员测试和消除重复元素，还可以用于数学上的集合操作，例如并集、交集、差集和对称差集。

### 7.1 代码示例

```python
set1 = {1, 2, "aiyc", 1.1, "book", (1, 2, 3), False}
t = type(set1)
print(set1)
print("set1 type is:>>>", t)
print("直接检测数据类型，并输出:>>>", type(set1))

# output
{False, 1, 2, 1.1, 'book', 'aiyc', (1, 2, 3)}
set1 type is:>>> <class 'set'>
直接检测数据类型，并输出:>>> <class 'set'>
```

### 7.2 集合的特性

1. 无序性：集合是没有顺序的，也就是：没有下标；

```python
set1 = {1, 2, "aiyc", 1.1, "book", (1, 2, 3), False}
print(set1)

# output
{False, 1, 2, 1.1, 'book', 'aiyc', (1, 2, 3)}
```

**注意：** 如果你运行集合很多次，或者其中某一次，集合顺序没有改变，我们也不能说集合是有序的。Why？你掷骰子，500次都是 6 点，你能说掷骰子是确定性事件吗？——显然是不行的🙅。

2. 确定性：
    1. 集合的每一个值都是确定的；（也就是需要不可变的数据类型）
    2. 比如：数字型、布尔、元组、字符串；
    3. 举个例子🌰：列表为什么不行？——列表可变，所以造成不确定性，故：不行🙅。

接下来我们来编写代码测试一下集合并加强理解集合的确定性，以及集合可以支持存放的数据类型：

```python

print(set1)

# output
{False, 1, 2, 1.1, 'book', (1, 2, 3), 'aiyc'}
```

上面的代码运行成功且正常输出，接下来我们放一个可变的数据类型来测试一下：

## 9. Python 基础类型函数使用方法

## 9.1 int()

#### 9.1.1 **基本用法**：将字符串转换为整数

最常见的用途是将字符串形式的数字转换为整数：

```python
# 将字符串转换为整数
num_str = "42"
num = int(num_str)
print(num)  


# ---output---
42
```

#### 9.1.2 **带进制的转换**：将字符串转换为不同进制的整数

`int()` 可以接收第二个参数 `base`，用来指定字符串的进制（默认为 10，即十进制）。

```python
# 二进制字符串转换为整数
binary_str = "1010"
binary_num = int(binary_str, 2)  # base=2 表示二进制
print(binary_num)  # 输出: 10

# 八进制字符串转换为整数
octal_str = "12"
octal_num = int(octal_str, 8)  # base=8 表示八进制
print(octal_num)  # 输出: 10

# 十六进制字符串转换为整数
hex_str = "a"
hex_num = int(hex_str, 16)  # base=16 表示十六进制
print(hex_num)  # 输出: 10
```

#### 9.1.3 浮点数转换为整数

`int()` 还可以将浮点数转换为整数，它会去除小数部分，保留整数部分。

```python
float_num = 12.34
int_num = int(float_num)
print(int_num)  # 输出: 12
```

#### 9.1.4 默认参数的使用

如果 `int()` 没有接收到一个参数，默认会返回 `0`。如果给定参数，则转换该值。

```python
# 使用默认值
print(int())  # 输出: 0
```

#### 9.1.5 异常处理

如果传入的字符串无法转换为数字，`int()` 会抛出 `ValueError` 异常。你可以通过 `try-except` 语句来捕获异常。

```python
invalid_str = "abc"
try:
    num = int(invalid_str)
except ValueError:
    print("不能将该字符串转换为整数")
```

#### 9.1.6 忽略空格

`int()` 会自动忽略字符串中的前后空格。

```python
num_str = "   123   "
num = int(num_str)
print(num)  # 输出: 123
```

#### 9.1.7 转换带符号的字符串

`int()` 还可以处理带正负号的字符串。

```python
negative_str = "-42"
positive_str = "+42"
negative_num = int(negative_str)
positive_num = int(positive_str)

print(negative_num)  # 输出: -42
print(positive_num)  # 输出: 42
```

#### 9.1.8 使用 `int()` 解析二进制数据

在处理二进制数据时，可以将 `int()` 用作解析工具，比如从字节流中读取数据时，常常会用到 `int()` 来转换二进制数据。

```python
binary_data = b'\x01\x02'  # 字节流
int_data = int.from_bytes(binary_data, byteorder='big')
print(int_data)  # 输出: 258
```

#### 9.1.9 小结

- `int()` 用于将其他数据类型（如字符串、浮点数等）转换为整数。
- 可以通过第二个参数 `base` 指定转换的进制。
- 当字符串无法转换为整数时，会抛出 `ValueError`，需要使用异常处理机制。
- 可以通过去除浮点数的小数部分或将其转换为不同进制进行转换。





## 9.2 float()

#### 9.2.1 `float()` 是干嘛的？

`float(x)`：把 `x` 转成**浮点数**（小数）。

`x` 可以是数字、字符串、布尔值等；如果不传参数，`float()` 返回 `0.0`。

```python
float()        # 0.0
float(3)       # 3.0
float(3.14)    # 3.14
```

#### 9.2.2 最常见：把 int / bool 转 float

`int → float`

```python
float(10)   # 10.0
float(-7)   # -7.0
```

`bool → float`

Python 里 `True` 当 1，`False` 当 0：

```python
float(True)   # 1.0
float(False)  # 0.0
```

#### 9.2.3 把“数字字符串”转 float

1. **纯数字字符串**

    ```python
    float("3")       # 3.0
    float("3.14")    # 3.14
    float("-0.5")    # -0.5
    ```

2. **前后空白会被自动忽略**

    ```python
    float("  3.14 \n")   # 3.14
    ```

3. **科学计数法字符串（非常常用）**

    ```python
    float("1e3")     # 1000.0
    float("2.5e-2")  # 0.025
    float("-3E2")    # -300.0
    ```

4. **特殊值：inf / nan（字符串也能转）**

    ```python
    float("inf")       # inf 无穷的
    float("-inf")      # -inf 无穷小
    float("nan")       # nan 空
    ```

#### 9.2.4 不能转的情况

1. **空字符串 / 乱七八糟的字符串**

    ```python
    float("")        # ValueError
    float("3.1.4")   # ValueError
    float("abc")     # ValueError
    ```

2. **含“逗号分隔”的数字**

    ```python
    float("1,234.56")  # ValueError
    ```

    这种要先清理：

    ```python
    float("1,234.56".replace(",", ""))  # 1234.56
    ```

3. **None**

    ```python
    float(None)  # TypeError
    ```

#### 9.2.5 进阶：把字节串 bytes 转 float

如果是**数字内容的 bytes**（注意是 b"3.14" 这种）：

```python
float(b"3.14")   # 3.14
float(b"1e2")    # 100.0
```

#### 9.2.6 常见的“坑”与正确姿势

1. **浮点数精度问题（最经典）**

    ```python
    0.1 + 0.2   # 0.30000000000000004
    ```

2. **比较浮点数不要直接 `==`，用：**

    ```python
    import math
    math.isclose(0.1 + 0.2, 0.3)  # True
    ```

3. **金额/精确小数不要用 float**

    比如钱、精确计费，用 `decimal.Decimal` 更合适：

    ```python
    from decimal import Decimal
    Decimal("0.1") + Decimal("0.2")  # Decimal('0.3')
    ```

4. **`int("3.14")` 不行，但 `float("3.14")` 行**

    ```python
    int("3.14")      # ValueError
    int(float("3.14"))  # 3  （会截断，不会四舍五入）
    ```

    要四舍五入：[https://bornforthis.cn/column/Python-Programming-Course/P02-2-basequestion/radix_point.html](https://bornforthis.cn/column/Python-Programming-Course/P02-2-basequestion/radix_point.html)

    ```python
    round(float("3.14"))  # 3
    round(float("3.6"))   # 4
    ```
