你好，我是悦创。

上一讲，我们学习了通过可视化高效传递信息，塑造受众的感受。这一讲我们反过来，看看怎么防止别人操纵数据来误导我们。

首先要澄清一点，虽然我们使用了“操纵数据”这个说法，但是我们不关心动机问题，到底是有意欺骗、存心误导，还是水平不够犯了错误，我们不做判断和分别。我们就是从数据思维的角度，看看如何防止被误导，不管对方是有意的，还是无意的。

还要澄清的一点是，我们这里讨论的都是数据是真实的，只是被错误的使用造成了误导，不包括伪造数据的情况。

举个例子：

有一家印度的承包商接受印度政府的委托，负责为难民提供食物保障，包括提供日用品和生活保证品。但是，由于没有难民的确切人数，所以这家承包商说要多少钱，政府就得掏多少钱。可是支出看起来实在是太大了，于是就有人建议请统计学家帮忙。

统计学家瞄准了三样东西——大米、豆类食品和盐。如果一个人群的人数是稳定的，那么这三种食品的消费量就是基本稳定的，因此它们可以交叉印证。结果发现，盐估计出来的人数最少，大米估计出的人数最多。因为盐的价格低、总量少，所以没有人在这个地方夸大。而大米价格高、总量大，所以就有动机在这个地方做假账。

这个案例就是通过伪造数据来达到非法的目的，是技术水平最低的骗子。这就不属于我们这一讲讨论的内容。利用真实的数据，通过各种操作手段误导人，才是技术含金量比较高的工作。我们这一讲主要讨论这个方向。

**<span style="color:orange">通过操纵数据来误导受众大致有三个方向，分别是操纵数据的使用、操纵数据的产生和操纵数据的解释。</span>**

## 1. 操纵数据的使用

这方面的案例太多了，给你举几个例子：

### 1.1 用平均数掩盖分布

“某公司有 3003 名股东，平均每人持股 660 股。”误导你的真相是这样的：公司总共 200 万股，其中 3 名大股东持有 3/4，其余 3000 人总共持有 1/4。

先说结论：👉 **“平均数”本身没错，但在分布极度不均匀时，用平均数来描述整体，是一种典型的认知操纵。**

#### 1.1.2 表面说法为什么“看起来没问题”

原话是：“某公司有 **3003 名股东，平均每人持股 660 股**。”

我们来算一下：3003 × 660 ≈ **200 万股**

✅ 数学上**完全正确**

✅ 没有造假

✅ 没有算错

所以很多人第一反应是：“哦，大家差不多，挺公平的。”

#### 1.1.3 真正的结构是什么（关键）

但真实情况是：

- **总股数**：200 万股；
- **3 名大股东**：持有 **3/4（150 万股）**；
- **其余 3000 名股东**：合计 **1/4（50 万股）；**

我们拆开算👇

- 🔹 大股东：150 万 ÷ 3 = **每人 50 万股**
- 🔹 普通股东：50 万 ÷ 3000 ≈ **每人 167 股**

#### 1.1.4 关键对比（这一步最重要）

| 描述方式        | 听起来的感觉 | 实际情况     |
| --------------- | ------------ | ------------ |
| 平均每人 660 股 | 大家都差不多 | ❌ 极端不均   |
| 实际普通股东    | 被“平均”代表 | ❌ 被严重抬高 |
| 大股东真实持股  | 被“平均”隐藏 | ❌ 被严重压低 |

👉 **660 股既不代表普通人，也不代表大股东**

👉 它是一个**现实中几乎没人真正拥有的数字**

#### 1.1.5 为什么这是“操纵数据”，而不是“正常统计”

这里的操纵点在于：❌ 只给一个“平均数”。

但**刻意不告诉你分布**，这在统计学里叫：**用集中趋势掩盖离散程度**！

如果对方真的想让你“理解情况”，至少应该给：

- 中位数（普通股东更接近它）；
- 分布区间；
- 前 1% / 前 0.1% 的占比；

但他们没有。

#### 1.1.6 一个更直观的类比（秒懂）

想象一个班：

- 班里 **1 个人年收入 1 亿**；
- **99 个人年收入 5 万**；

平均收入是：（1 亿 + 99×5 万）÷ 100 ≈ **104 万**

然后告诉你：“我们班平均年收入 100 万，大家都很富。”

你会不会觉得被耍了？👉 **这和股东例子一模一样**。

#### 1.1.7 真正的问题不在“平均数”，而在“只给平均数”

⚠️ 平均数适合的前提是：

- 数据分布相对均匀；
- 或至少 **同时给出其他指标**；

当分布呈现**头部极端集中**时：**平均数 = 最容易被用来“洗白结构性不公平”的数字**。

#### 1.1.8 你可以怎么“反制”这种说法（实战用）

下次看到类似表述，直接问三句话之一：

1. **中位数是多少？**；
2. **前 1% 占多少？**；
3. **最低 50% 拿了多少？**；

如果对方答不上来——👉 **你已经赢了**。

### 1.2 用百分比掩盖规模

“霍普金斯大学 1/3 的女生嫁给了大学老师。”但其实，总共只有 3 名同学录取，其中 1 个人嫁给了老师。

一句话说清楚：**问题不在“百分比对不对”，而在“你被故意忽略了基数（总人数）”。**百分比本身是真的，但**规模太小**，导致结论**听起来很大、实际上没什么意义**。

#### 1.2.1 原句在“制造什么感觉”？

“霍普金斯大学 1/3 的女生嫁给了大学老师。”人脑会自动脑补出这样的画面：

- 霍普金斯大学（名校）；
- 很多女生；
- 三分之一 → 比例很高；
- 似乎是一个**有统计意义的社会现象**；

这句话**在心理上极具冲击力**。

#### 1.2.2 但真实情况是怎样？

“总共只有 3 名同学录取，其中 1 个人嫁给了老师。”

我们把数字写清楚：

| 项目           | 数值              |
| -------------- | ----------------- |
| 总人数         | 3 人              |
| 嫁给老师的人数 | 1 人              |
| 百分比         | 1 ÷ 3 = **33.3%** |

👉 **数学上完全正确**

👉 **统计意义几乎为 0**

#### 1.2.3 核心问题：被“掩盖”的是什么？

🔴 被掩盖的是：**样本规模（基数）**

这是典型的 **“用百分比掩盖规模”**：当你只说比例，不说总量，听者就会**默认一个“很大的基数”**。

但实际上：

- 3 个人 ≠ 一个群体；
- 1 个案例 ≠ 一个趋势；
- 33% ≠ 普遍现象；

#### 1.2.4 为什么这是“误导”，而不是“错误”？

这是最容易混淆的地方 👇

- ❌ **不是造假**（比例是真的）；
- ❌ **不是算错**；
- ✅ **是“选择性呈现信息”**；

这类话术的特点是：**让你得出一个“比事实本身大得多”的认知印象**。

#### 1.2.5 换个方式你立刻就能看穿

同一个事实，换种说法：

- ❌ **误导式**：霍普金斯大学 1/3 的女生嫁给了大学老师

- ✅ **诚实式**：当年只录取了 3 名女生，其中 1 人后来嫁给了大学老师

你感受到的“重要性”，是不是瞬间掉下来了？

#### 1.2.6 这类话术在现实中非常常见

你以后可以用一个**反制公式**来判断：**任何百分比 = 数量 ÷ 总量**，所以**先问：总量是多少？**

常见场景包括：

- 广告：「90% 的用户都选择了我们」；
- 自媒体：「50% 的程序员后悔学计算机」；
- 职场：「80% 的员工支持这项改革」；

**如果没告诉你样本规模，这个数字就不值得相信。**

一句话总结（可以记住）：**百分比描述“比例”，不描述“规模”；比例在小样本里，几乎没有意义。**

### 1.3 用短期波动代替长期效应

“卫生部最新公布，大雾的一周内伦敦市郊的死亡人数猛增至 2800 人。”这是因为大雾带来的吗？这个地方平均死亡人数如何？接下来的几周死亡人数又是如何？

#### 1.3.1 这句话表面在说什么？

> “卫生部最新公布，大雾的一周内伦敦市郊的死亡人数猛增至 2800 人。”

**表面含义**：

- 最近一周；
- 有大雾；
- 死亡人数很多（2800）→ **暗示**：大雾导致了死亡人数激增；

但注意：**这里还没有真正证明“因为大雾”。**

#### 1.3.2 关键问题一：2800 到底算不算“猛增”？

要判断“猛增”，**必须有基准**。

你至少要知道：

- 👉 **这个地区平时一周死多少人？**
    - 如果平时是 **2700 人** → 2800 根本不算异常；
    - 如果平时是 **1500 人** → 那才可能是显著上升；

👉 **没有“长期平均值”，单独一个数字是没有意义的。**

这就是典型的 **脱离背景的数据误导**。

#### 1.3.3 关键问题二：这是“一次性波动”还是“长期影响”？（核心）

这就是标题里说的：**用短期波动代替长期效应**

- **什么叫短期波动？**

    - 某一周、某几天的异常；

    - 可能由很多偶然因素造成：
        - 天气；
        - 流感季；
        - 医院统计延迟；
        - 周期性集中上报；
        - 老年人口集中去世；
    - 📌 **短期数据 = 噪声很多**。

- **什么叫长期效应？**

    - 如果大雾真的“致死”，你应该看到：

        - 不止一周高
        - 而是 **连续几周 / 一段时间** 都明显高于平均值

    - 也就是说，你需要问：

        > **接下来几周的死亡人数如何？**

        - 如果下一周、再下一周迅速回落到正常水平→ 更像是 **随机波动**；
        - 如果连续多周都显著偏高→ 才可能是 **环境因素造成的系统性影响**；

#### 1.3.4 为什么这是一个常见的“统计陷阱”？

这是新闻、营销、甚至论文中**非常常见的误导方式**：

错误推理链条是这样的：

1. 发生了一个事件（大雾）
2. 同一时间出现一个异常数字（死亡人数高）
3. **直接把两者因果绑定**
4. 不看前后、不看长期趋势

👉 这在统计学里属于：**“相关 ≠ 因果” + “以点代面”**

只看“大雾这一周死了 2800 人”，却不看**平时一周死多少人**、也不看**接下来几周的死亡趋势**，就断言“大雾导致死亡”，这是**用短期波动冒充长期效应**。

#### 1.3.5 一个极简类比（更直观）

- 你今天体重比昨天重了 1 kg
- 就说你“开始肥胖了”

但你没有看：

- 过去一年体重走势
- 接下来几天会不会回落
- 昨天是不是刚吃了火锅

👉 **单点异常 ≠ 趋势**

### 1.4 遗漏变化的原因

“最近 25 年，癌症死亡人数增多。”听起来吓人，但其实很多因素更有解释力。比如，以前很多病因不明的案例现在被确诊为癌症；尸体解剖成为常用方法，便于明确诊断；医学统计资料更全面；易发病年龄段人数增多。还有，现在的人数远远超过从前。

### 1.5 偷换概念

“某议员提议：我们可以让囚犯离开监狱，去住酒店，这样反而更便宜。因为囚犯一天的费用是 8 美元，而住酒店只要 7 美元。”但其实，这里的 8 美元指囚犯所有的生活费，但是议员拿来比较的仅仅是住酒店的房租。

### 1.6 定义不统一

几家平台都说自己流量第一，证据是平台播出的电视连续剧收视率第一。但是，各家的定义不一致，有的用平均收视率，有的用单集最高收视率，有的用首播重播合计收视率。

### 1.7 忽略测量误差

“李蕾的智商 101，韩梅梅智商 99，所以李蕾比韩梅梅聪明。”但是，任何测量都有误差，结果应该加上一个区间，比如 `±3%`。这样，李蕾和韩梅梅的智商范围有重合，不能断定谁比谁聪明。

### 1.8 差别过小没有现实意义

“某次大规模的智商测试结果，男生平均 106.1，女生平均 105.9。”即使这个差异在统计上存在，由于差异过小也没有现实意义。

### 1.9 参照对象不清

“这款榨汁机的榨汁功能增强了 26%。”这是跟谁比？如果是跟老式手摇榨汁机比呢？

### 1.10 比较时忽略基数

“高速公路晚上 7 点的事故是早上 7 点的 4 倍，所以早上出行生还几率高 4 倍。”其实，晚上事故多，只是因为晚上高速公路上的车和人更多。

### 1.11 对象不同强行比较

“美国和西班牙交战期间，美国海军的死亡率是 9‰，同时期纽约市居民的死亡率是 16‰，所以海军士兵更安全。”其实，这两组对象不可比。海军主要是体格健壮的年轻人，而城市居民包括婴儿、老人、病人，这些人在哪里死亡率都高。

::: details 补充

表面上看，这是一种**合法的数值比较**：

- 海军死亡率：9‰
- 纽约市居民死亡率：16‰

**9 < 16**，所以结论似乎成立。

👉 **问题是：比较对象错了。**

### 真正的错误：把“不同类型的人”强行放在一起比

- **1️⃣ 海军士兵是什么人？**

    海军并不是“随机抽取的人”，而是**被严格筛选过的人群**：

    - 年龄：主要是 **年轻人**

    - 身体：必须 **健康、体能达标**

    - 性别比例：几乎全是 **成年男性**

    - 职业要求：不能有严重疾病或残疾

    👉 换句话说：**他们本来就是死亡率最低的一类人。**

- **2️⃣ 纽约市居民包含谁？**

    纽约市居民是一个**“全人群集合”**：

    - 婴儿（新生儿死亡率高）
    - 老人（自然死亡率高）
    - 慢性病人、残疾人
    - 贫困者、无医疗保障者
    - 各种年龄、健康状况的人

    👉 这是一个**天然死亡率就高得多的群体**。

### 关键点一句话总结（非常重要）

❗ **你不能把“精英子集”和“全民集合”直接比死亡率。**

这就像：拿「奥运运动员」去比「一个城市的全部居民」

然后得出结论：“当运动员更安全”，这当然是**废话级结论**。

### 那“正确的比较方式”应该是什么？

- **✅ 方法 1：同类人对比（最重要）**

    比如：20–30 岁男性海军士兵 vs 20–30 岁男性纽约市居民。

    如果这时发现：

    - 海军：9%
    - 平民：4%

    那你才能说：**战争环境提高了死亡风险**

- **✅ 方法 2：分层比较（统计学叫“控制变量”）**

    把人群按以下因素拆开：年龄、性别、健康状况。

    在**每一层内部**比较，而不是一锅端。

:::

### 1.12 变换基数让人产生幻觉

50% 折扣再打 20% 折扣，会让你以为有 70% 的折扣。实际上，折扣只有 60%，因为后面 20% 的折扣是用 5 折后的价格计算的。

### 1.13 用数字游戏控制听众感觉

投资回报率第一年为 3%，第二年为 6%。下面两个说法都是对的：

1. 提高了 3 个百分点；
2. 增长高达 100%。

怎么呈现，取决于你要让听众感受到什么。

## 2. 操纵数据的产生

这方面的案例也很多，比如：

1. **算法采用的规则有差异**

    试验用两种算法来判断交通违规行为：

    - 一种是“严格遵守法律条文”，简称条文版，车速一过线就开罚单。
    - 另一种是安全原则，如果车速在当时的状况下是安全的，就不判罚。比如周围没有车，或者大家速度都很快，你慢下来就是一个移动的石头，反而对安全不利。这种规则能“准确反映法律意图”，因此简称意图版。

    试验做下来，同样的交通状况，条文组的算法开出了 500 张罚单，而意图组的算法只开出了 1 张罚单。你说，交通违规的现象是严重还是不严重呢？

    ::: details 补充

    #### 1. 先把两种算法“翻译成人话”

    - **① 条文版（规则至上）**

        - 判断标准：**有没有违反字面规则**
        - 不管环境、不管后果
        - 不管环境、不管后果

        它回答的是：**“你有没有违反这条写在纸上的规则？”**

    - **② 意图版（安全至上）**

        - 判断标准：**行为是否真的危害了交通安全**

        - 会考虑：

            - 周围有没有车
            - 整体车流速度
            - 你慢下来会不会反而更危险

            如果行为在当下是安全的 → 不罚

        它回答的是：**“你的行为有没有违背这条法律想要保护的目标？”**

    #### 2. 为什么结果会差 500 倍？

    同一批交通行为：

    - 条文版：**500 张罚单**

    - 意图版：**1 张罚单**

    这里的关键不是算法“准不准”，而是：**它们根本在回答两个不同的问题**。

    | 算法   | 实际在统计什么       |
    | ------ | -------------------- |
    | 条文版 | “规则被触碰的次数”   |
    | 意图版 | “真实危险行为的次数” |

    #### 3. 那问题来了：违规到底严重不严重？

    答案是——**这个问题本身没有唯一答案，除非你先说明“违规”是什么意思。**

    我们分别回答：

    - **✔ 按条文版定义，交通违规现象非常严重！**

        - 500 次越线

        - 规则被大量触碰

        - 执法尺度严格

    - **✔ 按意图版定义，交通违规现象几乎不存在。**

        - 只有 1 次行为真的威胁安全
        - 大多数司机是在“合理驾驶”

    但实际上：

    - 罚单 ≠ 危险
    - 规则违反 ≠ 法律目的被破坏

    这在很多领域都会出现：

    - 教育（作业没交 ≠ 没学会）
    - 医疗（指标异常 ≠ 病情严重）
    - AI 审核（违规词 ≠ 有害内容）

    不是“交通违规到底严不严重”，而是——“你用什么规则在定义违规？”

    - 条文决定了**统计结果**
    - 规则决定了**现实长什么样**
    - 数据并不是客观事实，而是**规则的投影**

    :::

2. **实验条件设置错误**

    有一份得了省级奖的论文，说阿胶的营养效果好，做法是先把老鼠搞到营养不良，然后给老鼠吃阿胶，结果各种数据都优于对照组。看起来，阿胶似乎真的有效，但是一看对照组，只给那些营养不良的老鼠喝清水。这相当于给东西吃和不给东西吃的区别，而不是阿胶和普通营养方式的区别，实验结论当然不可靠。

    为了防止杠精，我强调一下，我是说这篇论文的结论不可靠，不是讨论阿胶有没有营养。

3. **提问的次序影响回答者的选择**

    调查显示，向女性调查时，如果先提问关于服装广告的问题，再问一般性广告的问题，女性对广告的态度就更多是正面的。

    向一般人调查，类似的次序问题也存在。比如，先问婚姻生活是不是幸福，再问整体生活是不是幸福，回答者会自动把自己婚姻生活的感受排除，评价整体生活。反过来则相反。

## 3. 操纵数据的解释

还是举几个例子给你感受一下：

1. **归因错误**

    一位飞行教官非常自信地说，“批评使人进步，表扬使人退步。”因为教官发现，只要他表扬了学员，第二天学员的表现肯定会变差，批评学员就会反过来，第二天的表现会更好。

    实际上，这是一个回归现象。如果今天学员达到了被表扬的程度，就说明他今天的表现超过了自己的平均线，第二天向自己的平均水平回归是正常的。

2. **因果关系不成立**

    在印度，研究人员发现，看电视的人对男女平等的态度更加积极。这指示我们应该普及电视来改变印度农村地区对女性的态度吗？

    真实的情况是，教育程度好的人才买得起电视，而教育程度好的人对男女平等的态度更开明。经常看电视与男女平等积极的态度之间不是因果关系，而是伴随关系。

3. **理论适用错误**

    网上有段子说，汉朝是 8000 人养 1 个公务员，唐朝是 3000 人，明朝是 2000 人，清朝是 1000 人，而今天是 18 个人，暗示这个时代的公务员太多了。

    这个错误是没有条件地按比例放大或缩小。随着人口规模的上升，公共服务需要的人数不是按线性比例增加的，应该是按几何程度增加的。只有在合理的理论框架下，才能评价 18 个人养 1 个公务员是多还是少。
