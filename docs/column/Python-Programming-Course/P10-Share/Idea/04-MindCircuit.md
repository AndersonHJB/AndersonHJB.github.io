## 1. idea 💡

- [x] 直接支持用户分享设计的游戏地图 json，支持张贴；
- [ ] 「new P」迷宫游戏
- [x] 游戏添加音效，用户可以选择关闭或者启动音频；
- [x] 游戏的棋盘可以整大一些；
- [x] 棋盘用户可以自己选择大小，网页初始化时，自动适配当前屏幕比例；
- [x] 目前游戏的最佳路径，是错误的，忽略了障碍物的存在；
- [x] 程序指令块支持直接拖动；
- [ ] 实现金币玩法；
- [x] 闯关可以自己选择，类似游戏地图展示出来；
- [ ] 不要把最佳路径指令缓存进去，而是用户自己的闯关指令（待定｜思考）
- [x] 需要保证棋盘格子要统一大小，不要被障碍物等不停变换大小；
- [x] 游戏增加限时功能，支持用户是否开启。创造模式中，也同样支持是否开启计时以及计时时间设置；
- [ ] 过关后，可以选择把过关弹窗关闭；
- [ ] 在创造模式下，当地图尺寸超过 7x7 时，缩小机器人尺寸，以适配小格子；
- [ ] 计时开始，需要有倒计时提示音；
- [ ] 支持制作多个连续关卡导入，变成个性化闯关模式；
- [ ] 制作关卡 json 格式要求，可以借助 AI 进行批量生成关卡；
