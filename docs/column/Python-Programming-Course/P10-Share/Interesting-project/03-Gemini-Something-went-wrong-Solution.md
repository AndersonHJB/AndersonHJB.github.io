## 1. 方法一：手机端试用

没有别的方法，只能选择手机使用：Gemini，用几天后再次尝试给网页版。

当然，有网友说给你谷歌 help 发邮件，过几天就会好。也可以考虑试一试，不知道具体结果怎么样。



## 2. 方法二：邀请新入制

这个方法最快速，最省时间，但是需要花些钱。那就是：开会员，不过 Gemini 支持邀请体验。可以让已经是 Pro 会员的人，复制专属邀请链接给你。（每个人只能邀请 3 人，不知道会不会像 Sora 2 那样，过段时间就恢复邀请额度。）
