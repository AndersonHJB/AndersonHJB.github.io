### 做网站的过程中，就是探索一个复杂的体系结构如何诞生！

:::

记录自己所学的知识，只是网站功能之一。

首先，构建个人博客过程需要得到的进化是。分为两个种类：开源现成版、AI 持续迭代版（具有生命的成长性）

## 1. 开源版

- [x] 了解如何把开源的项目，为我们所用；
- [x] 了解在这样的实现目标下，每个软件、代码之间的互相调用（使用）的逻辑；
- [x] 无需深入研究每一个技术、软件，而是看自身是否可以抽象出整个网站的整体架构（可以做思维导图验证）；
    - [x] 也就是每个软件什么时候需要，什么时候要用，把以往学习过程中缺失的东西补全；
- [x] 逻辑、架构都要了熟于心，至于技术后期需要再进行深入；
- [x] vibe coding 强大，那么如果使用 AI 制作出来的网站。如何进行部署公开，这也是你接下来要掌握的；
    - [x] 流程内也可以部署静态网页；（public）

- [x] 实时记录生活、笔记、经历；
- [x] 这是你后期需要自检，也需要等你来补充；

## 2. AI 成长版本

成长顾名思义就是：结合 AI 让这个网站更好，持续的开发新的功能或修复潜在 bug。

- [x] 零技术基础的情况下，使用 AI 完完全全进行开发迭代的网站。
- [x] 在与 AI交互中最重要的是什么？——了解 AI 的工作流，我们要做领导者的角色，制定工作流。
- [x] 了解静态网站所有零成本的部署方式，包括不限于：GitHub、Vercel、Cloudflare Pages 等。（借助：Cloudflare Pages 带你体验首次使用部署的研究过程）
- [x] 熟悉 GitHub 的交互使用已经使用逻辑，强大的“百度网盘”！我的数据备份核心法则！
- [x]
