## 1. 目标

设计调研 skill

1. 图面尺寸：`2560*1080`
2. 品牌调性分析：输入品牌名称，分析历史产品矩阵，设计风格，并提取设计关键词4组，每组均为形容词
3. 竞品分析：根据不同设计风格唯独，分析5-6组核心竞品，提取竞品特征，寻找机会点
4. 关键词分析：根据输入的设计关键词ABCD分别寻找符合调性的图片，每张照片的色调分别参照R：G：B：来调整；每张图片尺寸为：`__*__`
5. 主题规划：根据关键词输出设计主题规划页，包含三套设计主题，并给出对应的中英标题（中文4个字），简介（中文20字）以内；
6. 用户画像根据对应的设计主题，分别生成对应的用户画像，包括用户形象图，和用户需求与示意图，以及用户基本特征描述（年龄、职业、收入、消费习惯等）

我一般创建 Skills 或项目都是下面的流程。
