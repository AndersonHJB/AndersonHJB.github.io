写一个程序: 判断一个数字是否是质数。

质数是一个只能被**2**或其本身整除的数字。例如，**7**，**5**，**19**，等等。

- 输入一个数字并赋值给变量 `number`。

- 如果该数可以被除，则打印 "不是质数"。否则，打印 "质数"。

一个整数
