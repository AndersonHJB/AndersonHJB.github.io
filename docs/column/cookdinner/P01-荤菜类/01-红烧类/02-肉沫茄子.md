## 2. 步骤

1. **料汁**：1 勺糖、2 勺醋、3 勺生抽、半勺老抽、1 勺蚝油、1 勺淀粉；

2. 准备好肉沫、大葱末、蒜末；

3. 茄子切成长条；

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/45/451b5250feffec39188f0fbfcc5fef756a77a1881e249bebe92ca4af31882c90.png" style="zoom:25%;" />

    :::

4. 茄子少吸油秘诀 1：加盐给茄子杀水；「加盐，翻拌均匀、等待 5 分钟」

5. 茄子少吸油秘诀 2：挤出茄子杀出的水分（可选：清水清洗一下）——>加入适量干淀粉，翻拌均匀，在茄子上面挂上薄薄一层就好；

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/1c/1cde74024fb9d39e07ce8097363178f6afab1da1a1753523f42f071fbf642a47.png" style="zoom:25%;" />

    :::

6. 茄子少吸油秘诀 3：油煎代替油炸；

7. 锅热，少油——>加入准备好的茄子——>保持大火——>煎至枣红色——>捞出备用；

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/9f/9fdc3ded681a79fbc3e86ee03c14cc6f0dc5e620a67f1476dd802cafa04c6c56.png" style="zoom:25%;" />

    :::

8. 锅热，加油——>加入肉沫——>炒至断生，加点花雕酒——>酒随肉走，顺着锅边淋下去——>加入小米辣，翻炒出辣味；

9. 加入大葱末和蒜末（茄子不配蒜，味道少一半）——>炒出香味，加入准备好的茄子——>加入准备好的料汁，翻炒均匀——>加入小葱花；

@tab 夏叔「肉沫烧茄子」准备淘汰！

原料：茄子750克+3克盐杀水；烧茄子料汁（花雕酒15克，酱油20克，米醋10克，老抽6克，蚝油30克，白糖3克，白胡椒粉0.2克，清水200克，淀粉10克）；五花肉末100克，姜末5克，蒜末15克，大葱末5克，郫县豆瓣酱15克，黄豆酱20克，香葱花10克。

## 1. 食材

| 圆茄子 | 五花肉粒 | 葱姜蒜末 | 郫县豆瓣酱 | 黄豆酱 |
| ------ | -------- | -------- | ---------- | ------ |

酱汁：花雕酒、酱油、米醋、老抽、蚝油、白糖、白胡椒粉、水、淀粉；

## 2. 步骤

1. 茄子长条——>加盐，翻拌均匀——>腌制 10 分钟——>清水清洗一下——>挤出水分；

2. 酱汁：花雕酒、酱油、米醋、老抽、蚝油、白糖、白胡椒粉、水、淀粉；

3. 锅热，加五花肉粒——>煎炒至美拉德反应——>加入：挤干水分的茄子——>加入：葱姜蒜末（蒜：放入 2/3，留 1/3）——>煎至茄子两头自然下垂——>加入：郫县豆瓣酱、黄豆酱；

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/3c/3c8e91fba5cb29384d7923cd9527e9a7d9d35ba86593dc6a65c1be0fd4538185.png" style="zoom:25%;" />

    :::

4. 加入提前准备好的酱汁，翻炒均匀；

5. 加入剩下的蒜末、葱花。
