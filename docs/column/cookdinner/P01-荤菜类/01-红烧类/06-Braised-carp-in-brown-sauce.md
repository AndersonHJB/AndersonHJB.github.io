## 1. 食材

| 食材名称 |      |
| -------- | ---- |
| 鲤鱼     | 盐   |
| 白酒     | 水   |
| 油       | 白糖 |
| 八角     | 花椒 |
| 干辣椒   | 姜   |
| 大葱     | 蒜   |
| 花雕酒   | 酱油 |
| 胡椒粉   | 醋   |





## 2. 步骤

:::: tabs

@tab Step1

去掉鱼嗓子眼的部位「鱼牙」

::: center

<img src="https://blog.images.bornforthis.cn/docs-images/sha256/4d/4d1ad2fe99ce5825e8413c6df4777a45a62b64ef71ba08d54609fc1d7d70a4cc.jpg" alt="03-红烧鲤鱼_0001" style="zoom:25%;" />

:::

@tab Step2

盐撒在鱼皮表面

::: center

<img src="https://blog.images.bornforthis.cn/docs-images/sha256/c7/c72f63b7db649b2785a75030ea4e3fc7ed3521c10e3a3b76b9c5d911620fe73e.jpg" alt="03-红烧鲤鱼_0002" style="zoom:25%;" />

:::

盐可以增大摩擦，白酒可以挥发腥味。去除掉鱼表面的粘液，鱼肚子里面也用盐酒的混合搓一搓。

@tab Step3

用水冲洗干净

::: center

<img src="https://blog.images.bornforthis.cn/docs-images/sha256/e0/e076943834b14c98f643525cdf6c0e33a288d2f6b44b7f446f8a061b2f91dd5e.jpg" alt="03-红烧鲤鱼_0003" style="zoom:25%;" />

:::

@tab Step4

**切花刀**

斜 45 度切进去，深及鱼骨。每五公分一刀，一直切到鱼尾。

::: center

<img src="https://blog.images.bornforthis.cn/docs-images/sha256/4e/4eef64cf21a762f3163dbc1c1f1cfbd52955bf6f28cf85ccf5d92086125b7b19.jpg" alt="03-红烧鲤鱼_0004" style="zoom:25%;" />

:::

> 两面都要

@tab Step5

剪鱼尾「做燕尾造型」

::: center

<img src="https://blog.images.bornforthis.cn/docs-images/sha256/3e/3e896ffc3e0a2e2c08eaeba8ce2edfe684c2b99dc27c18f7c6ad33bdbaac1427.jpg" alt="03-红烧鲤鱼_0005" style="zoom:25%;" />

:::

@tab Step6

油，润满锅底即可

::: center

<img src="https://blog.images.bornforthis.cn/docs-images/sha256/11/112f6160c4979ee08868cb81f5899779f4a57744c60bcbb41acb3e821ec2d7fe.jpg" alt="03-红烧鲤鱼_0006" style="zoom:25%;" />

:::

@tab Step7

盐，撒匀锅底。盐立在锅底，形成一个托举层，把鱼可以拖起来，这样鱼就不粘锅

::: center

<img src="https://blog.images.bornforthis.cn/docs-images/sha256/e7/e737d41fa6beb5ad990963c104e02e7a3c80367a896e40d70a9af3d82b7dc4b2.jpg" alt="03-红烧鲤鱼_0007" style="zoom:25%;" />

:::

@tab Step8

油温冒烟的状态，6～7成热直接下鱼，刚下锅的时候别动鱼🐟让鱼定型定型

<img src="https://blog.images.bornforthis.cn/docs-images/sha256/2b/2b2836c85c1593d5abd297be8ce67f153bc8de90da524ba731f0f920b2bff1dc.jpg" alt="03-红烧鲤鱼_0001" style="zoom:25%;" />

:::: tabs

@tab Step9

转一转锅，让鱼在锅里均匀受热。一面定住了，煎另外一面；煎到两面均匀后、定型，关火🔥出锅。

::: center

<img src="https://blog.images.bornforthis.cn/docs-images/sha256/0f/0fb9c119f6687532358e121f257a7b2cc4649a5e880492de2c179dc1f49646c0.jpg" alt="03-红烧鲤鱼_0002" style="zoom:25%;" />

:::

@tab Step10

洗锅，开始红烧；

@tab Step11

锅里加油，油热，加入五花肉；「给鱼整香」

肉片把它煸香

<img src="https://blog.images.bornforthis.cn/docs-images/sha256/13/139ba12ff44e6d0a70a5c038bfa06b2aa87e9f9f6dca1fbea0b1670d27b2a6e3.jpg" alt="03-红烧鲤鱼_0003" style="zoom:25%;" />



@tab Step12

加入糖，炒出焦糖的颜色和香气

::: center

<img src="https://blog.images.bornforthis.cn/docs-images/sha256/91/9170a6378a0711b0b114196b2f1354451597d42bd977fc0c6ae7fbaa3b23948f.jpg" style="zoom:25%;" />

<img src="https://blog.images.bornforthis.cn/docs-images/sha256/d5/d5098f86ed0d26d6c1f687f48ab2e11970663d6ed620a79156c9f327360123f4.jpg" style="zoom:25%;" />

:::

@tab Step13

加入香料：八角、花椒、干辣椒，炒出香气

::: center

<img src="https://blog.images.bornforthis.cn/docs-images/sha256/b7/b71a135f43e044f71d6fd563bad399ba6f59877166f0880e9e21151a792f8d51.jpg" style="zoom:25%;" />

:::

@tab Step14

加入大块的大葱、姜、蒜块，随着焦糖的颜色越来越深。

::: center

<img src="https://blog.images.bornforthis.cn/docs-images/sha256/fa/fae050c5ee6c50618bbfa21717b457a61db6608aa319f42e90259e6d1b02fc90.jpg" style="zoom:25%;" />

:::

@tab Step15

加入花雕酒「料酒」、酱油。

酱油的豉香，伴随着花雕酒的酒香，已经充满了我们的鼻腔。

**加入水，大火烧开。**

- 加盐
- 加胡椒粉
- 醋少一点，起到去腥的作用
- 味道调好了，把鱼下锅
- 开锅之后，把火🔥调整到中火的状态「千滚豆腐万滚鱼」
- 这鱼要在锅里烧一会，一边烧一边把热汤浇上去；
- 但是红烧鲤鱼全程不盖盖子，为什么呢？——看鱼是否熟了。就是筷子直接插入最厚的鱼肉，然后就可以了。看插入是否轻松，拔出来是否带肉。
- 最厚淀粉勾芡。
- 加入香油增香。
