## 1. 食材

| 菜椒 200g          | 土豆 500g       | 五花肉 200g  | 大蒜 15g    | 姜 5g        |
| ------------------ | --------------- | ------------ | ----------- | ------------ |
| **干辣椒（可选）** | **十三香 0.3g** | **生抽 20g** | **白糖 4g** | **蚝油 20g** |
| **老抽 5g**        | **鸡精 3g**     |              |             |              |

## 2. 步骤

1. **配料**：
    1. 生姜：切片；
    2. 蒜末：蒜末；
    3. 干辣椒切段；（可选）
2. **土豆**：切成小片、清洗几遍（洗掉表明的淀粉）；
3. **菜椒**：手掰成小片（类似土豆片）；
4. **五花肉**：切成硬币厚的薄片；
5. **炒制 1**：
    1. 锅热，正常油量，锅烧至冒烟，下入土豆；
    2. 不要直接翻炒，等十几秒再翻炒；
    3. 使用半煎半炒的方法，把土豆片炒制略微金黄；
    4. 炒到半透明状态，出锅备用；（把油滤干）
6. **炒制 2**：
    1. 锅热，少量油；
    2. 下入五花肉；
    3. 先大火炒至变白，然后转中火慢慢炒制略带金黄；
7. **调味 1**：
    1. 十三香 0.3g；
    2. 姜片、一半蒜末；
    3. 干辣椒段（可选）；
    4. 炒出香味；
    5. 锅边淋生抽，并翻炒均匀；
8. 倒入：菜椒，保持中火翻炒 1 分钟；
9. **调味 2**：
    1. 白糖 g；
    2. 蚝油 20g；
    3. 老抽 5g；
    4. 鸡精 3g；
    5. 翻炒均匀；
10. 下入：土豆片；
11. 转大火，爆炒 30s；
12. 倒入：剩下一半的蒜末；
13. 出锅；
