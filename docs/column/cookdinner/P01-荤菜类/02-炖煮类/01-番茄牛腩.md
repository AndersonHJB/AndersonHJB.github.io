## 2. 步骤

- **关键一：处理牛肉**

    1. 锅内冷水下入牛腩
    2. 烧开后，撇去浮沫
    3. 捞出备用

    **一定！！！要冷水下锅。才可以更好的去除牛肉的血水，做出来的牛肉不腥。**

- **关键二：番茄的切法**

    1. 一个番茄，一分为二；
        - 一半切小丁「小丁出沙」
        - 一半切大块「大块出形」

    这样做出来的好吃又好看。这个可是大厨的小秘诀。

- **关键三：烹饪的步骤**

    1. 起锅烧油
    2. 下入牛腩
    3. 煸炒到**表皮上色**
    4. 加 **葱、姜、八角、香叶、黑胡椒、糖、花雕酒、生抽**
    5. 充分炒香入味
    6. 下入**番茄丁**，翻炒至**软烂出汁**
    7. 加热水烧开
    8. 盖盖
    9. 小火炖一个半小时

    > 这牛肉炖之前，一定要炒一下，味道才会更香

    10. 到点开盖，加入**番茄块**
    10. 大火收汁
    10. 点缀上 **香菜**


好吃到连汤都剩不下！

@tab 2. 范大厨 2

## 1. 食材

| 牛腩     | 白酒     | 番茄     | 番茄酱 | 大葱 |
| -------- | -------- | -------- | ------ | ---- |
| **生姜** | **生抽** | **冰糖** | **盐** |      |

## 2. 步骤

1. 冷水，加入牛腩，静置半个小时；（去除牛肉中的血水）
2. 番茄切块、切碎；
3. 冷水下锅，大火烧开，撇去浮沫；
4. 关小火，那种似开非开的状态，泡 2～3 分钟；
5. 捞出牛肉；（可以考虑保留焯水的汤，后面当开水加入）
6. 锅热、加油——>下入：控干水的牛腩，翻炒一会——>下入高度白酒，让酒的挥发带走牛肉的腥膻味道；（炒到枣红色的状态）
7. 锅热加油——>下入葱姜——>炒出香味——>下入番茄块 and 番茄酱，炒到出沙——>下入生抽 20ml（顺着锅边）；
8. 下入牛肉——>翻炒均匀；
9. 下入第二次的生抽——>翻炒均匀；
10. 下入：开水；（没过牛肉）
11. 下入冰糖（可选）；
12. 倒到砂锅；（铁锅会出铁锈味）
13. 关成最小火，似开非开的状态，1.5h；
14. 加入：适量盐；
15. 香菜「可选」

@tab:active 3. 林述巍

## 1. 食材

| 牛腩     | 生姜     | 番茄       | 番茄酱 |
| -------- | -------- | ---------- | ------ |
| **白糖** | **开水** | **小香葱** |        |

## 2. 步骤

1. 番茄切块；
2. 姜末；
3. 凉水下入：牛腩，水开 3 分钟捞出牛腩；
4. 锅热加油——>下入白糖（炒糖色），熬到泛起绵密小泡的枣红色——>下入牛腩爆香；
5. 下入：姜米爆香；
6. 番茄一定要在锅里跟牛腩一起爆香；（下入番茄）
7. 下入番茄酱、鸡精、盐、开水；
8. 加入高压锅 20 分钟；
9. 回锅收汁；
10. 撒上一些香葱丝；
