## 1. 食材

| 鸡翅     | 鸡爪     | 玉米     | 胡萝卜     | 土豆     | 熟芝麻 |
| -------- | -------- | -------- | ---------- | -------- | ------ |
| **姜片** | **葱段** | **八角** | **干辣椒** | **香叶** |        |



## 2. 步骤

1. 鸡翅斜开两刀，鸡爪剪掉指甲；
2. 凉水、大葱、生姜、花雕酒、鸡翅、鸡爪，进行焯水去腥——>捞出洗净；
3. 酱汁：
    1. 3 勺生抽；
    2. 1 勺老抽；
    3. 1 勺蚝油；
    4. 2 勺豆瓣酱；
    5. 1 勺黄豆酱；
    6. 白糖少许；

4. 加油、大葱、生姜、蒜、干辣椒、桂皮、八角、香叶、花椒——炒香
5. 加入酱汁翻炒均匀
6. 加入开水
7. 10min 后加入胡萝卜、玉米、土豆
