## 1. 食材

:::

| 琵琶腿 6 个    | 青椒、红椒 | 土豆 | 葱姜蒜 |
| -------------- | ---------- | ---- | ------ |
| **郫县豆瓣酱** | **干辣椒** |      |        |

酱汁：黄豆酱 2 勺、蚝油 1 勺、生抽 3 勺、盐 1 勺尖、糖 1 勺、胡椒粉 1 克、香油 1 勺；

::: center

## 2. 步骤

:::

1. 琵琶腿进行切块，一个琵琶腿切成四块；

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/f1/f1f603b01f57967d6f00003fdb9e91da22adccf6d5e2682d8d04540560a7a42e.png" style="zoom:25%;" />

    :::

2. 剁好之后，再去清洗（可选：一盆清水，加盐、花雕酒，浸泡 10 分钟）——>清洗完成后，挤干水分；

3. 青红椒切成块、泡好的香菇对半切、土豆切薄一点，这样容易熟；

4. 准备：葱姜蒜；

5. 酱汁：黄豆酱 2 勺、蚝油 1 勺、生抽 3 勺、盐 1 勺尖、糖 1 勺、胡椒粉 1 克、香油 1 勺；

6. 锅热加油——>油热，加入鸡肉——>保持大火，鸡肉炒至全部变色——>把鸡肉往边上移，留出中间的位置。加入：干辣椒，稍微煸炒——>加入半勺郫县豆瓣酱，炒匀——>加入葱姜蒜——>花雕酒去腥增香——>加入调好的酱汁——>翻炒均匀；

7. 加入足量的热水，水开加入土豆、香菇——>盖上锅盖，转小火 10 分钟——>加入青红椒；

8. 转大火炒，进行收汁；

::: center

## 1. 食材

:::

| 鸡腿     | 青红辣椒   | 香菇       | 蚝油       | 黄豆酱 |
| -------- | ---------- | ---------- | ---------- | ------ |
| **生抽** | **黄冰糖** | **葱姜蒜** | **花生酱** |        |

**酱汁**：3 勺蚝油、1 勺黄豆酱、3 勺生抽；



::: center

## 2. 步骤

:::

1. 鸡腿切块、青红椒切块、香菇切块、土豆滚刀块；
2. 酱汁：3 勺蚝油、1 勺黄豆酱、3 勺生抽；
3. 焯水：水开关火，出锅清洗；
4. 空锅不放油——>15 克冰糖、加适量的油、中火🔥——>糖色出现小泡泡——>加入鸡肉、转小火、翻炒均匀——>加入：葱姜（蒜）、大火炒香；
5. 加入酱汁——>加入清水、没过鸡块——>水开之后加入：土豆、香菇「翻炒均匀」——>盖上锅盖、小火炖煮十分钟；
6. 加入 1 勺花生酱——>加入青红椒块；
7. 大火收汁；
