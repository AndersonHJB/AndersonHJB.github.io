## 1. 食材

| 鸡腿         | （半勺）十三香  | 1 片香叶     | 白芷半片      | 花椒 8 粒     | 柱候酱        |
| ------------ | --------------- | ------------ | ------------- | ------------- | ------------- |
| **海鲜酱**   | **蚝油**        | **老抽**     | **鸡精**      | **食用油**    | **绿辣椒**    |
| **红辣椒**   | **芹菜 1～2株** | **洋葱半个** | **香菇 2 朵** | **大蒜 6 粒** | **姜片 4 片** |
| **火锅底料** |                 |              |               |               |               |



## 2. 步骤

1. 4 个去掉骨头的鸡腿；
2. 鸡腿切小方块，不要切的太小，鸡肉一炒会缩水；
3. （半勺）十三香、1 片香叶、白芷半片、花椒 8 粒——>直接放入鸡腿当中；
4. 柱候酱 2 勺（李锦记）、海鲜酱 1 勺、蚝油 3 勺、老抽半勺、鸡精 1 茶勺、食用油 1 勺——>直接放入鸡腿当中；
5. 抓拌均匀！腌制 20 分钟；
6. 青椒、红椒：切块、切丝都可以；
7. 香芹（芹菜）切长段；
8. 半个洋葱切成丝；
9. 2 个香菇切厚片；
10. 大蒜 6 粒，从中间一分为二；
11. 准备 4 片姜；
12. 锅热烧油，下入姜片，姜片煎至边缘金黄；（砂锅比较推荐）
13. 下入：小四方块的火锅底料；（取其香味）
14. 火锅底料融化之后，下入鸡肉——>翻炒 4 分钟；（中火）
15. 加入：5 勺清水；（喜欢啤酒的，可以用啤酒代替）
16. 盖盖焖 3 分钟；
17. 倒入所有的配菜——>转大火翻炒 1 分钟；
18. 如果喜欢干锅的，现在就可以吃了。如果喜欢带汤的，开始加水。水不要加太多，足够煮面即可；
19. 水开之后下入喜欢的配菜：金针菇、方便面饼；

@tab 范大厨

## 1. 食材

| 鸡翅中                 | 土豆     | 胡萝卜   | 芹菜       | 香菇           |
| ---------------------- | -------- | -------- | ---------- | -------------- |
| **洋葱**               | **蒜**   | **姜片** | **方便面** | **郫县豆瓣酱** |
| **火锅底料**（牛油版） | **啤酒** |          |            |                |



## 2. 步骤

1. 鸡中翅对半开——>清水清洗；
2. 土豆滚刀块、胡萝卜滚刀块、芹菜切段、香菇切片、洋葱切小块（丝）、蒜、姜片；（喜欢什么，加什么）
3. 料汁：
    1. 生抽 3 勺；
    2. 老抽 1 勺；
    3. 蚝油 1 勺；
    4. 甜面酱 1 勺；
    5. 胡椒粉 2 抖；
    6. 花雕酒 1 盖；
    7. 搅拌均匀；
4. 锅热加油——>等油热加鸡块，刚刚下锅的时候别动，等鸡翅定型——>动一动翻一翻，把鸡翅每个面都煎至焦黄；
5. 换砂锅：加油——>下入：洋葱、姜片、蒜——>炒出香味；
6. 下入：郫县豆瓣酱、一小块火锅底料；
7. 炒化、炒香——>加入：煎好的鸡块——>翻炒均匀；
8. 加入：啤酒、加入香菇；（大火烧开）
9. 关小火：炖煮 10 分钟；
10. 加入配菜——>开大火，把调好的料汁加入进去；
11. 大火烧开后，再关小火煮 5 分钟；
12. 下入方便面；
