## 1. 食材

| 菠萝 | 排骨 | 小葱 | 生姜 | 冰糖 | 迷迭香 |
| ---- | ---- | ---- | ---- | ---- | ------ |





## 2. 步骤

1. 凉水排骨下锅进行焯水；（加入：少量的盐、料酒） 
2. 菠萝切块、泡水+盐；
3. 锅热下油，微微冒油——>下入排骨，炒到排骨焦香——>下入一点冰糖（间接实现炒糖色）；
4. 炒到上色后，加入：料酒小半碗、蚝油适量、生抽适量、鸡粉一小勺、盐适量、放入姜、小葱；
5. 加入开水，大火烧开后，转小火炖煮；（40 分钟）
6. 下入：菠萝、迷迭香；
7. 到排骨软烂了之后，大火收汁；
