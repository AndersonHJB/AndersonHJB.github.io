## 1. 食材

| 腊肉     | 扁豆     | 大葱     | 小米辣       | 生姜 | 小葱段 | 花雕酒 |
| -------- | -------- | -------- | ------------ | ---- | ------ | ------ |
| **生抽** | **彩椒** | **大蒜** | **白胡椒粉** |      |        |        |





## 2. 步骤

1. 准备：姜片（两份）、小葱段、蒜片、大葱片、彩椒丝、小米辣圈；
2. 拿到腊肉，把拿温水清洗一下腊肉表面，接着用刀刮一刮腊肉的表面；（把多余的油脂刮掉）
3. 锅中热水，放入腊肉，下入：姜片、小葱段、花雕酒；（焯水 3 分钟（预估））
4. 捞出腊肉，把腊肉切成一块钱厚的片；
5. 扁豆斜刀切成丝（平行四边形）；
6. 锅热，下入一些花生油——>腊肉翻炒半分钟——>腊肉微微出油，把扁豆丝下入；
7. 翻炒到扁豆翠绿色后，下入：姜片、蒜片、大葱片；
8. 下入：花雕酒、生抽、蚝油、白胡椒粉——>翻炒均匀；
9. 锅边淋浇一些开水——>保持中火，盖盖，焖烧 1 分钟；
10. 保持最大火，大火收汁；
11. 下入：彩椒、小米辣；

## 3. 制作日期

- 日期：2025 年 10 月 28 日
    - 不要轻易尝试，味道评价：食之无味，弃之可惜。
    - 肉片切太厚，要切薄一些；
    - 油不能太多，要少。五花肉本身也会持续出油；
    - 小米辣可以考虑提前加入，炒出辣味！
