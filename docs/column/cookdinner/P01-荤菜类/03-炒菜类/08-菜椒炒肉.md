## 1. 食材

| 鸡蛋               | 绿菜椒 | 大蒜 | 大葱 | 盐   | 白糖 |
| ------------------ | ------ | ---- | ---- | ---- | ---- |
| **红菜椒**「可选」 |        |      |      |      |      |

> 青椒炒蛋 原料：青椒350克，鸡蛋4个，花生油35克，蒜蓉10克，大葱花10克，盐2克，白糖1克，松茸调味料2克，酱油15克，蚝油10克，香油2克。

## 2. 步骤

1. 准备蒜末、大葱末；
2. 拍一拍，直接手撕菜椒、还可以切一些红菜椒；
3. 鸡蛋搅碎；
4. 锅中加油（多一些），下入鸡蛋液煎制，出锅；（想要香一些，鸡蛋要煎制老一些）
5. 锅中少油，下入：蒜末、大葱末；
6. 下入：（绿红）菜椒，当菜椒更加翠绿的时候——>下入：适量的盐、（适量的白糖、味精（鸡粉）｜**可选**）；
7. 调味：酱油、蚝油、香油；（or 酱油、老抽、陈醋，调味后，加入两小勺热水、蚝油，稍微的煮软一会）；
8. 下入：鸡蛋，翻炒均匀；
9. 汁水多或者想要口感滑润一些的，可以选择性勾芡；
10. 出锅；
