## 1. 食材

| 鱿鱼     | 菜椒       | 红菜椒 | 小米辣 |
| -------- | ---------- | ------ | ------ |
| **洋葱** | **花雕酒** |        |        |





## 2. 步骤

1. **鱿鱼**：
    1. 交叉斜刀切；
    2. 锅中加水、花雕酒；
    3. 水开后加入鱿鱼；
    4. 鱿鱼卷起就捞出；
2. **切配菜**：菜椒切块、洋葱切块、小米辣切圈；
3. **炒制**：
    1. 油热，下入：配菜，炒至断生；
    2. 倒入鱿鱼；（可以淋锅边花雕酒）
    3. **调味**：少许盐、1 勺生抽、蚝油；
    4. 最大火翻炒出锅；
