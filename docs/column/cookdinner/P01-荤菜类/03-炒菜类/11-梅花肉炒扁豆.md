## 2. 步骤

1. **梅花肉**：可以适当冷冻，切薄片；
2. **扁豆**：
    1. 去掉头尾、清洗一下；
    2. 锅中加水、加盐，煮沸后：下入扁豆；
    3. 焯水：2～3 分钟；
    4. 捞出，并切成丝；（平行四边形）
3. **炒制**：
    1. 热锅凉油，下入梅花肉；
    2. 炒制断生，淋锅边花雕酒；
    3. 下入：扁豆丝，炒到变成翠绿色；
    4. 下入：蒜片、姜片、大葱片；
    5. 加适量：盐，翻炒均匀；
    6. 加适量：生抽，锅边淋入；
    7. 加入：蚝油、白胡椒粉，翻炒均匀、（白糖、鸡精可选，后期试一试不加怎么样）；
    8. 锅边淋浇一些开水——>保持中火，盖盖，焖烧 1 分钟；
    9. 保持最大火，大火收汁；（老婆喜欢有汁水一些）
