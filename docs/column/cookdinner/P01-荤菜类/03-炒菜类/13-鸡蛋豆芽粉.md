## 1. 食材

| 豆芽 | 鸡蛋 | 韭菜 |
| ---- | ---- | ---- |





## 2. 步骤

1. **粉条**：热水泡着；
2. **鸡蛋**：煎至块状；
3. **韭菜**：切段；
4. **炒制**：
    1. 锅热，下入豆芽；
    2. 炒出香味后，下入：韭菜；
    3. 翻炒均匀；
    4. 下入：鸡蛋、粉条；
5. **调味**：
    1. 盐；
    2. 生抽；
    3. 老抽；
6. **出锅**；
