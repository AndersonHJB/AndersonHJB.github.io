## 1. 食材

| 牛里脊               | 葱姜水（小葱 7g、姜 3g、清水 50g） | 大蒜 25g    | 小米辣                      |
| -------------------- | ---------------------------------- | ----------- | --------------------------- |
| **野山椒 30g**       | **香菜 70g**                       | **盐 1g**   | **鸡精 2g**                 |
| **白胡椒粉 0.2g**    | **小苏打 1g**                      | **老抽 3g** | **土豆淀粉 7g or 红薯淀粉** |
| **薄皮辣椒 or 菜椒** |                                    |             |                             |

## 2. 步骤

1. **准备葱姜水**：小葱、生姜、清水；
2. **牛肉**：
    1. 切薄片；
    2. 盐 1g；
    3. 鸡精 2g；
    4. 白胡椒粉 0.2g；（多了会臭）
    5. 小苏打 1g；（多了发苦）
    6. 老抽 3g；
    7. 抓匀，分次加入葱姜水，抓匀；（朝着同一个方向），肉片摸起来黏糊糊的，水当当的即可；
    8. 土豆淀粉 7g 或者红薯淀粉；
    9. 抓匀，到肉非常黏了，加入食用油 20g；
3. **配料**：
    1. 生姜切丝；（切碎都可以）
    2. 大蒜切片或者切粒都可以；
    3. 也山椒切小圈；（可选）
    4. 薄皮辣椒切成小颗粒，如果是菜椒切成小块；
    5. 小米辣，斜着切圈；
    6. 香菜要多，切成小段；
4. **炒制**：
    1. 热锅凉油，油可以稍微多一些；
    2. 下入牛肉，炒散，出锅备用；
    3. 下入：姜、蒜、泡椒，翻炒均匀；（锅中本来就有油）
    4. 翻炒出香味后，下入：青红辣椒（菜椒、小米辣）；
    5. 保持最大火，翻炒均匀后，下入牛肉；
    6. 锅边：生抽 10g、蚝油 10g、白糖 2-3g；
    7. 翻炒均匀后，下入：香菜段；
    8. 关火出锅！
