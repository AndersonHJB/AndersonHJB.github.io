## 1. 用料

| 猪肉         | 生姜       | 玉米淀粉 | 豆皮或者薄饼 | 鸡蛋清 | 盐       |
| ------------ | ---------- | -------- | ------------ | ------ | -------- |
| **白胡椒粉** | **花雕酒** | **香油** | **豆瓣酱**   | **糖** | **大葱** |
| **胡萝卜**   | **黄瓜丝** |          |              |        |          |



## 2. 步骤

### 2.1 肉的准备

1. 切丝（肉丝）「横切牛羊，竖切猪」，与耳机线一样粗细；
2. 清水清洗切好的肉丝；
3. 1g 多的盐、白胡椒粉、花雕酒 10ml——>一边搅、一边抓匀；
4. 加半个鸡蛋清——>抓匀；「上浆如同穿衣服，一件一件的穿」
5. 加淀粉 5g 左右；
6. 「可选」加点水，来稀释淀粉。——>抓匀；（就是：你淀粉加多的情况下）
7. 最后来电油——这样下锅之后，可以快速分离不会粘成一坨，并且可以使浆上的更稳；

### 2.2 配料

1. 生姜——>拍松——>花雕酒（后续就不用再添加）——>加水——>再捏一捏姜「让姜汁的味道都释放出来」（酱不离姜 姜不离酱）（如果用姜末，会影响口感）（黄酒可以很好的激发酱香的香气，所以我们使用花雕酒）
2. 大葱、胡萝卜、黄瓜——>切丝
3. 豆皮或者薄饼

### 2.3 炒制

1. 锅烧热、加油；（油温不要太高，过高会给肉丝上色）
2. 加入准备好的肉，（将肉丝直接下锅）；
3. 感觉肉丝稍微定型了，再慢慢打散，炒匀；
4. 保证 3 的每一个肉丝都熟了，并且不粘了，肉丝出锅；
5. 小火，锅内底油放香油；（也可以普通油，后面再加点香油，省点香油）「油温不能太高」
6. 加入豆瓣酱 30g（甜面酱）；
7. 加入花雕酒 15ml「前面做生姜水时，如果有添加花雕酒，此时就不用添加花雕酒」
8. 老话说得好，浆不离姜，姜不离浆——>加入姜水；
9. 保持小火、搅匀；
10. 加糖；（给甜面酱去除涩口的味道）
11. 搅动浆，快速出现酱香气——粘稠状态「炒到酱入锅之前的状态」
12. 炒熟的肉丝下锅，目的就是让酱汁都包裹在肉丝上。
13. 「可选」而酱爆炒的菜，需要使用香油来增香，如果一开始使用的是香油，就不用加。如果使用的是其它油，这步就要添加；
14. 没有多余的油，没有多余的酱，没有多余的汁——这叫手艺
15. 齐活，咱出锅；



### 2.4 摆盘

1. 肉丝+大葱丝+豆皮（薄饼）
