## 3. 制作顺序

1. 猪小排——>直接煎，不要焯水！——>煎至两面金黄（美拉德反应）——>黄酒淋浇（激发出肉香味道）「可以换大锅」
2. 加入配料：八角、桂皮、白芷、老冰糖、葱、姜、蒜；「可以稍微的翻炒一下」
3. 倒入酱汁：3勺花雕酒、4勺酱油、5 勺糖、6勺米醋；「再次稍微翻炒」
4. 热水、老抽调色——>小火焖烧45min（可以选择高压锅）
