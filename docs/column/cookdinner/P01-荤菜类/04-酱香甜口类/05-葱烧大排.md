## 1. 食材

| 猪里脊两斤 | 小葱300克  | 葱       | 姜       | 盐           | 料酒     |
| ---------- | ---------- | -------- | -------- | ------------ | -------- |
| **糖**     | **白胡椒** | **老抽** | **鸡蛋** | **玉米淀粉** | **生抽** |

**葱烧大排：**

- 猪里脊两斤，小葱300克；
- 腌制：葱姜水100毫升（葱30克姜10克盐1克，水100毫升），盐5克，糖20克，白胡椒1克，老抽10毫升，鸡蛋一个，淀粉30克。
- 酱汁：料酒10毫升，老抽10毫升，生抽50毫升，水100毫升

## 2. 步骤

1. 大里脊切厚块，如果有筋膜就把筋膜进行切开，否则煎的时候会鼓起来；

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/c1/c17d3f320e4a839bacc7d9dc5dade092532c8b9bde702d137b41284f097328ea.png" style="zoom:25%;" />

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/af/af624821f0911f6907ded05a982e0231acf64067628eec959dd3677d524ded29.png" style="zoom:25%;" />

    :::

2. 猪排嫩的关键 1：

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/a5/a5d9f7e5650638641a1e07d7ef873cb9b70b04d87fead877c2cb6d2ef2223e02.png" style="zoom:25%;" />

    :::

3. 关键 2：拍大

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/7c/7c61feb58ffd4f9aaa0b6353c1d6672557b10ed0738e694fb5dccaf38a7ea25c.png" style="zoom:25%;" />

    :::

4. 葱姜水汁：葱（30g）、姜（10g）、盐（1g）、水（100 ml）——>倒入猪排抓匀；

5. 加入：盐5克，糖20克，白胡椒1克，老抽10毫升，鸡蛋一个——>接着抓匀；

6. 加入：玉米淀粉30克——>抓匀；

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/7c/7cc02e40bb43bf89e0ab64e898a1b304c73ade4e0a2a1f7357c25625aa68d1a1.png" style="zoom:25%;" />

    ::: 

7. 油热，把葱白煸炒一下，这样油就变成葱油：

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/14/144ad4651f96b82980a9004000ef2930599932765e67ca7477fcac6c81129fda.png" style="zoom:25%;" />

    

    :::

8. 捞出葱白，煎大排 4～5min：

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/43/43a12e565a90b9f232f18e8b2a48c594104c25039d606089e9d9e91657145548.png" style="zoom:25%;" />

    :::

9. 煎好大排，锅里还有油。加入葱叶：

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/39/39899ff74b6141e4ec92d8daa6239475ecfdbdb9ba4fc3aeda3364e9e56897c1.png" style="zoom:25%;" />

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/33/3318fe79c16c80f3f3c2ff8c0a68e5445013128a451d0490a9cb0a680ae0999c.png" style="zoom:25%;" />

    :::

10. 铺上大排

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/3f/3f1d4cdeb5ac98e645cf5fc4f1a6e64eb88897a853d9d5e42647c628ed912499.png" style="zoom:25%;" />

    :::

11. 加入料汁：料酒10毫升，老抽10毫升，生抽50毫升，水100毫升；

12. 中火炖煮 10 分钟；

13. 出锅，开吃。
