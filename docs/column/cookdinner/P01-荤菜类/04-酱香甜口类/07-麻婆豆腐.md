@tab 范大厨版

## 1. 食材

| 南豆腐         | 盐                         | 四川大红袍花椒 | 牛肉末     |
| -------------- | -------------------------- | -------------- | ---------- |
| **郫县豆瓣酱** | **永川豆豉**               | **辣椒粉**     | **大葱**   |
| **生姜**       | ~~**蒜**（原本菜谱没有）~~ | **玉米淀粉**   | **酱油**   |
| **糖**         | **老抽**                   | **味精**       | **青蒜苗** |



## 2. 步骤

1. **豆腐**：

    1. 豆腐切小块，注意⚠️：不要切太大，否则不容易入味；
    2. 豆腐焯水：锅中烧开水，加入：豆腐、盐、（老抽、生抽，随意，上色用）；
    3. 转小火，烧开 2 分钟左右，去除豆腥味；
    4. 豆腐焯水之后，不用马上捞出来，泡在热水中，这就是麻婆豆腐烫的来源！

2. **麻**：

    1. 炒花椒，锅里不要下油；
    2. 下入：花椒；
    3. 小火慢慢焙炒，一定不要急！等花椒红色变淡，就可以拿起一粒花椒，一捏一揉就碎，就可以了！
    4. 用擀面杖，擀碎即可；

3. **香、酥**：

    1. 牛肉剁碎；

    2. 热锅凉油；

    3. 下入牛肉末，把牛肉炒到失水的状态，牛肉有些许上色了；

        ::: details 这样的牛肉吃起来，才有酥酥的口感。

        <img src="https://blog.images.bornforthis.cn/docs-images/sha256/e1/e1350bfe0e0073ea8526ec52a6d09df551981cd06392d58accc69c6088bd1a1a.png" style="zoom:25%;" />

        :::

4. 把牛肉往旁边扒开，下入：永川的豆豉、郫县豆瓣酱——>炒出红油；

5. 接着下入：

    1. 辣椒粉 3g，提升辣的味道；
    2. 葱姜末 15g；~~（考虑：要不要加蒜末）~~
    3. 花椒粉 3g（加入一半）；（提前准备的，不要把准备的花椒粉全加了！）

6. **豉香味**：

    1. 锅边酱油 20ml；
    2. 水 150ml；
    3. 糖 10g；
    4. 老抽 5ml；
    5. 味精 2g；

7. 下入豆腐，煮 5 分钟；（千滚豆腐，万滚鱼）

8. 勾芡：

    1. 第一次勾芡：使汤汁浓稠；（适当推一推豆腐）
    2. 第二次勾芡：使汁水包裹住豆腐；
    3. 第三次勾芡：让汤汁里面的油脂分离出来，形成一个保护层；

9. 最后出锅保持麻婆豆腐的烫，撒下剩余的花椒面、青蒜苗；

## 3. 制作感受

- 日期：2025 年 11 月 1 日
    - 制作时不要刻意追求辣，郫县豆瓣酱不要加太多，正常添加出红油即可；

@tab 野驴版

## 1. 食材

| 老豆腐 | 花椒 | 青蒜「40g」 | 生姜「10g」 | 大蒜「10g」 | 郫县豆瓣酱「30g」 | 豆豉「10g」 |
| ------ | ---- | ----------- | ----------- | ----------- | ----------------- | ----------- |
|        |      |             |             |             |                   |             |



## 2. 步骤

1. **准备花椒末**：锅烧热至冒烟，关火倒入花椒，炒到适当变色就可以。使用装入保鲜袋中，擀面杖碾碎备用；

2. **备菜**：

    1. 青蒜苗的蒜白部分，斜刀切。蒜苗部分，切小段即可。（分开放）

        ::: details

        <img src="https://blog.images.bornforthis.cn/docs-images/sha256/a2/a2e9d290e219b487eb3defeba44cf54f9bd23b01760643c43f5884d40e394c13.png" style="zoom:25%;" />

        <img src="https://blog.images.bornforthis.cn/docs-images/sha256/a3/a3096e986dd4089d17b391be3bdb9075fa19376f0b354ec2549dd687718ee327.png" style="zoom:25%;" />

        :::

    2. 准备蒜末、姜末，（蒜姜分开放，量不用太多）把郫县豆瓣酱+永川豆豉用刀切碎；

    3. 豆腐切块（不要切太大）；

3. **豆腐焯水**：锅中烧开水，加入：盐（底味）、老抽（上色）；（水开下入豆腐，水开煮一分钟）（焯水后不要捞出锅）

4. **炒牛肉末**：

    1. 热锅凉油，转小火，下入牛肉粒，等牛肉粒炒散就可以转大火；
    2. 先下入一半的姜末；
    3. 1/3 勺的料酒 或 黄酒，翻炒均匀；
    4. 1/3 勺生抽；
    5. 出锅备用；

5. **开始炒制**：

    1. 锅中加油，油可以多一些；（不然豆瓣酱、豆豉炒不透）
    2. 大火：油热，下入姜蒜末，炒出香味；（传统麻婆豆腐是不加大蒜的）
    3. 转小火：下入准备好的郫县豆瓣酱+豆豉——>炒出红油；
    4. 下入：干辣椒面、辣椒粉（可选｜为了颜色）；
    5. 加入一碗半的清水；
    6. 汤底调味：白糖 5g、味精 3g、鸡精 3g；
    7. 烧开之后，下入豆腐、青蒜头；
    8. 保持大火炖煮 4～5 分钟；
    9. 适量加盐调味；
    10. 第一次勾芡，翻炒均匀后，加入：牛肉碎；
    11. 第二次勾芡，撒入：青蒜苗（叶）；
    12. 第三次勾芡出锅；
    13. 淋入自制的：花椒面；




@tab 夏叔版

## 1. 食材

|老豆腐|花椒|||

## 2. 步骤

1. **准备**：蒜末、姜蒜、「可选」高度白酒浸泡一下干辣椒；
2. **豆腐处理**：
    1. 豆腐切块；
    2. 焯水加盐；
    3. 连焯水的汤一起出锅备用（汤保持温度）；
3. **准备香料**：
    1. 锅热加油，下入花椒进行翻炒出香味；
    2. 下入：二荆条干辣椒，翻炒到红褐色；
    3. 出锅使用捣碎器捣碎；
4. **炒牛肉粒**：
    1. 锅中菜籽油，放入牛肉粒；
    2. 翻炒出酥香的时候，淋入一些花雕酒；
    3. 取出一半牛肉备用，一半留锅底；
5. **正式开炒**：
    1. 锅中剩下的牛肉，下入：姜末、蒜末，炒出香味后；
    2. 下入：郫县豆瓣酱，炒出红油后，下入：豆豉；
    3. 下入：辣椒面；
    4. 加入：牛肉汤（没有加开水吧）；
    5. 下入：滤干的豆腐；
    6. 下入：前翻炒的香料；
    7. 勾芡（凤凰三点头）：
        1. 一点：高山流水；（第一次勾芡）
        2. 二点：波涛澎湃；（第二次勾芡）
        3. 下入：青蒜、之前取出的半碗牛肉粒；
        4. 三点：万马奔腾；（第三次勾芡）
