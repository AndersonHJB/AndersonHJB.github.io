## 1. 食材

| 干香菇   | 鸡腿     | 料酒     | 生抽     | 生粉 |
| -------- | -------- | -------- | -------- | ---- |
| **大葱** | **生姜** | **大蒜** | **白糖** |      |



## 2. 步骤

1. **香菇**：
    1. 干香菇温水泡发；
    2. 泡好的香菇轻轻挤干水分；
    3. 切条备用；
2. **鸡腿**：
    1. 鸡腿去骨；
    2. 鸡腿肉，改刀切丁；
    3. 鸡皮可选去掉；
3. **鸡腿腌制**：
    1. 生抽；
    2. 料酒；
    3. 辣椒粉（可选）；
    4. 少量生粉；
    5. 抓匀上浆；
    6. 腌制 30 分钟；
4. **配料**：
    1. 大葱末；
    2. 姜末；
    3. 蒜末；
5. **炒制**：
    1. 锅热加油；
    2. 下入鸡肉，只要鸡肉变色就马上出锅；
    3. 把油留在锅里；
    4. 下入：葱姜蒜炝锅，炒香；
    5. 下入：香菇、适量盐；
    6. 大火翻炒 1 分钟；
    7. 鸡肉回锅，翻炒 30 秒；
    8. 加锅边生抽调味；
    9. 适量白糖提鲜；

## 3. 制作记录

- 日期：2025 年 11 月 11 日

    辣椒可以稍微多一些些，后期可以试试加点水。鸡肉本身就会包含水分，葱姜蒜的时候可以油多一些试一试。感觉容易在吃恶心边缘试探，但是又挺好吃的感觉。其次，鸡腿的筋可以去掉。

    解冻的鸡腿估计会更好去掉骨头～

    为了好看，我最后添加了一些老抽，不知道没加老抽会怎么样？

@tab 小红书

## 1. 食材

| 鸡腿     | 香菇 | 小香葱 | 大蒜 | 新鲜香菇 |
| -------- | ---- | ------ | ---- | -------- |
| **生姜** |      |        |      |          |





## 2. 步骤

1. **鸡腿**：
    - 去骨，切块；
    - 2 勺生抽；
    - 1 勺料酒；
    - 2 勺蚝油；
    - 1 勺玉米淀粉；
    - 半勺黑胡椒粉；
    - 抓匀腌制 20 分钟；
2. **炒制**：
    1. 锅热加油；
    2. 下入鸡块炒制金黄盛出；
    3. 下入：葱蒜末炒香；
    4. 下入：香菇炒软；
    5. 倒入鸡块，翻炒均匀；
    6. 撒入香葱末；

**补充 1**：

1. 我没有鸡腿是用鸡翅对半切代替鸡腿。
1. 感觉香菇会淡，所以炒香菇的时候加了一点生抽和耗油，再下鸡肉。味道刚好。

**补充 2**：

我是腌鸡肉的时候加了两片生姜，炒香菇的时候没有再加料了，也超级好吃！
