## 1. 食材

- 大白菜；
- 干辣椒；
- 葱、姜、蒜；
- 料汁：1 勺淀粉、2 勺酱油、3 勺糖、4 勺醋、蒜末「出锅蒜·增加蒜香气」、一点点🤏香油；



## 2. 步骤

1. 大白菜：一拍、二开、三斜切；

    ::: details

    1. 松松筋骨「拍松纤维」；

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/16/16b593655071f5170c83917fef4f9c4bc84d7f01029de7776111932b539c7c8d.png" style="zoom:25%;" />

    2. 太大了，要对半切；

        <img src="https://blog.images.bornforthis.cn/docs-images/sha256/c3/c3834451df0bc43a303b41d6fd03625d6088b506a8934647687cb74b3853bf94.png" style="zoom:25%;" />

    3. 斜切：斜切后的白菜横截面变大，变薄，更容易吸味道；

        <img src="https://blog.images.bornforthis.cn/docs-images/sha256/aa/aa38b291a3b021cbeb49b0d07925fd02aa25221cf47fba6ff61e0c7f07d0573e.png" style="zoom:25%;" />

    :::

2. 料汁：1 勺淀粉、2 勺酱油、3 勺糖、4 勺醋、蒜末「出锅蒜·增加蒜香气」、一点点🤏香油；

3. 锅中加油，油热——>加入：干辣椒「用刀切小段」——>干辣椒一上色，加入：葱姜蒜——>爆炒出香味——> 白菜下锅——>保持大火状态，不停的翻炒；

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/25/25cba3686885c45350d71311b559ca6040c63c1732080450b375087e73397b4f.png" style="zoom:25%;" />

    

    :::

4. 透明了，就可以加入我们提前准备的料汁，翻炒均匀。出锅！
