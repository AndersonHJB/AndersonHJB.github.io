## 1. 食材

| 土豆     | 茄子   | 尖椒、菜椒 | 葱姜蒜 |
| -------- | ------ | ---------- | ------ |
| **盐**   | **糖** | **酱油**   | **醋** |
| **淀粉** | **水** |            |        |

- 料汁：2 盐、3 克糖、20ml 酱油、醋 10 克、淀粉 5 克、水 30ml；

## 2. 步骤

1. 茄子、土豆、尖椒、菜椒「三角片」，全部采用滚刀块切块；

2. 准备好：葱姜、蒜「一部分蒜片、一部分蒜末」；

3. 锅热，加入足量的油，我们要进行油炸：

    1. 油面微微冒烟——>加入茄子块；

        ::: details

        <img src="https://blog.images.bornforthis.cn/docs-images/sha256/2e/2e6bc5e2670870a6fa25e3df2512608bc9c3fccd1c249824f6b788008ad0c358.png" style="zoom:25%;" />

        :::

    2. 下锅之后，保持最大火🔥，使茄子块快熟炸熟「大约 3 分钟」

        ::: details

        <img src="https://blog.images.bornforthis.cn/docs-images/sha256/b8/b8bfbb4c473f06acd81ec77ae2621ea6831e9b8c2f9ac93bd436aa55b54ed91a.png" style="zoom:25%;" />

        <img src="https://blog.images.bornforthis.cn/docs-images/sha256/12/1299a354a8b18dac51e32e457ed9cd8ba3eb6a522e21e8d591085fa8fbe92019.png" style="zoom:25%;" />

        :::

        > 茄子怕窝油的话，小技巧：先小火炸熟，最后开大火，使油温增高，这时候把食材出锅就不会窝油了。「里面的油会被持续顶出来。」

    3. 接着炸土豆，大概五成热左右，慢慢的推油，不要推菜；「这样可以保证食物的完整性」——>当土豆不粘锅、土豆与土豆之间不沾了之后「3～4 分钟」——>当土豆表面起了小气泡就可以出锅了；（注意⚠️：升高油温！使油吐出来）

        ::: details

        <img src="https://blog.images.bornforthis.cn/docs-images/sha256/5a/5a77c12cc537cbac229d25450f36a6b8f7dbc376034652c9b31d19e9cb3a4551.png" style="zoom:25%;" />

        :::

    4. 接下来油炸尖椒，大概 5 秒即可出锅；

    5.   准备料汁：2 盐、3 克糖、20ml 酱油、醋 10 克、淀粉 5 克、水 30ml；

    6. 锅中加入适量的油，别太多「毕竟食材都油炸过」——>加入：葱姜蒜「三香配三鲜」——>炒出香味，加入料汁，当淀粉粘稠——>加入我们炸好的三鲜，翻炒均匀。——>最后加入灵魂的蒜末，适当翻炒——>出锅！

        ::: details

        ![](https://blog.images.bornforthis.cn/docs-images/sha256/48/489492d8dc065370acb8dc57ed7df30fe965de60198f7df3abd71ab6f85473cc.png)

        :::
