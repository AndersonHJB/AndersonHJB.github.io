@tab 野驴

## 1. 食材

| 茄子     | 生姜 10g | 大蒜 50g | 香菜 20g | 葱 15g | 青红辣椒 60g（可选） | 五花肉馅 150g |
| -------- | -------- | -------- | -------- | ------ | -------------------- | ------------- |
| **生抽** | **老抽** | **白糖** |          |        |                      |               |



## 2. 步骤

1. **茄子**：
    1. 茄子一开二；
    2. 继续一开，切成条状；
2. **配料**：
    1. 生姜切丝；
    2. 大蒜做成蒜末；
    3. 香菜切成末；
    4. 小葱切葱花；
    5. 青红辣椒切成圈（可选）；
    6. 五花肉搅碎；
3. **锅中**：
    1. 喷薄油；
    2. 茄子有皮的一面朝下，均匀的码在锅中；
    3. 先开大火把锅烧热，锅内有热气飘上来的时候，中小火、慢煎 3～4 分钟；
    4. 茄子一戳就透，稍微翻炒一下，出锅备用；
    5. 锅热，下油；
    6. 微热，下入肉馅；
    7. 炒开，转小火慢慢炒；
    8. 炒到微微金黄，下入：姜丝；
    9. 翻炒均匀后，调味：
        1. **黄酒 5g、黄豆酱 50g**；
        2. 翻炒均匀，出香；
        3. **生抽 10g**；
        4. 翻炒均匀；
        5. **清水 300g**；
        6. **老抽 5g、白糖 5g、味精 3g**；
    10. 下入：茄子，翻炒均匀；
    11. 转小火 炖煮 5 分钟；
4. **勾芡**：
    1. 玉米淀粉 5g；
    2. 清水 20g；
5. **转大火收汁**：
    1. 下入：辣椒圈、葱花，翻炒出香；
    2. 淀粉水勾芡，不要太稠；
    3. 下入：蒜末、香菜末；
6. 最后看情况是否添加盐；
