@tab 范大厨「一般」

### 1. 食材

| 虾       | 龙口粉丝   | 蒜末     | 娃娃菜   | 金针菇 | 大葱 |
| -------- | ---------- | -------- | -------- | ------ | ---- |
| **生姜** | **小米椒** | **料酒** | **砂锅** |        |      |





### 2. 步骤

1. 去掉虾头、虾壳、虾尾留下——>开背去虾线——>开背后的虾，用刀稍微剁几个位置（防止虾熟的时候卷在一起）

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/04/04a59f816f59531d11f4a2c0df66b8abbf7fa6ebe8ef5c0c9f5a26ef4d1d1e48.png" style="zoom:25%;" />

    :::

2. 虾头、虾壳别扔掉！（后面熬制虾油）

3. 娃娃菜切丝

4. 金针菇

5. 粉丝泡软

6. 蒜蓉——>那清水洗一下蒜蓉（这样不会发苦、发黑）——>滤干——厨房用纸吸一下水；

7. **虾油：** 加油（要多一点）——>4～5成热——>下入虾头、虾壳（可选）——>中火——>加入大块葱姜——>一遍煎、一遍压——>过滤虾油（备用）「虾壳就可以不用了」

8. **黄金蒜+蒜油：** 加油——>不用等油热，直接加入蒜末——>小火慢炒（黄金蒜）——>炸到浅金黄就可以了——>过滤；

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/04/04867e0f37e5fdfbbaee37360e8008b45c618799447c1318e20aa19db35482ea.png" style="zoom:25%;" />

    :::

9. **蒜蓉酱：** 蒜蓉（炸过的）、盐、糖、生抽、老抽、蚝油、白胡椒粉、蒜油；（搅拌均匀）

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/8f/8f2a3ea362b2bdcd562f5fc5242ebad6c8a3d14bb403d6b25e64ddbaff9f7738.png" style="zoom:25%;" />

    :::

10. 装锅：剩下的蒜油铺底——>切丝娃娃菜——>金针菇；

11. 粉丝——>加入虾油——>搅拌均匀；

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/d2/d25b704aa897c651a051bb60549e96ec37273c70d18abe3ac45552ce40ff2548.png" style="zoom:25%;" />

    :::

12. 继续装锅：加入搅拌均匀的粉丝；

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/8c/8c1acc05c6660ca8570dfbcc6e2e937f8c5114c850fad46af93880879bf57b68.png" style="zoom:25%;" />

    :::

13. 摆虾：

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/5c/5cde5546bfd8141b5ec1a443d6e4aba7389445f963314811c946d2d59f200a1c.png" style="zoom:25%;" />

    :::

14. 把配的酱放在虾上面：

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/cd/cd23bdfaaa79e2f8e3f1591436db6c8e82a0899ddeb127abd262c866cba21678.png" style="zoom:25%;" />

    :::

15. 加入小米椒：

    ::: details

16. 听见砂锅里面有噼里啪啦的声音、砂锅眼上冒热气；

17. 关小火——>在锅盖上淋上：半瓶盖的花雕酒；

@tab:active 村驴

### 1. 食材

| 大蒜         | 虾       | 小米辣 | 蚝油 | 生抽 | 白糖 | 鸡精 | 盐   |
| ------------ | -------- | ------ | ---- | ---- | ---- | ---- | ---- |
| **龙口粉丝** | **香葱** |        |      |      |      |      |      |

### 2. 步骤

1. 做蒜末，要多——>清水清洗几遍并滤干备用；

2. 搅碎小米辣备用；

3. 小火——>锅中加入油——>微热，加入一半蒜末——>当蒜末变成淡淡的金黄色时——>关火，余温会让蒜蓉的颜色继续变深——>加入剩下的蒜蓉并不停的搅拌均匀——>等蒜蓉出现金银两种颜色，加入搅碎的小米辣——>加入生抽、蚝油、白糖、鸡精、盐——>一开锅，就可以出锅了；

4. 龙口粉丝使用开水泡开；

5. 虾去掉虾脑、虾线、从头开到尾部一节；

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/dd/dd124068fc6399c6bebda142f626fe5c3a71183221c3796ea2e97db0258f35e5.png" style="zoom:25%;" />

    :::

6. 把泡好的粉丝滤干，加入盐（1.5g）、生抽（10g）、蒜蓉酱 4 勺，搅拌均匀；

7. 接着摆上虾，铺满蒜蓉，水开之后下锅蒸；

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/1b/1b05534653f945c3000c92729a816a768c536825cb310639fcf0d80325eb0e7c.png" style="zoom:25%;" />

    :::

8. 撒点葱花，热油淋浇；
