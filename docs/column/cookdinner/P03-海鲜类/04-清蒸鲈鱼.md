## 1. 食材

1. 鲈鱼
2. 大葱
3. 小葱
4. 生姜
5. 香葱



## 2. 步骤

1. 大葱切细丝、香葱尾切细丝、红椒切细丝——>清水泡着备用；
2. 清洗鱼「洗干净」——> 开花刀「鱼背、鱼身」；
3. 大葱切段，把鱼架起来，形成空气流动，均匀受热、带走腥气味；
4. 把姜切成片，铺在鱼身，使姜片在蒸汽的作用下，姜汁流入鱼身，更好的去腥；
5. 可以选择是否使用保鲜膜包裹起来；
6. 蒸锅需要提前烧之上汽，然后才可以放入蒸锅蒸熟为止；
7. 把之前切丝的滤干，放在蒸好的鱼身上；
8. 自制蒸鱼豉油：
    1. 一份水；
    2. 一份生抽酱油；
    3. 香菜根；
    4. 美极酱油半份；
    5. 鱼露半份；
    6. 糖 1/4；
    7. 开锅之后，关小火（熬煮 3～5min）；
9. 加入做好的蒸鱼豉油，热油浇淋。
