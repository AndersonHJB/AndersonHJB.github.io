## 1. 食材

| 活虾     | 姜片     | 小香葱     | 花雕酒     | 盐   | 白糖 |
| -------- | -------- | ---------- | ---------- | ---- | ---- |
| **干葱** | **大蒜** | **小米辣** | **绿尖椒** |      |      |



## 2. 步骤

1. 凉水，加入姜片、小葱节、花雕酒；

2. 等到锅底的水泡，和虾的眼睛似的（虾目水），就可以下入虾了；

    ::: details img

    ![](https://blog.images.bornforthis.cn/docs-images/sha256/47/4797d299ab8a2603785a4ead8649f13224881586745bdccea9e2bcec2eac747b.png)

    :::

    > 为什么不能大开水去煮虾？因为虾是有厚度的，外面的水翻滚，虾的外面老了，里面的虾肉还没熟。

3. 煮 30秒；

4. 关火，少量的盐、白糖；

5. 泡 1 分 30 秒；

6. 蘸料：少放几滴花生油、干葱、大蒜、小米辣、绿尖椒——>翻炒到微微小焦；

7. 关火——>加入：生抽，让酱油初熟即可；
