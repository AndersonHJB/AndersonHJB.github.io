## 1. 食材

| 虾滑 250 克    | 馄饨皮 200 克       | 猪油 15 克 | 盐3克 | 白胡椒粉 0.2 克 | 酱油 10 克 |
| -------------- | ------------------- | ---------- | ----- | --------------- | ---------- |
| **葱花 10 克** | **煮面原汤 500 克** | **上海青** |       |                 |            |

## 2. 步骤

1. 虾做成虾滑；

2. 用馄饨（饺子皮也可以）皮包住虾滑——>扯开拉长；

3. 开水——>小扯面下入开水中；（1.5 分钟～2 分钟）扯面一飘在汤面上就可以；

    > 可以顺带煮点：上海青；
