## 1. 食材

| 桂鱼「鳜鱼」 | 猪油       | 姜片       | 广东米酒                 | 丝瓜条？西葫芦条？ | 盐   | 糖   |
| ------------ | ---------- | ---------- | ------------------------ | ------------------ | ---- | ---- |
| **蟹味菇**   | **虫草花** | **脆木耳** | **粉丝（提前用水泡好）** | **小韭黄**         |      |      |





## 2. 步骤

1. 鱼：去骨、取肉（骨头和头分开）；

2. 鱼肉切双飞；（要薄，也就是）

3. 猪油——>煎姜片——>鱼骨下锅——>鱼骨两边煎制焦香——>广东米酒（锅边淋）——>下入：凉水；

4. 把鱼骨和鱼汤进行分离；

5. 锅中烧油，下入丝瓜进行煸制一下——>下入：鱼汤；

6. 调味：两小勺盐和少许糖；

7. 下入：蟹味菇、虫草花、脆木耳；

8. 用滤勺把提前泡好的粉丝烫熟；
