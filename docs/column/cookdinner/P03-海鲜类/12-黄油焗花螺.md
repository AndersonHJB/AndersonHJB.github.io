## 1. 食材

| 花螺 2 斤  | 彩椒粒       | 洋葱蒜蓉 | 黄油适量「可选 | 盐   |
| ---------- | ------------ | -------- | -------------- | ---- |
| **花雕酒** | **白胡椒粉** | **白酒** | **小香葱**     |      |

## 2. 步骤

1. **焯水**：

    1. 清水；
    2. 花雕酒；
    3. 盐；
    4. 水开 1 分钟，出锅；
    5. 倒入：清水当中；

2. **准备**：彩椒切粒、洋葱切粒、蒜末、适量葱花；

3. **炒制**：

    1. 砂锅烧热，来一些油；
    2. 加入一些彩椒粒；
    3. 洋葱粒；
    4. 蒜蓉（蒜末）；
    5. 炒出香味，倒入花螺炒制；
    6. 加入：海盐、白胡椒粉；
    7. 下入：黄油；
    8. 炒匀；
    9. 盖上盖子，喷点白酒；
    10. 啫一分钟即可出锅；

    > 🔥 **用高温、少量汁液，把食材快速焖煮收汁的做法**

4. 撒葱花，出锅；
