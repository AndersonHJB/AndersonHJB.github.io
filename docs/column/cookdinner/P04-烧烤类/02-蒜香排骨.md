## 1.  食材

| 洋葱     | 红椒     | 小香葱「葱花」 | 大蒜     | 花雕酒       | 盐           | 鸡粉 | 耗油 |
| -------- | -------- | -------------- | -------- | ------------ | ------------ | ---- | ---- |
| **生抽** | **香油** | **大葱**       | **鸡蛋** | **玉米淀粉** | **白胡椒粉** |      |      |





## 2. 步骤

1. **辅料准备**：
    1. 半个洋葱切碎；
    2. 半个红椒切丁；
    3. 葱花切末；
    4. 大蒜适量切碎（可以多一些）；
        1. 清洗蒜蓉；（保留蒜水）
        2. 挤干；
2. **排骨**：
    1. 放一勺半的盐；
    2. 放生粉 2～3 勺（没有可以用红薯淀粉、面粉代替）；
    3. 抓匀后洗干净；
3. **蒜水**：拍生姜、拍小香葱、蒜水（姜蒜水）
4. **腌制排骨**：
    1. 盐、白胡椒粉适量；
    2. 鸡粉 2 小勺；
    3. 料酒 3 勺；
    4. 一点点耗油；
    5. 生抽 1 勺；
    6. 香油半勺；
    7. 抓拌均匀；
    8. 分次加葱姜水 50g；「**蒜水**」
    9. 一颗鸡蛋；
    10. 生粉 50g；
    11. 抓拌均匀；
    12. 加入油抓拌均匀，腌制 15 分钟；
5. **炸蒜蓉**：
    1. 锅 4～5 成热，下入蒜蓉；
    2. 蒜蓉微微金黄，关火；
    3. 再稍微泡一泡，控干油，捞出来；
6. **炸排骨**：
    1. 先大火定型上色；
    2. 泡个两分钟，捞出来；
    3. 油温升高，复炸 1 分钟；
7. **炒制**：
    1. 锅中适量的油；
    2. 倒入：洋葱碎、红椒碎；
    3. 炒出香味，倒入排骨；（翻炒均匀）
    4. 加入：白胡椒粉、一勺鸡粉、倒入蒜蓉；
    5. 出锅，撒入葱花；

## 3. 制作日期

- 日期：2026 年 2 月 16 日：排骨有点干、有点油，玉米淀粉可以多加一些、蒜水多一些。
