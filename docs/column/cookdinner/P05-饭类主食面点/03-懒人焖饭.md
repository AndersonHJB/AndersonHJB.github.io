## 1. 食材

| 大米 | 胡萝卜 | 土豆 | 香菇 | 腊肠 or 午餐肉 | 洋葱 | 豌豆（青豆） | 玉米粒 |
| ---- | ------ | ---- | ---- | -------------- | ---- | ------------ | ------ |

> 有啥菜就加啥菜

## 2. 步骤

1. 洗好大米；

2. 胡萝卜、土豆、香菇、腊肉、洋葱：切丁；

3. 把腊肠放入米中；

    ::: details

    ![](https://blog.images.bornforthis.cn/docs-images/sha256/5a/5a304d93b59d631b48456adc2f8ae070c0e9fad8c7293c072ed0ea0f7c112b71.png)

    :::

4. 加盐、生抽、老抽（上色）、蚝油——>抓匀；

5. 土豆、洋葱——>加盐（3g）、糖（2g）、黑胡椒（2 拧）、香油——>拌匀；

    ::: details

    ![](https://blog.images.bornforthis.cn/docs-images/sha256/46/46b7c14c0b21f0f32ab04530bb598b43106b65a9acc0ce6efc8e541692b31831.png)

    :::

6. 放入电饭锅：

    1. 油拌过的土豆、洋葱，铺在电饭锅的底部；

    2. 接着下入米饭（包含腊肉）

    3. 最后放入配菜：胡萝卜、土豆、香菇、玉米粒、腊肉、豌豆（青豆）

        ::: details

        ![](https://blog.images.bornforthis.cn/docs-images/sha256/ec/ec8ba06fe62e5fe681217c24cbbd9c1456af24107052cc3ccc25d0827bf83260.png)

        :::

7. 加入水，和米是 1:1
