## 1. 食材

| 豆角         | 五花肉   | 蒜       |
| ------------ | -------- | -------- |
| **酱油**     | **蚝油** | **盐**   |
| **糖**       | **鸡粉** | **老抽** |
| **玉米淀粉** |          |          |



## 2. 步骤

1. 豆角斜切、去皮五花肉切丝；
2. 锅热，加油——>热锅冷油；
3. 下入：去皮的五花肉丝——>肉丝炒焦，炼出猪油——>肉丝盛出；（油留在锅里）
4. 豆角丝下入锅中——>转大火，煸熟煸透，煸出豆角香气——>炒熟，盛出备用；
5. 肉丝中的油倒出，不够再补点——>加入拍蒜——>大蒜金黄，加入肉丝——>转小火，1 勺酱油、1 勺蚝油——>翻炒均匀；
6. 加入：热水；
7. 盐、糖、鸡粉都来一点；
8. 一些老抽上色；
9. 勾芡：勾芡薄薄就行；
10. 下入豆角——>转大火翻炒均匀；
