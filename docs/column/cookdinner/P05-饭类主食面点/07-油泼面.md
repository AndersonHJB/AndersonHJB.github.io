## 1. 食材

| 面条     | 豆芽     | 上海青 | 生抽 | 陈醋 |
| -------- | -------- | ------ | ---- | ---- |
| **小葱** | **大蒜** |        |      |      |





## 2. 步骤

1. 准备蒜末、葱花；
2. 水开下入面条——>再次煮开下入：豆芽——>沿着锅边淋一圈凉水；
3. 等水再次烧开，下入：上海青——>再沿着锅边淋一圈凉水；
4. 捞出，加一下面汤——>加入：蒜末、葱花、辣椒面、热油泼香；
5. 2～3 勺生抽、2～3 勺陈醋、2 勺白糖（可选）、味精与鸡精（各一些）；
