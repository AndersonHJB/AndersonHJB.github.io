## 1. 食材

| 老豆腐       | 大蒜     | 大葱 | 小葱 | 洋葱 | 鸡蛋 |
| ------------ | -------- | ---- | ---- | ---- | ---- |
| **白胡椒粉** | **鸡粉** |      |      |      |      |





## 2. 步骤

1. 老豆腐切块，正方形块；
2. 准备大蒜，拍碎；
3. 大葱切小圈、洋葱切丝、小葱头、葱花；
4. 碗中打入鸡蛋+白胡椒粉+鸡粉；
5. 料汁：适量白胡椒粉、适量盐、一勺鸡粉、两勺黄酒、一勺香油、半勺老抽、一小勺蚝油、两勺生抽、一大碗水；
6. 锅中：凉水+盐+生抽——>下入：豆腐，烧开 3 分钟；（煮到产生蜂窝状）
7. 锅热，加~~少量~~多一些油：把一面煎制金黄，翻面继续煎制——>倒入：一半的鸡蛋；（油要多加！！！）
8. 翻炒均匀，再倒入另外半碗鸡蛋，让鸡蛋紧紧抱住豆腐；
9. 豆腐可选出锅（可选）；
10. 把豆腐扒拉一边，下入：三葱、姜、蒜，加入一些：油；
11. 把葱蒜爆香后，与豆腐炒在一起；
12. 加入提前调配好的料汁；
13. 再加入一碗水；
14. 加完水之后，焖个 3～5 分钟；
15. 水淀粉勾芡；
16. 最后撒入葱花；
