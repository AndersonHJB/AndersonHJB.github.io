> 豆角烧土豆焖饭 原料：五花肉 400 克，豆角 300 克，土豆 400 克，八角 2 克，桂皮 2 克，干辣椒 2 个，姜 5 克，大葱 20 克，花雕酒 20 克，酱油 50 克，开水 1.5 千克，盐 3 克，白胡椒粉 1 克，老抽 10 克，米饭 1 千克，葱花 10 克，白芝麻3克。

## 1. 食材

| 五花肉     | 豆角                 | 土豆     | 八角   | 桂皮       | 干辣椒   | 姜       | 大葱       |
| ---------- | -------------------- | -------- | ------ | ---------- | -------- | -------- | ---------- |
| **花雕酒** | **酱油**             | **开水** | **盐** | **白胡椒** | **老抽** | **米饭** | **小香葱** |
| **白芝麻** | 想着：要不要加香菜？ |          |        |            |          |          |            |





## 2. 步骤

1. 提前蒸好干饭、烧好开水；

    > 个人感觉：蒸的不要太湿，因为后面要下入锅中煮，具体看实操结果；

2. 五花肉切成小条状；

3. 土豆切块；

4. 豆角掰成几段；

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/44/44477cd6d783997101de20fe381f467afef6dbdd22cdccc524d0489e2e7c9920.png" style="zoom:25%;" />

    :::

5. 锅热（无油、无水）——>下入：五花肉——>保持大火，五花肉出油、有焦边；

6. 下入：2 个八角、2 克桂皮、2 个干辣椒、5 克姜块——>翻炒均匀；

7. 下入：土豆块——>继续翻炒，五花肉金黄色、土豆出现焦边；

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/ff/ffb8c4dc5a8d8932a5b2e80ff4863073ed88ef754c99aadabd30da72bb1109e4.png" style="zoom:25%;" />

    :::

8. 倒出锅中多余的油！！！

9. 下入：豆角、大葱、花雕酒、锅边酱油——>翻炒均匀；

10. 锅中加入：开水、盐、老抽、白胡椒粉——>炖煮一会；

11. 下入提前蒸好的米饭，盖盖，炖煮 5 分钟；

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/cc/cc3e7432830ed455546eac22ab16b7a3f8640c022479f067477b2cf4c7bac73e.png" style="zoom:25%;" />

    :::

12. 开盖：下入香葱末、芝麻；

13. 翻拌均匀；





## 3. 制作记录

| 日期                | 感受                                                         |
| ------------------- | ------------------------------------------------------------ |
| 2025 年 10 月 23 日 | 味道稍微偏淡，主要对于蓉宝来说：不够辣🔥颜色不够深，五花肉煎制不够金黄，反而瘦肉很香。土豆、豆角没有很软烂，水要记得加多一些。老抽也可以适量多一些，盐也是，还有辣椒🌶。<br />最主要还是五花肉，需要煮到金黄，跟卤肉一样。 |
