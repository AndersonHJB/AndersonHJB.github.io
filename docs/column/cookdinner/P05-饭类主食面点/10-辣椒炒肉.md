## 1. 食材

| 螺丝椒     | 红尖椒（丰富颜色） | 五花肉       | 大葱     |
| ---------- | ------------------ | ------------ | -------- |
| **姜**     | **蒜**             | **盐**       | **豆豉** |
| **花雕酒** | **酱油**           | **白胡椒粉** | **香油** |
| **陈醋**   |                    |              |          |

- 螺丝椒：
    - 头部的柄，越弯曲说明这个辣椒越辣；
    - 颜色深一些的，辣度也会高一些；

## 2. 步骤

1. 螺丝椒去头，切滚刀块；

2. 红尖椒切滚刀块；

3. 五花肉切片；

4. 准备大葱、姜片、拍蒜；

5. 锅热（无油、无水）——>中火，下入：螺丝椒、红尖椒；

6. 加入一些盐；（使辣椒可以出一些水，方便后续入味。也是让辣椒一些底味）

7. 现在辣椒有一些慢慢的变得「蔫软」，用锅勺按压，让辣椒更重复的接触锅底温度；

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/e5/e561877aab483dabd51404c4436e1690692d7f36e87a5026eda6397b14979e07.png" style="zoom:25%;" />

    :::

8. 辣椒出锅；

9. 锅中少油，下入五花肉，等待出一些油后，再进行翻炒；（不粘锅）

10. 当五花肉出金黄的边的时候（肉香味最聚拢），关火——>倒出：全部的油；（五花肉在后期的烹炒中，还是会继续出油的）

11. （中火）下入豆豉，翻炒均匀，豆豉变得松散，粘附在五花肉上；

12. 葱姜蒜，倒炝锅；（如果一开始就加入，葱姜蒜都已经老了）；

13. 先加入：姜片、大葱——>翻炒均匀，蒜是非常容易焦糊；（等出香味了，下入：蒜。「拍松，不能剁碎的大蒜」）

14. 锅边淋：花雕酒；「可有可无」🉑🈶🉑🈚

15. 2 勺酱油、适量盐、适量白胡椒粉；

16. 下入提前炒好的辣椒；（最大火🔥）（15 秒，辣椒中的营养怕高温）

17.  稍微的加入一些：香油；

18. 锅边醋——>翻炒均匀，出锅！
