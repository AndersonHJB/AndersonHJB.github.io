## 2. 步骤

1. 半杯玉米面粉、半杯面粉——>一纸杯的凉白开，加入面粉当中——>再加入一小勺盐——>完全搅匀，静置 5 分钟；

2. 包饺子剩余的面团 or 饺子皮——>喷点油，可以更好的延展——>切几刀，可以更好的起鼓；

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/19/1923e7f12fb0707eca071e47ec072b9201f0581f5dd322ff3f79ae85c13f684b.png" style="zoom:25%;" />

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/72/72130a101e2a3054bf8d6bb6fc5fec8c51d1122ab4491675831297e154b5ca9d.png" style="zoom:25%;" />

    :::

3. 等油温微微冒烟，下入准备好的薄片——>等脆了之后，捞出即可；

4. 秘制酱：芝麻酱（20g）要澥，用凉开水澥开、海鲜酱（30g）、番茄酱（50g）、甜面酱（100 g）、五香粉（2g）——>搅拌均匀，来点凉开水，稀释一下；

5. 开始摊煎饼：倒一点面糊，刮开（刮的工具要一直泡水）——>加入鸡蛋捣碎并摊匀——>加入：葱末、香菜、黑芝麻；

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/5a/5a8ce321cee8f29b72713059bf4b50edd6d9016945970182e9f2673c322655fa.png" style="zoom:25%;" />

    :::

6. 翻面——>刷酱、薄脆、生菜、火腿；

7. 上下收起，并折叠即可；

## 2. 步骤

1. **面浆**：
    1. 半杯面粉；
    2. 半杯玉米面粉；
    3. $\frac{1}{4}$ 勺盐；
    4. 一杯水；
    5. 搅匀；
    6. 再加：半杯水，搅匀起筋；
2. **准备薄脆**：
    1. 混沌皮中间切两刀；
    2.  油热，油炸到金色即可；
3. **准备酱**：
    1. 1 勺甜面酱；
    2. 半勺蒜蓉辣酱；
    3. 半勺番茄酱；
    4. 1/3 勺蚝油；
    5. 一丢丢味精；
    6. 半勺白糖；

## 1. 食材

| 面粉 500g    | 玉米面 50g  | 黄豆面 50g       | 盐 8g          | 凉水 850 g     | 馄饨皮       | 五香粉 |
| ------------ | ----------- | ---------------- | -------------- | -------------- | ------------ | ------ |
| **白糖 10g** | **鸡精 3g** | **麻辣鲜 8g**    | **黄豆酱 80g** | **甜面酱 50g** | **玉米淀粉** |        |
| **鸡蛋**     | **生菜**    | **鸡柳**（可选） | **黑芝麻**     | **小香葱**     |              |        |

## 2. 步骤

1. **浆糊配置**：
    1. 面粉 500g；
    2. 玉米面 50g；
    3. 黄豆面 50g；
    4. 盐 8g；
    5. 凉水 850g；
    6. 第一次：先倒入 500g 凉水，顺着一个方向搅打上劲；（别倒太少，容器起小颗粒，不然容易煎制的时候容易破）
    7. 搅至光滑细腻后，把剩下的水分次加入搅拌；
    8. 醒发 20 分钟；
2. **薄脆**：馄饨皮切两刀，然后油炸即可；
3. **煎饼果子酱料**：
    1. **五香粉**：用现成的或者 **自配**：八角 10g、桂皮 6g、小茴香 5g、丁香 1g、草果 3g；
    2. 白糖 10g、鸡精 3g、麻辣鲜 8g；
    3. 黄豆酱 80g、甜面酱 50g；
    4. 放在一起，搅拌均匀；
    5. 锅热，少许的油：将我们的酱料放进去。
    6. 把酱料炒香，加入：300g 清水；
    7. 烧开后，转小火熬煮 2 分钟；
    8. 出锅前：水淀粉勾芡；

4. 开始摊煎饼；
