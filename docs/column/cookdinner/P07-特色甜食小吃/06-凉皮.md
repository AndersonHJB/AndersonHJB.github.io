| **香砂 0.5g**  | **草果半个去籽** | **40 g香醋或陈醋** | **大蒜**  | **食用油** | **土豆淀粉 20g** |           |



## 2. 步骤

### 2.1 面浆&面筋部分

1. 高筋面粉 500g+常温的清水 260～270g（面粉吸水程度不同）——>弄成面团，醒 10 分钟；

2. 找到家里最大的盆，盆上放滤网——>面里加凉水，进行洗面，当水洗成牛奶色——>   倒出来；

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/31/31c3ff8935be80ed144681f062b465889399f7c674345a2544ed877ad2c8acc1.png" style="zoom:25%;" />

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/c1/c1e004e7720cc688905a2f05f61d44fd6cad41a88a98292b583735bbd381fcfe.png" style="zoom:25%;" />

    :::

3. 如此反复，上面的步骤；（每次水不要太多，和面团齐平即可）

4. 一直洗到和淘米水一样的颜色即可；

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/67/675000d8d8a9e8569ab9b9d31ec920ddc38c502b6e2ef8abe0e8d6e794e50310.png" style="zoom:25%;" />

    :::

5. 洗出来的球，就是面筋。

    1. 把面筋放到水里泡 30 分钟；
    2. 洗出来的**面浆**放冰箱静置 5 个小时；

#### 2.1.1 面筋

1. 把面筋挤出水分并团成球；
2. 放入蒸锅，大火：水烧开后，转小火蒸 30 分钟；
3. 蒸好之后放凉，套保鲜膜，防止风干；

#### 2.1.2 面浆

1. 粉浆沉淀好了之后，分离掉上层的清水，保留下层的粉浆；（水不要直接倒掉）
2. 我们最终的粉浆成品应该是：1250g，如果不够则用上一步分离出来的清水进行补充；
3. 20 g 土豆淀粉+20 g 清水——>搅拌均匀，倒入粉浆中——>把粉浆掏底搅拌均匀；

#### 2.1.3 蒸凉皮

1. 盘子底部抹点有（注意⚠️：要非常非常少，可以不抹。主要是为了好撕起来）；
2. 放一锅水煮开、一盆凉水（其实可以加冰块）（锅和盘子都要可以直接放入盘子的大小！）；
3. 锅里的水开之后，空盘放入开水烫3～5 秒；
4. 根据喜欢的薄厚程度，加入面浆；（每次蒸的时候都要掏底搅拌均匀一下，因为会沉底）；
5.  放入锅中：夹子夹住圆盘，适当的摇匀，等定型后，盖上锅盖蒸汽 2～3 分钟；（注意防止水泡掉入盘子中）
6. 蒸到鼓起大泡，就可以拿出来放在凉水中；
7. 薄薄抹个油，防止凉皮互相沾在一起；（可以不抹）

### 2.2 料水

1. 可以做成料包：小茴香 1.5g、八角 0.5g、桂皮 0.5g、花椒 0.5g、香叶 0.5g、白扣 0.5g、香砂 0.5g、草果半个去籽；「个人不喜欢做成料包，有微塑料」

2. 小锅中加 225g 清水；

3. 40g 香醋或陈醋；

4. 加入前面准备好的料包；

5. 中大火煮开；

    ::: tip 做成香料包的话

    - 第一次：开锅就捞出来；
    - 第二次：水开关火泡 5 分钟；
    - 第三次：水开关火泡 15 分钟；
    - 第四次、第五次：水开关火泡 30 分钟；
    - 香料包千万不能煮，会导致味道过重；

    :::

6. 加入调味：

    1. 盐 10～15g（根据口味来添加）；
    2. 白糖 10g、生抽 10g、味精 4g、鸡精 5g；
    3. 趁热拌匀；
    4. 料水的保质期是 5 天；

### 2.3 蒜水

1. 大蒜 20g、清水 100g、食用油 5g；「加油防止大蒜氧化变绿」

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/8b/8b5bb90a3ec7ca0b926086a86a335ceedaa14653e5c6408034be979c2069e149.png" style="zoom:25%;" />

    :::

> 蒜水只能当天做当天吃，不能隔夜！

### 2.4 辣椒油（可以选择使用现成的）

#### 2.4.1 食材

| 菜籽油（其它食用油也可以）1000g； | 秦粗辣椒面 70g | 细辣椒面 70g            | 白芝麻 40g        | 香醋 30g       | 白酒 20g       | 洋葱 80g     |
| --------------------------------- | -------------- | ----------------------- | ----------------- | -------------- | -------------- | ------------ |
| **大葱 80g**                      | **姜片 30g**   | **香菜 1 根（保留根部** | **芹菜细细 1 根** | **胡萝卜 30g** | **小茴香 30g** | **八角 20g** |
| **桂皮 7g**                       | **花椒 7g**    | **香叶 10g**            | **白芷 1g**       |                |                |              |
| 下面是可选：                      |                |                         |                   |                |                |              |
| **草果 7g**                       | **毛砂仁 10g** | **香砂 6g**             | **丁香 2g**       | **肉蔻 5g**    | **良姜 3g**    | **紫草 2g**  |
| **苦豆子5g**                      |                |                         |                   |                |                |              |

> 一斤油搭配 15g香料粉，2 斤油，使用 30g

#### 2.4.2 步骤

1. 把香料搅碎（单独搅碎后，混合搅碎、搅匀）；

    > 小茴香 30g、八角 20g、桂皮 7g、花椒 7g、香叶 10g、白芷 1g、草果 7g、毛砂仁 10g、香砂 6g、丁香 2g、肉蔻 5g、良姜 3g、紫草 2g、苦豆子5g

2. 取出 30g香料粉，剩余密封保存；（30g 对应两斤，如果做一斤，使用 15g 即可）

3. 锅中加入 2 斤食用油；

4. 锅中油开始冒大烟，关火；

5. 慢慢下入姜片，慢慢炸至焦黄；

6. 慢慢加入其它青菜：洋葱、胡萝卜、芹菜；

    ::: tip

    喜欢的朋友可以在下完蔬菜后，加入猪油 80g，起到增香、增稠的作用；

    :::

7. 到目前为止都是关火状态，当锅中没什么反应了，开火转成中小火慢炸；（要有耐心，小火慢炸才能出香味）

8. 炸至金黄后，捞出；

9. 开大火，油开始冒泡、冒烟就关火；

10. 下入：白芝麻，飘在油面上，不糊，表面油温刚刚好——搅拌 30 秒；

11. 均匀的撒上香料粉——>搅拌 30 秒；

12. 下入：粗辣椒面——>搅拌均匀；

13. 下入：细辣椒面——>搅拌均匀；

14. 接着：淋入锅边醋；

15. 锅的中间淋入白酒——>下入白酒后，不要马上搅拌，否则会扑起来，等一小会再搅拌；

16. 倒出锅，盖上盖子焖上24h；

17. 

### 2.5 开拌

1. 凉皮切丝、面筋切块；
2. 加入：黄瓜丝、豆芽、花生粒，按自己喜好添加；
3. 加入：辣椒油、料水、蒜水；
4. 开炫！

## 2. 步骤

### 2.1 面凉皮

1. 250g面粉、75g玉米淀粉、食用碱 1g、盐 5g——>搅拌均匀；
2. 加入：400g 的水——>搅匀——>静置 10～15 分钟；
3. 搅蛋器：搅动到奶昔状态；
4. 准备两口大锅，一个烧开，一个凉水；
5. 准备一个盘子，盘子底部不要抹油，不容易成型；
6. 看自己想要的厚度，加入面浆；
7. 烫熟之后，放入凉水锅，撕开即可——>抹点油可以垒起来；
8. 剩下的如下炮制；

### 2.2 料汁

1. 蒜末、盐、味精、温水 40～50 度——>搅拌均匀；
2. 几滴生抽酱油；

### 2.3 组装

1. 中间凉皮；
2. 胡萝卜；
3. 黄瓜丝；
4. 中间面筋；
5. 小米辣椒圈；
6. 加入：蒜水；
7. 加入：芝麻酱；
8. 加入：西北的辣子；

> 网友：
>
> 一、250克面粉，75克玉米淀粉，碱1克，盐5克，搅匀，加入400克水，慢慢粗粗地搅一下，静置十几分钟，大疙瘩已变成小疙瘩，用打蛋器搅打成奶昔状就可以了。
>
> 二、准备好两口大锅，一锅里烧的是开水，一锅里是凉水。准备好一个有点深度的盘子，不用抹油，放入面浆，来回转到没有窟窿眼为止，直接放入开水锅里，盖上盖大约一分钟，取盘直接放入凉水锅中，悠着劲取下面皮。 
>
> 三、凉皮料汁：蒜末，盐，味精，四、五十度温水，几滴生抽。 四、凉皮切好放中间，左青瓜丝，右红萝卜丝，中上下面筋，撒上一些小米辣，放入料汁，芝麻酱，辣椒油。

@tab 3. 茶老姑

## 1. 食材

| 300g 高筋面粉 | 3g 盐 | 300g 温水 | 胡萝卜丝 | 黄瓜丝 | 豆芽 | 花生粒 | 香菜 |
| ------------- | ----- | --------- | -------- | ------ | ---- | ------ | ---- |



## 2. 步骤

### 2.1 凉皮

1. 300g 高筋面粉、3g 盐、300g 温水——>用打蛋器多搅拌一会，顺着同一个方向；（搅到面糊可以拉长丝就可以）

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/00/001b94ca5b523d62c2d152e35eaa15638334315efebd11245faef3e88209d1dd.png" style="zoom:25%;" />

    :::

2. 盖上盖子，醒面 30 分钟；

3. 加入：300g 清水——>搅拌均匀并过滤网；

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/d9/d919f672356122e6bdc07d69d758c91615e8754846f5e4d52d6dcc7c4c080de2.png" style="zoom:25%;" />

    :::

4. 剩下在滤网的就是面筋了，再用清水洗两遍即可，弄成团并上锅蒸 30 分钟；

5. 锅中倒入清水，烧开。再准备一锅凉水即可；

6. 抹浆，蒸到鼓起即可，中途不要开盖；

7. 夹出放入凉水，放凉之后表面抹一点熟油，这样不会开裂和粘在一起；

8. 剩下的如法炮制，记得每次都要搅匀粉浆；

### 2.2 组合

1. 凉皮切丝、面筋切块；
2. 调味：1 勺陈醋、1 勺生抽、1 小勺盐、1 小勺糖、1 勺大蒜水、辣椒油；
3. 放入：胡萝卜丝、黄瓜、焯水的豆芽、花生米、香菜；

### 2.2 料汁&辣椒油

1. 料汁：盐、醋、生抽、香油、黄芥末——>搅拌均匀；
2. 辣椒油：
    1. 配料 1：葱姜蒜、茴香、洋葱、花椒、辣椒、桂皮、八角、香叶、香菜根；
    2. 锅中加油，有温度后，下入：配料；
    3. 配料 2：粗秦椒、细秦椒、米醋、白酒、白芝麻；
    4. 碗中放入：配料 2
    5. 开始加入上面煮的油：
        1. 一点：春意在枝头；（第一次泼油到碗中）搅拌均匀
        2. 二点：辣香绕香楼；（第二次泼油到碗中）搅拌均匀
        3. 三点：浓香心中留；（第三次泼油到碗中）搅拌均匀

### 2.3 组合

1. 凉皮切丝、面筋切块；
2. 胡萝卜丝、香菜；
3. 料汁、辣椒油；

@tab 5. 用杯子速做

## 1. 食材

| 高筋面粉 | 小麦淀粉 | 杯子 | 盐   | 芝麻酱 | 生抽 | 辣椒面 | 小葱 | 蒜   | 白芝麻 | 蚝油 |
| -------- | -------- | ---- | ---- | ------ | ---- | ------ | ---- | ---- | ------ | ---- |





## 2. 步骤

1. 使用喝水的杯子：1 杯高筋面粉、1 杯小麦淀粉、1 杯凉水、1 小勺盐——>顺着一个方向搅拌均匀，搅拌到拉丝即可；
2. 接着再加入 1 杯凉水——>再次搅匀；
3. 准备两锅，一锅开水蒸，一锅凉水；
4. 如法炮制；
5. 调料：葱末、蒜末、辣椒面、白芝麻；
6. 淋浇热油，激发出香味；
7. 再加入：适量的生抽、蚝油、盐、澥好的麻酱；



> 为什么用小麦淀粉？
>
> 给大家解释一下昂！传统凉皮就是白面粉（小麦面粉）洗面，把面筋洗掉，用剩下的部分来蒸凉皮，而剩下的部分基本就是小麦淀粉。而视频做法就是直接白面粉掺小麦淀粉，这样可以省去洗面筋的步骤，更不需要醒面，简单省事，做出来跟外边凉皮店卖的正宗凉皮一模一样。唯一区别就是没有面筋。
