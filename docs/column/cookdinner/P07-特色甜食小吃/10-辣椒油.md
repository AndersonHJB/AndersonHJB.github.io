## 1. 食材

| 100g 粗辣椒面 | 100g 细辣椒面   | 5g 五香粉    | 8g 盐        | 5g 糖    |
| ------------- | --------------- | ------------ | ------------ | -------- |
| **20mL 白酒** | **50mL 食用油** | **3 个八角** | **2 个桂皮** | **花椒** |
| **香叶**      | **洋葱**        | **姜片**     | **大葱**     | **香菜** |
| **蒜片**      |                 |              |              |          |



## 2. 步骤

1. 拿个较大的碗：加入：
    1. 100g 粗辣椒面（取其：辣味与香气）；
    2. 100g 细辣椒面（取其：颜色）；
    3. 5g 五香粉；
    4. 8g 盐；
    5. 5g 糖；
2. 搅拌均匀；
3. 20 毫升的高度白酒、50mL 食用油；（把辣椒面进行打湿，这样淋热油就不会糊了，辣椒会更香）
4. 锅中热油（要多）——>不用等油热，下入：3 个八角、2 个桂皮，保持小火状态 2 分钟左右的时间；
5. 下入：花椒、香叶 4～5 片——>炸上 2～3 分钟；（香叶开始变色了）
6. 下入菜料：洋葱、姜片、大葱、香菜、蒜片，炸到金黄色的状态，捞出；
7. 泼油也是有技巧的，分为三次泼；
    1. 油温升到七层热；
    2. 泼第一次：第一次泼，是为了出红油，并且要搅拌均匀，为了受热均匀；
    3. 下入：白芝麻，搅拌均匀；（直接泼在芝麻上，芝麻会直接发苦）
    4. 泼第二次：第二次泼，是为了激发出辣椒的香气；（一边泼一边搅拌）
    5. 泼第三次：出现了一香、二红、三辣，搅拌均匀！
