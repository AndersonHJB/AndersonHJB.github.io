@tab 范大厨

## 1. 食材

| 猪皮、猪板油 | 大葱     | 姜片   | 花椒粒   |
| ------------ | -------- | ------ | -------- |
| **花雕酒**   | **八角** | **盐** | **香叶** |



## 2. 步骤

1. 猪皮、猪板油切小颗粒块；（尽量大小一致）
2. 烧一锅开水——>下入大块的葱、姜、花椒粒、花雕酒——>水烧开，煮 2～3 分钟——>捞出佐料；（留下味道，起到去腥的作用）
3. 把切好的猪油下锅，不能太久！太久猪油就会释放出来。（1 分钟）
4. 捞出来，放进温水当中，进行漂洗，接着换盆水；
5. 水熬法：
    1. 2 斤猪板油，加一斤水——>大火烧开，稍微搅动——>转中火熬煮——>时不时搅动，防止糊底；（猪油会通过慢慢的熬煮进行释放）
    2. 添加香料：油面高于料时，加入大块葱、姜和两三个八角增香（猪油呈浅金黄色、葱姜呈金黄色时**关火**，利用余温继续上色）。（不要出现焦黄，会出现苦味）
6. 装罐保存：准备罐子，放入一小勺尖的盐和两三片香叶防腐增香，直接往外揩油或小心倒油，盖上盖子放阴凉处，室温下可凝结。





- 准备工作：选用干净的猪板油，将其切成大小一致的小块。
- 焯水去腥：烧开水，加入大块葱姜、小花椒粒、花椒酒，煮两三分钟后捞出，放入切好的猪油块煮一分钟，捞出用温水漂洗。
- 熬制方法：水熬法，二斤猪板油加一斤水，大火烧开后中火熬煮，至水分蒸发完进入炼油状态，时不常搅动防止糊底。
- 添加香料：油面高于料时，加入大块葱姜和两三个八角增香，猪油呈浅金黄色、葱姜呈金黄色时关火，利用余温继续上色。
- 装罐保存：准备罐子，放入一小勺尖的盐和两三片香叶防腐增香，直接往外揩油或小心倒油，盖上盖子放阴凉处，室温下可凝结。
