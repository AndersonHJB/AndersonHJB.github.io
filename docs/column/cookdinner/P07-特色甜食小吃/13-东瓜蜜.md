## 1. 食材

| 冬瓜     | 蜂蜜   | 老冰糖     | 冰块       |
| -------- | ------ | ---------- | ---------- |
| **滤布** | **盐** | **过滤布** | **柠檬片** |



## 2. 步骤

1. 冬瓜切小块，不去皮；

    ::: details image

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/72/720bf19ba8c1333a277e2e53a2ed8925ce16a7ac59ccad6cfbec2af66528a920.png" style="zoom:25%;" />

    :::

2. 锅中烧开水，加入适量的盐，加入适量的老冰糖；

3. 冰糖融化，下入冬瓜块；（汆烫时间 60 秒）

    ::: details image

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/39/3950bd0b2d077156eda8f3b4f057ed6d0aab18777e00aaa8a76650e43e4c237e.png" style="zoom:25%;" />

    :::

4. 冬瓜初熟，捞出进冰水；（锁住翠绿，锁住清香）

5. 使用破壁机：7 两冬瓜、1 斤水；

6. 使用过滤布，隔掉粗渣，留下清香；（清澈的冬瓜蜜汁水，丝丝香浓，滴滴清甜）

7. 再加入：蜂蜜；（琥珀琉璃涤烦襟，玉露冰瓤沁素心，一盏蜜酿回春意，舌底涓涓生甘霖）

8. 柠檬片；
