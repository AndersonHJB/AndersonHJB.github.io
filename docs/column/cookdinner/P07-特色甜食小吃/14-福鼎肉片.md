@tab 村驴

## 1. 食材

| 后腿肉（纯瘦肉）250g | 姜 3g                                  | 大蒜 3g                            | 盐 3g                   | 味精 3g        |
| -------------------- | -------------------------------------- | ---------------------------------- | ----------------------- | -------------- |
| **鸡精 3g**          | **泡打粉 1.5g**（为了蓬松，可选·尽量） | **食用小苏打 1g**（必须·不能放多） | **红曲粉 0.2g**（可选） | **白糖（3g）** |
| **木薯淀粉 50g**     | **香菜**                               | **小香葱**                         | **虾皮**                | **紫菜**       |
| **泡椒**             | **白胡椒粉**                           | **生抽**                           | **米醋 or 白醋**        | **鸡精**       |
| **盐**               | **芝麻香油**                           |                                    |                         |                |





## 2. 步骤

1. 后腿肉切片，在盘子底部套个保鲜膜，放上切好的肉片。（主要为了冷冻之后，方便拿起来）（肉上面再来一个保鲜膜，防止冻的时候水分流失）
2. 生姜、大蒜拍烂，加入 115g清水——>最终过滤出 110g 的水；
3. 把肉、姜蒜水放入冰箱进行冰冻 2h；
4. 调味的粉料：盐 3g、味精 3g、鸡精 3g、泡打粉 1.5g、食用小苏打 1g、白糖 3g；
5. 50g 木薯粉（或者：40g木薯粉、10 g 藕粉）；
6. 搅打肉：绞肉机放入肉、粉料、姜蒜水一些，打 20 次（001、002、003……）——>加入大块的姜蒜冰块，留一些给木薯粉；
7. 木薯粉加入姜蒜水，用手指拌匀，接着加入绞肉机；
8. 起锅烧水；
9. 趁着烧水的时间，调汤底：
    1. 香菜（15g）、葱花（10g）、虾皮（10g）、紫菜（2g）
    2. 野山椒适量（泡椒）；
    3. 白胡椒粉（0.5g）、生抽（10g）、米醋（白醋）（10～20g）；
    4. 鸡精（2g）、盐（2g）、芝麻香油（5g）；
    5. 水开后，盛一个开水，冲开汤底；
10. 肉浆可以铺在刀上面，单个筷子来刮下去；
