### 白菜一出，百财进屋！

**年夜饭抢手菜！白菜肉卷，寓意百财聚来！简单好做，清淡有滋味！**

:::



## 1. 食材

| 超大白菜！ | 八瘦两肥的肉 | 盐         | 白胡椒粉 | 花雕酒     |
| ---------- | ------------ | ---------- | -------- | ---------- |
| **生抽**   | **蚝油**     | **十三香** | **大葱** | **生姜**   |
| **鸡蛋**   | **香菇**     | **小香葱** | **香油** | **小米辣** |
| **红彩椒** | **蒸鱼豉油** |            |          |            |





## 2. 步骤

1. 提前准备好：葱姜水；

2. 香菇泡水，切碎；

3. 小香葱切成末；（葱末）

4. 白菜洗干净，掰开一片一片；

5. 瘦肉搅碎——>加入：适量的盐、一小勺白胡椒粉、半瓶盖花雕酒、一小勺生抽、一小勺蚝油、十三香——>进行抓匀，下入适量的：葱姜水，边加边打（顺着一个方向）——>下入一个鸡蛋清、香菇碎、葱末、十几滴香油——>抓拌均匀！；

6. 准备一大盆凉水；

7. 锅中烧开水+盐（保留白菜的翠绿颜色）——>水开下入白菜，不要超过一分钟——>捞出放入凉水；

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/c8/c82e0059a912505cb303c4f6e0eddf6ee6ba211a58c9a284d78fe7083255ed82.png" style="zoom:25%;" />

    :::

8. 把白菜最厚的部分，切薄；

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/3c/3c4e33ececbbaf35f06be4012d21a1dd664eade62683779b850849126bca1c40.png" style="zoom:25%;" />

    :::

9. 卷起来一些后，两边轻轻的折叠进去；

    ::: details

    <img src="https://blog.images.bornforthis.cn/docs-images/sha256/4d/4dbc358d11b300d28a152054a3e610cd7cd2d0632350ed4f85104b89b1c7f0c7.png" style="zoom:25%;" />

    :::

10. 摆好盘子，大火蒸 8 分钟；

11. 蒸熟之后，倒出蒸出的原汤；

12. 摆上：大葱丝、姜丝、彩椒丝、辣椒丝等，热油淋浇；

13. 淋上蒸鱼豉油；
