## 2. 步骤

::: tabs#cook

@tab 口味 1#口味 1：黑胡椒

1. **肉的准备**

    1. 把瘦肉、肥肉分离；
    2. 肥肉切成小丁；
    3. 瘦肉部分：一部分切块，留小块切成片后切成条；
    4. 把三部分盖上保鲜膜，冷藏 2h；
    5. 同时准备 63g 清水，一起冷冻；

2. **配料**

    1. 耗油 10g；
    2. 盐 7g；
    3. 白糖 15g；
    4. 蜂蜜 13g；
    5. 木薯粉 38g；
    6. 红曲粉 1g；
    7. 黑胡椒粉 3g；
    8. 味精 10g；

3. **馅料准备**

    1. 先放入肥肉，把肥肉搅打出：绒的感觉；

    2. 下入大肉块、倒入提前准备好的配料、以及带冰的水；

    3. 3s 一次高速，每打一个搅拌一下；

    4. 打到非常黏后，下入：肉条，稍微搅打一下；

        > 脆弹的口感源于肉的胶质， 不管是冻肉还是冰水， 目的都是让肉保持低温， 低温才容易出胶， 肉在搅打的过程中会产生温度， 当温度高于13度，胶质便不易产生， 所以请务必一定保持低温！！ 最终成品肉馅温度2-10度之间都可以， 不同地区气温不同， 天气非常热的地区可以用碎冰， 完整的冰块家用绞肉机功率不易完全打碎， 使用碎冰搅打肉温会更低，弹性更大。 脆皮肠有弹性但是不能失去肉粒感， 追求非常非常Q弹可以继续搅打， 把肉打成低于10度的肉浆状态即可！ 本人不是专业大厨，说的可能不够严谨专业， 但这些都是我的实操结论。

    5. 打好肉后，冰箱冷藏 2h；

4. **肠衣准备**

    1. 清水冲洗表面盐分；
    2. 检查是否有漏孔（需剪除）；
    3. 高度白酒浸泡 2 小时；
    4. 使用前反复冲洗干净；

5. **制作**

    1. 可以自行考虑是否加玉米；
    2. 灌肠后，扎洞，挂着晾干；
    3. 水开上汽后，让蒸汽散一散；
    4. 放入烤肠；
    5. 必须：小火慢蒸；

@tab 口味 2#口味 2

1. **预处理阶段**：
    1. 糯米清水浸泡 3 小时，达到手指可捏碎的程度；
    2. 猪后腿肉分离肥瘦，瘦肉保留颗粒感，肥肉搅打细腻；
    3. 玉米粒焯水处理防止戳破肠衣；
2. **肉馅调制**：
    1. 混合肉末加入盐、生抽、糖、红曲米粉；

    3. 拌入糯米、玉米粒和融化的猪油；
