## 1. 食材

| 牛腩     | 西红柿   | 大葱       |
| -------- | -------- | ---------- |
| **姜片** | **八角** | **干辣椒** |
| **生抽** | **老抽** | **蚝油**   |
| **盐**   | **白糖** | **味精**   |
| **香菜** |          |            |



## 2. 步骤

1. 冷水下锅，大火烧开——>撇掉浮沫；
2. 西红柿切薄片；
3. 锅热——>加油——>3 段葱、4 片姜、2 个八角，翻炒出香味——>下牛肉，翻炒至金黄色；
4. 加入 2 勺生抽、1/3 勺的老抽、1/3 勺蚝油——>翻炒均匀；
5. 下入：西红柿——>进行翻炒；
6. 加入：开水；
7. 盖盖：炖煮 1～2h；
8. 时间到了之后，下入配菜：胡萝卜、洋葱、土豆——>大火烧开之后，转小火炖煮 30 分钟；
9. 土豆一掐就烂即可；
10. 按自己口味加盐、白糖（按西红柿的酸度来）调成酸甜口；
11. 下入：味精、香菜；
