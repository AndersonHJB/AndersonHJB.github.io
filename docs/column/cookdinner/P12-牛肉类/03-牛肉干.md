## 1. 食材

| 牛腿肉 2 斤 | 洋葱     | 胡萝卜     | 芹菜       | 香菜       | 大蒜   | 香叶       |
| ----------- | -------- | ---------- | ---------- | ---------- | ------ | ---------- |
| **白芷**    | **八角** | **花椒粒** | **小茴香** | **盐**     |        |            |
| **蚝油**    | **生抽** | **孜然粉** | **鸡精**   | **五香粉** | **盐** | **辣椒粉** |
| **吸油纸**  |          |            |            |            |        |            |





## 2. 步骤

1. **牛肉**：把牛腿肉切成条装，可以借助大拇指比；
2. **腌制**：
    - 洋葱切丝；
    - 胡萝卜切片；
    - 芹菜斜切；
    - 香菜切段；
    - 大蒜拍碎；
    - 6 片香叶捏碎；
    - 3 片白芷掰碎；
    - 2 个八角掰碎；
    - 1 茶勺花椒粒；
    - 1 茶勺小茴香；
    - 1 茶勺盐；
    - 充分抓匀，抓一分钟左右！
    - 保鲜膜包住，腌制 6～8 h；（不要太久，否则菜味过重）
3. **调味**：
    1. 把腌好的牛肉拿出来，把腌制的蔬菜去掉，留下干净的肉；
    2. 2 勺蚝油；
    3. 2 勺生抽；
    4. 1 勺孜然粉；
    5. 1 勺鸡精；（可选）
    6. 1/2 勺白糖；
    7. 1 勺尖五香粉；
    8. 2 平茶勺盐；
    9. 辣椒粉（可选 ）
    10. 再腌制 30 分钟；
4. **烤制**：
    1. 烤箱预热；
    2. 6 勺食用油；
    3. 铺上吸油纸，摆放；
    4. 上下 120 度 60 分钟，翻面 60 分钟，筷子压硬，手捏软。不够 10 分钟、10 分钟的烤；
