## 1. 食材

| 河粉         | 牛肉     | 豆芽     | 小葱         | 韭菜/韭黄          | 洋葱               | 小苏打   |
| ------------ | -------- | -------- | ------------ | ------------------ | ------------------ | -------- |
| **黑胡椒粉** | **白糖** | **生抽** | **玉米淀粉** | **食用油**         | **生抽**           | **老抽** |
| **蚝油**     | **白糖** | **味精** | **鸡精**     | **火腿肠（可选）** | **上海青（可选）** |          |

## 2. 步骤

1. **牛肉**：切片；
2. **腌制牛肉**：
    1. 小苏打；（不能添加太多，容易发苦）
    2. 清水；
    3. **抓匀，抓至粘手起胶**；
    4. 黑胡椒粉；
    5. 白糖；
    6. 生抽；
    7. 玉米淀粉；
    8. 食用油；
    9. **抓匀**；
3. **豆芽**：清洗、掐头去尾（可选）；
4. **洋葱**：少量洋葱，切丝；（跟豆芽放在一起）
5. **小香葱**：切成段；
6. **韭菜/韭黄**：切成一段一段；（跟葱段放在一起）
7. 切火腿肠片，放在香葱、韭黄一起；（可选）
8. 清洗上海青，放在配菜一起；
9. **调碗汁**：
    1. 生抽；（1 勺）
    2. 老抽；（半勺）
    3. 蚝油；（半勺）
    4. 白糖；（1 勺）
    5. 味精；（适量）
    6. 鸡精；（适量）
10. **炒制**：
    1. 油要多，把锅烧到冒烟。把牛肉进行滑散，出锅把油滤掉；
    2. 锅中少油，下入：豆芽、洋葱，翻炒 7～8 秒，出锅；
    3. 锅中少油，烧到冒烟：
        1. 下入河粉，翻炒；
        2. 下入：豆芽、洋葱丝；
        3. 葱段、韭黄段；
        4. 下入料汁；
        5. 翻炒均匀，即可出锅；
