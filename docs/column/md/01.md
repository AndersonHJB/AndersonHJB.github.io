Markdown 标题有两种格式。

# 1、使用 = 和 - 标记一级和二级标题

= 和 - 标记语法格式如下：

```markdown
我展示的是一级标题
=================

我展示的是二级标题
-----------------
```

显示效果如下图：

![](https://blog.images.bornforthis.cn/docs-images/sha256/e2/e20b26d3f6ccc81909170ee8f0dae72b6aa19d543799ad75d8caf982c0d98cb4.png)

# 2. 使用 # 号标记

使用 **#** 号可表示 1-6 级标题，一级标题对应一个 **#** 号，二级标题对应两个 **#** 号，以此类推。

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```
