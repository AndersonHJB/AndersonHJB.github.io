## 什么叫“启发”？

启发，其实是一个心理过程。更准确的说，是三个心理过程连贯起来，才能叫：启发。

- 第一，你得自己心理有个老问题，百思不得其解。
- 第二，你得在一个陌生的领域，获得了一个陌生的信息。
- 第三，你自己对原来的老问题，获得了一个新答案。

::: tip 所以连接起来就是

**新**答案	**生**信息	**老**问题

:::

把这样的心理过程，称之为：**启发**。
