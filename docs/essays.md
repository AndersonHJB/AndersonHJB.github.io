::: tip 辛泽承 日期：2025 年 10 月 10 日 9:59

写代码的核心是什么？不是语法，而是逻辑。语法只是工具，真正使你可以写代码的能力是由逻辑思维去推动。举个例子：让你用代码写出乘法交换律。

那你要怎么写？你得理解乘法交换律的本质原理是：a * b = b * a；

故而，你就可以写出如下代码：

```python
a = int(input())
b = int(input())

r1 = a * b
r2 = b * a
print(f"r1 == r2: {r1 == r2}")
```

上面的代码实现难吗？不难，取决于你是否理解这个乘法交换律，简简单单的几行代码，实现了一个很强大的乘法交换律。

:::
