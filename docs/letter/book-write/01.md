你好，我是悦创。

这是我一贯的文章开头，我今天想跟聊聊编程思维这件事。

一说起编程，你可能最先想到的是程序员坐在电脑前面**<span style="color:orange">敲代码</span>**的样子。确实，这就是一般人对“编程”的想象。不过，我想说的是：编程最重要的其实并不是写出那一行行代码，而是“**<span style="color:orange">编程思维</span>**”。

**那编程思维是什么呢？**

编程思维就是一种把一个问题转化成另一个问题，并且把它解决掉的思考方式。这么说有些抽象，我给你举个例子吧。









- 举一反三思维

- 引导思考思维

- 问题拆分思想：把大问题拆分成小问题，每个小问题又可以反推回大问题，致使
