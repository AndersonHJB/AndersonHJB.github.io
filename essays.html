def remove_duplicates(s):
    index_s = 0
    lst = []  # 初始化是空列表
    for i in s:
        if s[index_s] not in lst:  # 而你使用 s[index_s] in lst，这个是恒为 False。永远不在列表里面。
            lst.append(s[index_s])
            index_s += 1
        elif s[index_s] in lst:
            index_s += 1
    return lst


result = remove_duplicates("apple")
print(result)

辛泽承 日期：2025 年 10 月 10 日 9:59

写代码的核心是什么？不是语法，而是逻辑。语法只是工具，真正使你可以写代码的能力是由逻辑思维去推动。举个例子：让你用代码写出乘法交换律。

那你要怎么写？你得理解乘法交换律的本质原理是：a * b = b * a；

故而，你就可以写出如下代码：

a = int(input())
b = int(input())

r1 = a * b
r2 = b * a
print(f"r1 == r2: {r1 == r2}")

上面的代码实现难吗？不难，取决于你是否理解这个乘法交换律，简简单单的几行代码，实现了一个很强大的乘法交换律。

高效学习应遵循以下核心原则：

  • 学习方式：自学优于补课，主动探索比被动接受更有效。
  • 刷题方法：归纳总结比机械刷题更重要，质量胜于数量。
  • 记忆策略：理解是记忆的基础，而非死记硬背。
  • 考试准备：扎实的基础比应试技巧更关键。
  • 知识构建：体系化的学习优于零散的知识点积累。

大家要记得一句话，学习的第一原理是自学，而不是补课。刷题的第一原理是归纳和总结，而不是数量。记忆的第一原理是理解，而不是背诵。考试的第一原理是基础，而不是技巧。知识的第一原理是体系，而不是碎片。
